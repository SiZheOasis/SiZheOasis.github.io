# 马原遮词初筛

给审阅用的初筛，不是定稿。二十九篇正文与底稿逐字相同，只在建议遮住的词两端加了【】。

【点拨】和【命题分析】没有遮，包括没有写成完整标记、而是写在段末或表格里的点拨。真题年份、考查次数、分析题提示都留在原处。行内点拨从标记起，遮词停在标记之前；标记之后直到下一个标题，按提示段处理。专题二十、二十一里，正文编号在点拨之后重新接上的，从那个编号起仍按正文遮。

虚字「的、了、地、得」尽量留在括号外。下面几类留在【】里，是因为再拆会剩下单字，或那一个字本来就是词的一部分：三处篇名；「人的依赖关系」「以物的依赖关系为基础的人的独立性」；「走自己的路」。另外，「目的」「土地」「地位」「兼得」「合目的性」里的的、地、得是词内的字。真、善、美是单字，所以把整句认识目的一起遮了。

人名只在第一次作为考点时遮了两处：专题二十八开头的三位代表人物，以及一国胜利论的提出者。说明里不列姓名和篇名。

## 各篇

1. 导论。遮了社会根源、阶级基础、三个直接理论来源和三项科学发现；著作栏的篇名，以及意义里的转变方向、首次、公开问世、全面等定位；基本特征的概括句，以及本质、首要、基本、根本。命题分析里再次出现的篇名没有遮。
2. 世界的物质性。遮了第一性、同一性；唯物与唯心、可知与不可知、辩证与形而上学、两种历史观的对照两侧；客观实在、运动、绝对与相对、时空、物质性与基石。辩证法那一句里「发展」两处都遮了，略密。
3. 物质与意识。遮了劳动的决定作用、物质外壳、主观映象；能动作用四条；规律定义；前提、根本途径、物质条件；自然规律与社会规律的对照；人工智能的定义，以及情感意志、社会属性、自立自主自觉。人工智能「做得到」的列举基本没遮。
4. 联系和发展。遮了总观点与总特征、联系的四性、发展的实质、扬弃、人民群众，以及「历史上产生」和「历史上灭亡」。
5. 对立统一。遮了实质和核心、钥匙、矛盾分析方法；斗争性与同一性的条件；无处不在、无时不有；共性寓于个性；主要矛盾与主要方面；绝对与相对对照表。点拨里的四种解决形式没有遮。
6. 量变质变。遮了质的内在规定、度与关节点、适度；必要准备、必然结果、开辟道路、部分质变。点拨里「是否超出度」没有遮。
7. 否定之否定。遮了自我否定、扬弃、两次否定与三个阶段、波浪式前进与螺旋式上升、前进性与曲折性。点拨里的外部否定和「回复」没有遮。
8. 五对范畴。遮了相互依存、渗透、转化、作用；内容对形式的决定；本质与现象的两侧；原因在前；必然通过偶然表现；现实的当前状况与可能的发展方向。真象与假象、可能与不可能都在点拨里，没有遮。
9. 根本方法。遮了本质上的统一、外部必然性与观念形式、反映与被反映、六种思维能力。系统的定义在点拨里，没有遮。
10. 实践。遮了本质里的能动、社会性、物质活动；直接现实性；三种实践类型和最基本；最根本的实践关系；来源、直接经验、动力、目的、唯一标准。虚拟实践，以及直接经验与间接经验的说明，在点拨里，没有遮。
11. 认识的本质。遮了两条认识路线和举例；旧唯物主义与辩证唯物主义的对照；摹写性、原型、创造性、同一本质。
12. 两次飞跃。遮了感性认识与理性认识的对照表；起点、必经、基础和那十六个字；非理性因素的列举；第二次飞跃更为重要。点拨里的两种认识过程公式，以及从认识到实践的最后一个环节，没有遮。
13. 真理。遮了正确反映、形式主观与内容客观、客观真理与本质属性、一元性；绝对性与相对性及转化方向；真理与谬误的绝对对立和可以转化；真理的本性、直接现实性；逻辑证明不能回答、不能取代。点拨里的主观真理标准没有遮。
14. 价值。遮了意义关系；两种错误价值论和两条正确表述；以主体为中心、客观存在、不能创造也不能消灭价值；认识目的的整句；真理尺度与价值尺度、合规律性与合目的性。点拨里「物趋近人」和价值评价的最高标准没有遮。
15. 认识世界和改造世界。遮了统一的基础是实践；必然即规律；自由的定义、认识条件与实践条件、前提与真正实现；自由是相对的。宿命论和唯意志论在点拨里，没有遮。
16. 社会存在与社会意识。遮了地理环境的永恒必要条件、促进或延缓；人口与地理环境不能决定社会形态；生产方式的基础及决定力量；社会心理与意识形态的对照；客观来源、具体的历史的、反作用这一突出表现。
17. 社会基本矛盾。遮了生产力三要素、生产工具的客观依据、劳动者最活跃；所有制的决定意义；决定与反作用；经济基础是生产关系的总和；上层建筑的构成和政权是核心；最终决定力量、根本动力；阶级斗争、革命、改革、科学技术，以及凝聚力量。点拨里「科学技术是生产发展的决定性因素」没有遮。
18. 社会进步与社会形态。遮了集中表现是社会形态的更替；曲折发展、停滞和倒退；三个阶段的整句；五种社会形态；客观、确定不移；归根到底是人民群众的选择性。跨越的限度写在点拨里，没有遮。
19. 人民群众。遮了现实的人是前提；一切社会关系的总和、社会属性；质与量上的范围、劳动群众；三个创造者身份；经济条件的首要影响；可以与不可以对照表里的个别历史事件、总进程和总方向、外貌或后果、基本方向、创造历史、历史的创造者、英雄史观、人们自己创造自己的历史、人人创造历史、参与者。点拨里「一定历史时期会包括某些剥削阶级」没有遮。
20. 商品与劳动价值。遮了两个历史条件；使用价值与价值、交换价值；劳动二重性对照表；社会必要劳动时间、正比与反比、简单劳动；价值量与劳动生产率对照表；价值形式四个阶段；一般等价物和五种职能，以及观念上的货币、实在的货币、足值的金属货币、延期支付；价值规律的三种价格表现形式；私人劳动和社会劳动、生产社会化与私人占有、枢纽。商品是历史范畴、废品类干扰项、单位时间价值量的推导，都在点拨里，没有遮。
21. 剩余价值。遮了两条产生途径和原始积累的两条途径；劳动力成为商品的两个条件；资本的本质；必要劳动与剩余劳动；不变资本是条件、不是来源；唯一源泉；剩余价值率、利润率、生产价格、有机构成四个式子；绝对剩余价值与相对剩余价值；个别价值低于社会价值；工资是劳动力的价值或价格，以及计时工资和计件工资；部门之间的竞争、平均利润、生产价格；核心内容和基石，以及和唯物史观一起。点拨里的计算例题、工资假象的展开，没有遮。「唯一源泉」在自动化那一句又遮了一次，因为问的是自动化是否改变源泉。
22. 资本积累与循环。遮了扩大再生产及其源泉、剩余价值的资本化、资本规模与剥削、失业、必然灭亡和必然胜利；技术构成里的劳动力与比例、有机构成的一般趋势；相对过剩人口的三种形式；资本循环三个阶段和并存、继起；不变资本、可变资本、固定资本、流动资本的对照；价值补偿和实物补偿。点拨里的源泉清单，以及「加快周转不会提高剩余价值率、但会提高年剩余价值率」这一句，没有遮。分类对照表紧接在这句点拨之后，中间没有新标题；这里按正文对照表遮了，审阅时请确认它算不算点拨。
23. 基本矛盾与经济危机。遮了私人占有这一侧；生产相对过剩与绝对过剩；支付手段和流通手段；两个具体表现；危机、萧条、复苏、高涨，以及危机阶段是基本阶段、必经阶段。
24. 垄断。遮了生产集中的结果、大资本吞并小资本；资本积累与资本积聚的对照；联合起来、短期价格协定、垄断利润；竞争的目的、手段、范围；金融资本的融合和三条途径；参与制、个人联合；垄断高价与垄断低价；国家政权与私人垄断资本的融合、五种形式；三种资本输出；国际垄断组织的例子；金融自由化与金融创新。金融化后面的长段叙述只遮了这一句制度条件。垄断价格并不改变价值总量，写在点拨里，没有遮。
25. 经济全球化。遮了生产、贸易、金融三种表现；根本推动力、企业组织形式、体制与组织保障。点拨里金融危机的原因没有遮。
26. 当代资本主义的新变化。遮了国家资本所有制和法人资本所有制；职工参与决策、终身雇佣、职工持股、全民化；实际控制者；滞胀；空心化、金融化、债务化、两类危机交织；根本推动力量；基本框架与根本性质；产业结构；最突出、最鲜明、最主要；经济发展失调、政治体制失灵、社会融合机制失效、社会流动性退化。点拨里三个「没有」没有遮。
27. 历史地位。遮了金钱操纵与精英统治、事实上的不平等、社会矛盾、历史过渡性、冲突的萌芽、社会主义的前奏。这一篇多为完整论断，遮得少。
28. 社会主义的发展。遮了三位代表人物的姓名（只此一次）和直接思想来源；两个学说构成的理论基础和核心命题的那句判断；两个年份、组织的正式名称和简称、灵魂、第一次伟大尝试、选举制和撤换制、工薪水平；一国胜利论（句中两处都遮了）、提出者的姓名（只此一次）、不平衡；三个时期各自的政策；严峻挑战、长期、现实原因、科学态度、走自己的路、文明成果。
29. 共产主义。遮了预见未来的基本前提、与空想社会主义的根本区别、根本价值目标；远大理想与共同理想在时间、层次、范围上的三对关系。
