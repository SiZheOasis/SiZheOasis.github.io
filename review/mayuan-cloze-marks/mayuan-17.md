# **马原·专题十七｜社会基本矛盾和社会历史发展的动力**

# **1\. 生产力与生产关系**

## **（1）生产力是人类社会生活和全部历史的物质基础**

① 生产力**三要素**：【劳动资料】；【劳动对象】；【劳动者】。

生产工具是区分社会经济时代的**【客观依据】**。劳动者是生产力中**【最活跃】的因素**。

② 科学技术是生产力中的重要因素。

## **（2）生产关系**

* 人们在物质生产过程中形成的不以人的意志为转移的经济关系（实质是人们的【物质利益关系】）。生产关系是社会关系中**【最基本】的关系**，其他关系都受其支配和制约。  
* 在生产关系中，生产资料所有制关系是**最基本的、具有【决定意义】的方面**，它是区分不同生产方式、判定社会经济结构性质的**【客观依据】**。

## **（3）生产力与生产关系的相互关系**

生产力**【决定】**生产关系，生产关系对生产力具有**能动的【反作用】**。（适合时起**【推动作用】**，不适合时起【阻碍作用】）

# **2\. 经济基础与上层建筑**

① 经济基础：由社会一定发展阶段的生产力所决定的**【生产关系】的【总和】**。

② 上层建筑：建立在一定经济基础之上的**【意识形态】以及与之相适应的【制度、组织和设施】**。

| 构成 | 类别 | 具体内容 |
| :---- | :---- | :---- |
| **观念上层建筑（即社会意识形态）** |  | **【政治法律思想、道德、艺术、宗教、哲学】等** |
| **政治上层建筑（【主导地位】）** | 政治法律制度 | 国家政治制度、立法司法制度和行政制度 |
| （续上） | 政治组织及设施 | 国家政权机构、政党、军队、警察、法庭、监狱等（国家政权**是【核心】**） |

③ 经济基础与上层建筑的辩证关系：经济基础决定上层建筑，上层建筑反作用于经济基础。（推动或阻碍社会发展）

# **3\. 社会基本矛盾是社会发展的【根本动力】**

① 生产力与生产关系、经济基础与上层建筑之间的矛盾，是**【人类社会基本矛盾】**。

② 生产力是社会基本矛盾运动中**【最基本】的动力因素**，是人类社会发展和进步的**【最终决定力量】**。

③ 社会基本矛盾特别是生产力和生产关系的矛盾，决定着社会中其他矛盾的存在和发展。点拨

在社会基本矛盾的运动中，生产力和生产关系的矛盾是更为基本的矛盾，它决定经济基础和上层建筑的矛盾的产生和发展。

# **4\. 社会发展的其他动力**

社会发展动力是一个系统，其中**【基础性和根本性】**的动力是社会基本矛盾。

此外还有：【阶级斗争、革命、改革、科学技术】等。

① 科学技术：是推动社会文明进步的重要力量。但是，科学技术有时也会表现为异己的、敌对的力量。

② 文化：是推动社会发展的重要力量。

文化为社会发展提供思想指引、精神动力、**【凝聚力量】**。**点拨**

社会基本矛盾是社会发展的**根本动力**。因此，在"社会发展"这个语境下，其他动力基本上都不能对应"**决定**"这个关键词。注意一个特殊情况，在"生产发展"语境下，可以说科学技术日益成为生产发展的**决定性因素**。**【命题分析】**

* 2010 年以来真题选择题考查频率：4 次。  
* 经典干扰项：  
  * 文化是人类社会发展的决定力量（×）  
  * 科学技术是历史变革中的唯一决定性力量（×）
