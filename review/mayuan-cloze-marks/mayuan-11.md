# **马原·专题十一｜认识的本质**

# **1\. 不同哲学派别对认识本质的看法**

| 哲学派别 / 观点 | 说明 |
| :---- | :---- |
| **【唯心主义先验论】** | **坚持【从思想和感觉到物】的唯心主义认识路线** |
| （续上） | 观点：认识先于人的实践经验。**比如"【生而知之】""【认识即回忆】"等** |
| **【唯物主义反映论】** | **坚持【从物到感觉和思想】的唯物主义认识路线** |
| （续上） | **观点：认识是【主体对客体】的【反映】，一切知识都是从【后天】接触实际中得来的** |

| 旧唯物主义（直观的、消极被动的反映论） | 辩证唯物主义（实践基础上的能动的反映论） |
| :---- | :---- |
| 缺陷 | **特点** |
| **① 【离开实践】考察认识问题** | ① 把【实践】的【观点】引入认识论 |
| **② 不了解认识的【辩证本性】** | **② 【把辩证法应用于反映论】考察认识的发展过程** |
| **没有把认识看作一个不断发展的过程，而是认为认识是【一次性完成】的** | **把认识看成一个【由不知到知、由浅入深】的充满矛盾的能动的认识过程** |

# **2\. 认识的本质：主体在实践基础上对客体的能动反映**

① 认识的反映特性（【摹写性】）：人的认识必然要以客观事物为【原型和摹本】。任何观念都可以从现实世界中找到其物质"原型"。

② 认识的能动的创造性：认识不是简单、直接的描摹或照镜子式的原物映现，而是一种在思维中的能动的、**【创造性】的活动**。（比如透过现象看本质）

③ 反映和创造不是人类认识的两种不同的本质，而是**【同一本质】**的两个不同的方面。人的认识是反映性或摹写性与创造性的统一。

## **【命题分析】**

* 2010 年以来真题选择题考查频率：3 次。  
* 命题特点：主要考查直观反映论，尤其要注意"直观""**机械**"等提法。  
* 经典干扰项：  
  * 物质世界是外在于人类的直观的、**机械的**、自在的对象（×）  
  * 要对事物本来面目做直观反映（×）  
  * 意识是对存在的直观反映（×）  
  * 一切观念都是现实的模仿（×）  
  * 意识建构认识对象（×）
