# **马原·专题十二｜认识的两次飞跃以及实践与认识的辩证运动**

# **1\. 从实践到认识：认识过程的第一次飞跃**

| 维度 | 感性认识 | 理性认识 |
| :---- | :---- | :---- |
| **内容** | **认识的【初级阶段】** | 认识的【高级阶段】 |
| （续上） | 由感觉器官直接感受到 | **要借助【抽象思维】** |
| （续上） | **对事物的【现象】、事物的【外部联系】、事物的【各个方面】的认识** | **对事物的【本质】、全体、【内部联系】和事物自身【规律性】的认识** |
| **形式** | **【感觉、知觉、表象】** | **【概念、判断、推理】** |
| **特点** | **【直接性、具体性】** | **【间接性、抽象性】** |
| **评价** | **【不深刻】（注意：不深刻≠不可靠）** | 深刻 |

## **（1）感性认识和理性认识的辩证统一关系**

* 第一，理性认识依赖于感性认识。感性认识是认识过程**的【起点】**，是达到理性认识的**【必经】**阶段。  
* 第二，感性认识有待于发展和深化为理性认识。  
* 第三，感性认识和理性认识相互渗透、相互包含。感性中有理性，理性中有感性。

## **（2）从感性认识上升到理性认识必须具备两个基本条件**

* 第一，获取十分丰富和合乎实际的感性材料。这是实现由感性认识上升到理性认识**的【基础】**。  
* 第二，对感性材料进行**【去粗取精】**、【去伪存真】、**【由此及彼】**、【由表及里】的处理加工。

## **（3）认识活动中的非理性因素**

无论在感性认识中还是在理性认识中，都有非理性**因素的作用**。非理性因素主要是指认识主体**的【情感】**、**【意志】**，广义上还**包括【联想】**、**【想象】**、**【猜测】**、【直觉】、**【顿悟】**、**【灵感】等**。非理性因素对于人的认识能力和认识**活动具有激活**、驱动作用。**点拨**

① 感性中有理性（强调理性），人的感觉是渗透着理性的感觉，如对于同一棵大树，木匠看到的是木材，画家看到的是色彩和色调，植物学家看到的是它的形态特征；理性中有感性（强调感性），比如"饱经风霜的老人与缺乏阅历的少年对同一句格言的理解是不同的"。② 人的认识过程是理性因素和非理性因素协同起作用的结果。理性因素是指人的理性直观、理性思维等能力。理性因素在认识活动中的作用主要有：指导作用、解释作用、预见作用。③ 感性认识与理性认识不等同于非理性因素和理性因素。

# **2\. 从认识到实践：认识过程的第二次飞跃**

从认识到实践的飞跃是比第一次飞跃【更为重要】的飞跃。这是因为：

① 认识世界的目的是【改造世界】。

② 认识的真理性只有在实践中才能得到检验和发展。点拨

① 正确的认识指导实践会使实践顺利进行、达到预期的效果；错误的认识误导实践时，就会对实践产生消极的乃至破坏性的作用，使实践失败。② 从认识到实践的**最后**一个环节，是对人民群众进行组织和宣传，让理论为群众所掌握，并转化为改造世界的物质力量。

# **3\. 实践与认识的辩证运动**

① 实践与认识的辩证运动，是一个由感性认识到理性认识，又由理性认识到实践的飞跃，是【实践、认识、再实践、再认识】，循环往复以至无穷的辩证发展过程。

② 认识是一个反复循环和无限发展的过程。这个过程是一个波浪式前进和螺旋式上升的过程。**点拨**

两种认识过程

具体的认识过程：感性认识—理性认识—实践；认识发展的总过程：实践—认识—再实践—再认识，循环往复、无限发展。
