# **一、教育、科技、人才是中国式现代化的【基础性、战略性支撑】**

1. 全面建设社会主义现代化国家，教育**【是根本】**，科技**【是关键】**，人才**【是基础】**。必须坚持科技是**【第一生产力】**、人才是**【第一资源】**、创新是**【第一动力】**。  
2. **建设教育强国**、科技强国、人才强国具有**【内在一致性和相互支撑性】**。要坚持教育发展、科技创新、人才培养**【一体推进】**。

# **二、加快建设教育强国**

1. 教育是【强国建设、民族复兴之基】，是民族振兴、社会进步的基石。  
2. 教育是国家经济社会发展的支撑力量，在国家发展中始终具有【基础性先导性全局性】地位。  
3. 建设教育强国是全面建成社会主义现代化强国的**【战略先导】**，是实现高水平【科技自立自强】的**【重要支撑】**，是促进全体人民共同富裕的**【有效途径】**，是以中国式现代化全面推进中华民族伟大复兴的**【基础工程】**。  
4. 建成教育强国是实现以中国式现代化全面推进强国建设、民族复兴伟业的【先导任务、坚实基础、战略支撑】。  
5. 教育具有政治属性。教育的**【根本任务】**是【立德树人】。培养**【什么人】**、【怎样培养人】、【为谁培养人】是教育的**【根本问题】**，也是建设教育强国的**【核心课题】**。  
6. 教育具有人民属性。人民满意是发展教育的**【根本尺度】**。【教育公平】是【社会公平】的重要基础。

# **三、加快建设科技强国**

1. 重要性  
   * 科技强则国家强。科技是国之利器。实现高水平科技自立自强，**第一**，是国家强盛和民族复兴的**【战略基石】**。全面建成社会主义现代化强国关键看科技自立自强，这是促进发展大局的**【根本支撑】**。  
   * 第二，是应对风险挑战和维护国家利益的**【必然选择】**。科技自立自强是国家【强盛之基】、【安全之要】。  
   * 第三，是构建新发展格局、推动高质量发展、满足人民美好生活需要的内在要求。  
2. 打赢【关键核心技术】攻坚战  
   1. **关键核心技术**是**【国之重器】**，**关键核心技术**必须掌握在**【自己手中】**。**关键核心技术是【要不来、买不来】**、【讨不来】的。  
   2. 建设世界科技强国，需要标志性科技成就。  
3. **增强【自主创新能力】**  
   1. 重要性：第一，自力更生是中华民族自立于世界民族之林的**【奋斗基点】**，自主创新是我们攀登世界科技高峰的**【必由之路】**。第二，实现高水平科技自立自强，必须增强自主创新能力，坚定不移走中国特色**【自主创新道路】**。  
   2. **含义**：自主创新，就是从增强国家创新能力出发，加强【原始创新、集成创新和开放创新】，确保国家拥有【自主可控】的科技创新能力。  
   3. 举措：第一，【基础研究】是科技创新的**【源头】**，是所有技术问题的**【总机关】**。第二，【国家战略科技力量】是世界科技强国竞争的**【着力点】**。

# **四、加快建设人才强国**

1. 培养人才是国家和民族长远发展大计  
   * 人才是人力资源中能力和素质较高的劳动者，在国家发展中具有重要战略地位，已经成为推动社会发展**【最活跃、最积极】**的因素。人才是实现民族振兴、赢得国际竞争主动的**【战略资源】**。人才是**第一资源**，是全面建设社会主义现代化国家的基础性、战略性支撑。  
2. 培养造就大批【德才兼备】的高素质人才  
   * 抓好国家战略人才力量储备，建设【世界重要人才中心】和【创新高地】。
