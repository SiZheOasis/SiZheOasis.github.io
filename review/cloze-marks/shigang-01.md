# **史纲·专题一｜资本帝国主义对中国的侵略与近代中国社会的半殖民地半封建性质**

# **1\. 西方列强对中国侵略的手段**

【军事侵略】（这是【首先和主要】的手段）、政治控制、经济掠夺和文化渗透。

文化渗透的目的，是宣扬【殖民主义奴化思想】，麻醉**中国人民的精神**，摧毁中国人的【民族自尊心和自信心】。

# **2\. 鸦片战争——中国近代史的【起点】**

鸦片战争以清政府的失败而告终。中国被迫与英国签订了《【南京条约】》，这是中国近代史上**【第一个不平等条约】**。此后到【20世纪初】，资本－帝国主义列强又通过强迫清政府签订一系列不平等条约，在中国攫取了大量侵略特权。随着外国资本主义的入侵，中国的【封建社会】逐步变成了【半殖民地半封建】社会。**点拨**

**鸦片战争之所以成为中国近代史的起点，主要是因为鸦片战争使近代中国社会的性质、主要矛盾、革命任务（开始了反帝反封建的资产阶级民主革命）发生了变化。**

# **3\. 近代中国社会的半殖民地半封建性质**

## **（1）中国逐步变成半殖民地的原因**

1. 在西方列强的侵略下，中国已经丧失了【完全独立】的地位（领土、主权都**【不完整】**）。  
2. 帝国主义列强没有能够实现【灭亡和瓜分】中国的图谋，中国名义上还是**【独立国家】**，有自己的政府，因此被称作半殖民地。

## **（2）中国逐步变成半封建社会的原因**

1. 中国出现了资本主义**【生产关系】**，已经不是完全的封建社会了。  
2. 中国的民族资本主义经济并没有也不可能成为中国社会经济的【主要形式】（西方列强并不愿意中国成为独立的资本主义国家）。中国的经济既不再是完全的【封建经济】，也不是完全的【资本主义经济】，而成为半殖民地半封建的经济了。

**近代以来中国签订的部分不平等条约**

| 时间 | 条约 | 条约主要内容和后果 |
| :---- | :---- | :---- |
| **【1842年】** | **中英《【南京条约】》** | \*\*① 【割让香港岛】，【五口通商】，开始丧失【关税自主权、领土主权、领海主权】；\*\*② 中国开始成为半殖民地半封建社会的【标志】 |
| **【1843年】** | **中英《【五口通商章程】》** | **帝国主义开始在华取得【领事裁判权】** |
| **【1843年】** | **中英《【虎门条约】》** | \*\*① 开外国人在中国不受中国法律管束的先例，中国丧失【司法主权】；\*\*② 【片面最惠国待遇】；**③ 租赁土地，永久居住，后变为设【租界】** |
| **【1858年】** | **《【天津条约】》** | 外国公使【常驻北京】，逐渐控制中国的【内政外交】 |
| **【1895年】** | **中日《【马关条约】》** | ① 割让【辽东半岛、台湾岛及所有附属岛屿、澎湖列岛】；② 允许外国人在中国【投资办厂】，**【商品输出向资本输出】的转变；③ 帝国主义列强掀起【瓜分中国】的狂潮；④ 中国人民的民族意识开始【普遍觉醒】** |
| **【1901年】** | **《【辛丑条约】》** | ① 【赔款最多】；② **获得在中国领土上【驻军】的特权**；**③ 中国【完全成为】半殖民地半封建社会** |

**点拨**

在近代中国社会性质开始发生质变的过程中，近代中国社会阶级关系也发生了变动。① 新的阶级的产生。第一，工人阶级诞生。它是先于中国的资产阶级而产生的，最早出现于外国资本主义在华企业中。第二，中国资产阶级产生。其中有一部分是**官僚买办资本家**，另一部分是民族资本家。**② 旧的阶级的变化。地主阶级：出现了一批城居地主；一部分地主转化为资本家。农民阶级：不少自耕农失去土地，向贫农或雇农转化；有些成为产业工人的后备军。**

# **4\. 近代中国的社会主要矛盾和两大历史任务**

## **（1）社会主要矛盾**

【帝国主义和中华民族】的矛盾（【民族矛盾】），是【最主要】的矛盾；

【封建主义和人民大众】的矛盾（【阶级矛盾】）。

## **（2）两大历史任务**

争得【民族独立】、**【人民解放】**；实现【国家富强】、**【人民幸福】**。

关系：

1. **区别**：两大历史任务的主题、内容和**【实现方式】都不一样**。  
2. **联系**：前一个任务为后一个任务**【扫除障碍】**，**创造【必要前提】**；后一个任务是前一个任务的最终目的和**【必然要求】**。

**点拨**

**要争得民族独立和人民解放，必须首先进行反帝反封建的民主革命**。其他的救国主张（如工业救国、教育救国、科学救国）都被历史证明是行不通的。
