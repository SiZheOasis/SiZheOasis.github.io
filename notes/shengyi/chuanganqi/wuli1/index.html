一、 变阻式（电位器）传感器与负载效应推导（P4–6）

1.1 结构分类与优缺点（PPT P4–6）

  • 结构：直线电位器、单圈电位器、多圈电位器，将机械位移 $x$ 转化为电阻阻值变化。
  • 优缺点：结构简单、尺寸小、价格低、受温湿度与电磁场干扰小、输出信号大；缺点是电刷与电阻膜间存在机械摩擦，需较大输入能量、易磨损降低精度与分辨力、动态响应差（仅适于慢变信号）。

1.2 理想空载 vs. 实际负载效应（Loading Effect）推导

设电位器总长度为 $L$、总阻值为 $R_p$、激励电压为 $V_{\text{in}}$，电刷滑片位置为 $x \in [0, L]$（对应下方电阻 $R_x = \frac{x}{L}R_p$，上方电阻 $R_p - R_x$）：

  1. 理想空载输出（$R_L \to \infty$，P5）： $$V_{\text{out}} = \frac{R_x}{R_p}V_{\text{in}} = \frac{x}{L}V_{\text{in}}$$
  2. 接入负载电阻 $R_L$ 后的实际输出：$R_x$ 与 $R_L$ 并联，等效下臂电阻 $R_{\parallel} = \frac{R_x R_L}{R_x + R_L}$，由分压公式得： $$V_{\text{out}} = \frac{R_{\parallel}}{(R_p - R_x) + R_{\parallel}}V_{\text{in}} = \frac{\frac{x}{L}V_{\text{in}}}{1 + \frac{R_p}{R_L}\cdot\frac{x}{L}\left(1 - \frac{x}{L}\right)}$$
    • 结论：当 $R_L$ 不够大时，分母出现非线性项 $\frac{R_p}{R_L}\frac{x}{L}(1-\frac{x}{L})$，使输出曲线向下弯曲（最大非线性误差发生在中点 $\frac{x}{L}=\frac{1}{2}$ 处，约为 $\frac{R_p}{4R_L}$）；工程上必须满足 $R_L \gg R_p$。

二、 电阻应变效应全微分推导：尺寸效应 vs. 压阻效应（P7–13）

2.1 应变效应物理本质与基本结构（PPT P7, P11–12）

导体或半导体在外界机械力作用下产生形变 $\varepsilon = \frac{\Delta L}{L}$，导致电阻值发生变化，称为应变效应（可测纳米级微小位移）。

  • 粘贴式应变计三类（P12）：电阻丝式（常用直径 $0.025\;\text{mm}$ 高阻丝绕成敏感栅）、金属箔式（光刻成型，端头加宽可有效抑制横向效应）、螺旋式。

2.2 灵敏系数 $G$ 的零跳步全微分推导（PPT P8, P10, P13）

最小闭环

【最小闭环：从 $R = \rho\frac{L}{A}$ 导出应变灵敏系数 $G = (1 + 2\mu) + \frac{\Delta\rho/\rho}{\varepsilon}$】

  1. 对圆柱形电阻丝（$A = \pi r^2$）取对数全微分： $$\ln R = \ln\rho + \ln L - \ln A \implies \frac{dR}{R} = \frac{d\rho}{\rho} + \frac{dL}{L} - \frac{dA}{A}$$
  2. 将截面积微分转化为半径微分：对 $A = \pi r^2$ 求微分得 $dA = 2\pi r\,dr$，故： $$\frac{dA}{A} = \frac{2\pi r\,dr}{\pi r^2} = 2\frac{dr}{r}$$
  3. 引入泊松比 $\mu$：轴向拉伸（$dL > 0$）时半径收缩（$dr < 0$），满足 $\frac{dr}{r} = -\mu\frac{dL}{L}$。代入上式并改写为有限小增量： $$\frac{\Delta R}{R} = \frac{\Delta L}{L} - 2\left(-\mu\frac{\Delta L}{L}\right) + \frac{\Delta\rho}{\rho} = (1 + 2\mu)\frac{\Delta L}{L} + \frac{\Delta\rho}{\rho}$$
  4. 定义轴向应变 $\varepsilon \equiv \frac{\Delta L}{L}$ 与灵敏系数 $G$（PPT P10, P13）： $$\boxed{G \equiv \frac{\Delta R / R}{\Delta L / L} = (1 + 2\mu) + \frac{\Delta\rho / \rho}{\varepsilon}}$$ $$\frac{\Delta R}{R} = G\varepsilon$$
  • 金属 vs. 半导体物理主导机制对比（PPT P10 必考！）：
材料类型 主导物理效应 灵敏系数 $G$ 典型值 工程特性
金属电阻丝（如康铜） 尺寸效应 $(1+2\mu)$ 为主 $G \approx 2$（因金属 $\mu\approx 0.3 \implies 1+2\mu\approx 1.6$，外加微弱压阻） 线性范围宽、温度稳定性好、康铜应用最广
半导体（单晶硅等） 压阻效应 $\frac{\Delta\rho/\rho}{\varepsilon}$ 为主 为金属的 $50 \sim 70$ 倍（$G \approx 100\sim 140$） 灵敏度极高，但电阻率温度系数极大、非线性强，必须做温度补偿

三、 应变片横向效应完整微元积分推导（P14–18）

由于丝式应变片敏感栅两端是半径为 $r$ 的半圆弧形横栅，当试件承受轴向应变 $\varepsilon$ 的同时受到垂直方向的横向应变 $\varepsilon_r$ 时，半圆弧段也会产生电阻变化，称为横向效应。

最小闭环

【最小闭环：半圆弧横栅微元积分推导 $K_x, K_y$ 与横向效应系数 $H$（PPT P15–18）】 设敏感栅有 $n$ 根纵栅（每根长 $l$），则共有 $(n - 1)$ 个半径为 $r$ 的半圆弧横栅，栅丝总长 $L = nl + (n-1)\pi r$，栅丝材料本身的灵敏系数为 $K_s$。

  1. 纵栅总变形量：全部 $n$ 根纵栅仅感受轴向应变 $\varepsilon$： $$\Delta L_1 = n l \varepsilon$$
  2. 半圆弧微元弧长上的应变 $\varepsilon_\theta$：在半圆弧上极角 $\theta \in [0, \pi]$ 处取微元弧长 $dl = r\,d\theta$。由材料力学平面应变转轴公式（主应变 $\varepsilon, \varepsilon_r$ 投影到切向方向）： $$\varepsilon_\theta = \varepsilon\sin^2\theta + \varepsilon_r\cos^2\theta = \frac{\varepsilon + \varepsilon_r}{2} - \frac{\varepsilon - \varepsilon_r}{2}\cos 2\theta$$ (注：若以垂直于 $\varepsilon$ 的半径方向为 $\theta=0$ 起算，则写成 PPT P15 形式 $\varepsilon_\theta = \frac{\varepsilon+\varepsilon_r}{2} + \frac{\varepsilon-\varepsilon_r}{2}\cos 2\theta$，积分结果完全相同！)
    • (附：为什么平面应变转轴公式会出现 $2\theta$？取微元矢量 $\vec{dr} = (dx, dy) = dr(\cos\theta, \sin\theta)$，变形后由对称应变张量 $[\varepsilon_{ij}]$（主方向无切应变 $\gamma_{xy}=0$，且 $\varepsilon_x=\varepsilon,\;\varepsilon_y=\varepsilon_r$）得沿切线方向正应变 $\varepsilon_\theta = \hat{n}^T \mathbf{\varepsilon} \hat{n} = \varepsilon\cos^2\theta + \varepsilon_r\sin^2\theta$，再用降幂公式 $\cos^2\theta = \frac{1+\cos 2\theta}{2},\;\sin^2\theta = \frac{1-\cos 2\theta}{2}$ 即得 $2\theta$ 形式！)
  3. 积分求单个半圆弧变形量 $\Delta l$：注意到 $\int_0^\pi \cos 2\theta\,d\theta = \left[\frac{1}{2}\sin 2\theta\right]_0^\pi = 0$： $$\Delta l = \int_0^\pi \varepsilon_\theta\,dl = \int_0^\pi \left(\frac{\varepsilon + \varepsilon_r}{2} + \frac{\varepsilon - \varepsilon_r}{2}\cos 2\theta\right)r\,d\theta = \frac{\pi r}{2}(\varepsilon + \varepsilon_r)$$
  4. 全部 $(n-1)$ 个横栅变形量与敏感栅总变形： $$\Delta L_2 = (n-1)\frac{\pi r}{2}(\varepsilon + \varepsilon_r)$$ $$\Delta L = \Delta L_1 + \Delta L_2 = \left[nl + \frac{(n-1)\pi r}{2}\right]\varepsilon + \frac{(n-1)\pi r}{2}\varepsilon_r$$
  5. 解耦轴向与横向灵敏系数（PPT P17–18）： $$\frac{\Delta R}{R} = K_s \frac{\Delta L}{L} = K_x \varepsilon + K_y \varepsilon_r$$ 其中： $$K_x = K_s\frac{nl + \frac{(n-1)\pi r}{2}}{L}, \qquad K_y = K_s\frac{\frac{(n-1)\pi r}{2}}{L}$$
    • 令 $\varepsilon_r = 0$ 得轴向灵敏度 $K_x = \frac{\Delta R/R}{\varepsilon}$；令 $\varepsilon = 0$ 得横向灵敏度 $K_y = \frac{\Delta R/R}{\varepsilon_r}$。
    • 定义横向效应系数 $H$ 为二者之比（PPT P18）： $$\boxed{H = \frac{K_y}{K_x} = \frac{(n-1)\pi r}{2nl + (n-1)\pi r}}$$
    • 工程设计准则：$r$ 越小、$l$ 越大，则 $H$ 越小（即敏感栅越窄、基长越长，横向效应误差越小；金属箔式应变片通过把端头转弯处做宽降低横栅电阻占比，也能大幅减小 $H$）。

四、 应变片静态非理想特性与电桥戴维南等效（P19–26）

4.1 三大非理想特性（PPT P19–21，常考名词解释/简答！）

  1. 机械滞后（P19）：恒温下加载与卸载特性曲线不重合（残余变形、粘结剂固化不充分导致；加载最大应变越大，卸载滞后也越大）。
  2. 零点漂移与蠕变（P20）：
    • 零漂：恒温、无应变时阻值随时间变化（通电自热、内应力释放、胶固化不充分）；
    • 蠕变：恒温、恒定机械应变下阻值随时间变化（方向常与原应变相反，因胶层发生“滑动”使传递到敏感栅的应变逐渐松弛）。
  3. 应变极限（P21）：恒温下，指示应变 $\varepsilon_i$ 相对真实应变 $\varepsilon_g$ 的相对误差不超过规定值（一般为 $10\%$）时的最大真实应变值： $$\delta = \frac{|\varepsilon_i - \varepsilon_g|}{\varepsilon_g}\times 100\% = 10\% \implies \varepsilon_i = 90\%\,\varepsilon_g$$

4.2 惠斯通电桥戴维南等效与负载输出（PPT P22–25）

  • 开路戴维南等效电压 $v_{eq}$（$Z_1, Z_2$ 为左支路，$Z_3, Z_4$ 为右支路，P22）： $$v_{eq} = V_{\text{in}}\left(\frac{Z_1}{Z_1 + Z_2} - \frac{Z_3}{Z_3 + Z_4}\right), \qquad Z_{\text{eq}} = (Z_1 // Z_2) + (Z_3 // Z_4)$$
  • 平衡条件：$Z_1 Z_4 = Z_2 Z_3$。
  • 接入负载电阻 $R_L$ 后的实际输出电压（P22）： $$v_o = \frac{R_L}{R_{\text{eq}} + R_L}v_{eq}$$
  • 等臂纯电阻电桥三大经典结论（P23–25）：单臂（$1/4$ 桥）$v_{eq} \approx \frac{1}{4}\frac{\Delta R}{R}V_{\text{in}}$；差动半桥 $v_{eq} = \frac{1}{2}\frac{\Delta R}{R}V_{\text{in}}$；差动全桥 $v_{eq} = \frac{\Delta R}{R}V_{\text{in}}$（完整推导见第 08 讲）。

五、 物理公理与底层简单证明（补强短板）

5.1 微观欧姆定律与电阻定律 $R = \rho\frac{L}{A}$ 证明

为什么导体的电阻正比于长度 $L$、反比于截面积 $A$？

  1. 微观欧姆定律：在导体内部施加电场 $\vec{E}$，自由电子定向漂移形成电流密度 $\vec{J} = \sigma \vec{E}$（$\sigma = \frac{1}{\rho}$ 为电导率，$n$ 为载流子密度）。
  2. 积分宏观量：对均匀截面积 $A$、长度 $L$ 的电阻丝，总电流 $I = J A = \sigma E A$，两端电压 $U = E L$。
  3. 两式相除： $$R \equiv \frac{U}{I} = \frac{E L}{\sigma E A} = \frac{1}{\sigma}\frac{L}{A} = \boxed{\rho\frac{L}{A}}$$ 物理直觉：长度 $L$ 越长，电子碰撞散射路径越长，阻碍越大；截面积 $A$ 越大，并行通道越多，阻碍越小。

5.2 泊松比 $\mu$ 与体积相对变化 $\frac{\Delta V}{V} = (1-2\mu)\varepsilon$

为什么金属丝轴向拉长时，横截面积一定会收缩？

  • 设圆柱电阻丝体积 $V = A L = \pi r^2 L$，取对数全微分： $$\frac{dV}{V} = \frac{dL}{L} + 2\frac{dr}{r} = \varepsilon + 2(-\mu\varepsilon) = \boxed{(1 - 2\mu)\varepsilon}$$
  • 物理极限：对于完全不可压缩材料（如橡胶、水），拉伸时体积不变（$dV = 0$），故 $\mu = 0.5$；金属晶格存在原子间距弹性扩张，通常 $\mu \approx 0.3 < 0.5$，因此拉伸时体积微增，尺寸效应项 $1 + 2\mu \approx 1.6$。

5.3 戴维南等效定理（Thevenin's Theorem）的叠加证明

为什么任何复杂的线性电阻电桥，对负载 $R_L$ 而言总能简化为一个电压源 $v_{eq}$ 串联一个内阻 $R_{eq}$？

  • 在输出端外接假想电流源 $I_{\text{test}}$，由线性电路叠加定理，端口电压 $V$ 是原独立源（令 $I_{\text{test}}=0$，得开路电压 $v_{eq}$）与测试电流源（令原独立源置零，得 $I_{\text{test}} R_{eq}$）的线性叠加，即 $V = v_{eq} - I_{\text{test}} R_{eq}$。这正是电压源串联内阻的伏安特性！

一、 动脉与静脉血压生理学基础（P27–31）

1.1 动脉血压 vs. 静脉血压与能量转化（PPT P27–28）

  • 动脉血压：左心室射血产生；血管阻力大、压力高；心室收缩时动脉瓣（半月瓣）打开、房室瓣（二尖瓣）关闭，动能 $\downarrow$、弹性势能 $\uparrow$，最高值为收缩压（SP）；心室舒张时动脉瓣关闭、房室瓣打开，动能 $\uparrow$、势能 $\downarrow$，最低值为舒张压（DP）。
  • 静脉血压：主要由右心室舒张负压抽吸与呼吸负压驱动，压力很低且易受重力影响。

1.3 正常血压范围与平均动脉压公式（PPT P30–31）

二、 弹性贮器效应与五大血压影响因素（P32–34）

2.1 弹性贮器效应（Windkessel Effect，PPT P32）

  • 物理机制：外周阻力主要来自小动脉和微动脉（阻滞血液瞬间流走），而大动脉血管壁弹性大。心室射血时约 $1/3$ 血液直接流向外周，其余 $2/3$ 撑开大动脉将动能转化为弹性势能储存；心室舒张时大动脉弹性回缩，将储存的血液压向外周，从而把心脏的间断脉冲射血转化为连续血流，维持较高的平均压。
  • 血管网络串并联阻力（P32）：串联 $R_{\text{总}} = \sum R_i$；并联 $\frac{1}{R_{\text{总}}} = \sum \frac{1}{R_i}$。
  • 核心结论：收缩压 $SP$ 主要反映心室每搏输出量；舒张压 $DP$ 主要反映外周阻力大小。

三、 血液动力学三大物理定律与泊肃叶积分推导（P35–37）

3.1 连续性方程与伯努利方程（PPT P35）

  1. 连续性方程（质量守恒）：不可压缩定常流中体积流量 $Q\;(\text{m}^3/\text{s})$ 处处相等： $$Q = v_1 A_1 = v_2 A_2$$
  2. 伯努利方程（能量守恒）：单位体积流体的静压能、动能与重力势能之和沿流线守恒： $$p + \frac{1}{2}\rho v^2 + \rho g h = \text{const}$$

3.2 牛顿粘性定律与泊肃叶定律推导（PPT P36–37，核心推导！）

  • 牛顿内摩擦（粘性）定律（P36）：相邻液层间的切应力 $\tau$ 正比于速度梯度 $\frac{dv}{dx}$（$\eta$ 为血液粘滞系数，单位 $\text{Pa}\cdot\text{s}$）： $$\tau = \frac{F}{A} \approx \eta\frac{dv}{dx}$$
最小闭环

【最小闭环：从牛顿粘性定律积分导出泊肃叶定律与流阻 $R = \dfrac{8\eta L}{\pi r^4}$】 考察半径为 $R_0$（PPT 记作 $r$）、长度为 $L$ 的刚性圆管内定常层流，两端压差为 $\Delta p$：

  1. 力平衡求速度剖面 $v(\rho_c)$：取半径为 $\rho_c$ 的同轴圆柱液柱，推动力 $\Delta p \cdot \pi \rho_c^2$ 与管壁粘性阻力 $2\pi \rho_c L \cdot \left(-\eta\frac{dv}{d\rho_c}\right)$ 平衡： $$\frac{dv}{d\rho_c} = -\frac{\Delta p}{2\eta L}\rho_c$$ 由管壁无滑移边界条件 $v(r) = 0$，从 $\rho_c$ 到 $r$ 积分得抛物线流速分布： $$v(\rho_c) = \frac{\Delta p}{4\eta L}\left(r^2 - \rho_c^2\right)$$
  2. 环带积分求总体积流量 $Q$：取圆环微元面积 $dA = 2\pi \rho_c\,d\rho_c$，积分得： $$Q = \int_0^r v(\rho_c)\cdot 2\pi \rho_c\,d\rho_c = \frac{\pi\Delta p}{2\eta L}\int_0^r \left(r^2 \rho_c - \rho_c^3\right)d\rho_c = \frac{\pi\Delta p}{2\eta L}\left[\frac{r^4}{2} - \frac{r^4}{4}\right] = \boxed{\frac{\pi r^4}{8\eta L}\Delta p}$$
  3. 流体欧姆定律与血管阻力 $R$（PPT P36–37）：类比电学 $I = \frac{U}{R}$，令流量 $Q \leftrightarrow I$、压差 $\Delta p \leftrightarrow U$，得： $$\boxed{Q = \frac{\Delta p}{R}, \qquad R = \frac{8\eta L}{\pi r^4}}$$
    • 病理映射（P37）：阻力与半径的 4 次方成反比！原发性高血压中微动脉半径 $r$ 轻微收缩（$r\downarrow$），或高血脂引起血液粘滞度 $\eta\uparrow$，都会导致外周阻力 $R$ 急剧升高。

四、 物理公理与底层简单证明（补强短板）

4.1 伯努利方程的能量守恒 / 动能定理 3 行证明

为什么流速越快的地方，静压强 $p$ 反而越低？ 考察理想不可压缩流体沿流管微元在 $dt$ 时间内从截面 $1$（$p_1, v_1, h_1$）移动到截面 $2$（$p_2, v_2, h_2$），流过的微元体积 $\Delta V = A_1 v_1 dt = A_2 v_2 dt$，质量 $\Delta m = \rho\Delta V$：

  1. 外力做功：上游推力做正功 $p_1 A_1 (v_1 dt) = p_1\Delta V$，下游阻力做负功 $-p_2\Delta V$，重力做功 $-\rho g(h_2 - h_1)\Delta V$。
  2. 由动能定理 $\sum W = \Delta E_k$： $$(p_1 - p_2)\Delta V - \rho g(h_2 - h_1)\Delta V = \frac{1}{2}\rho\Delta V(v_2^2 - v_1^2)$$
  3. 消去 $\Delta V$ 移项： $$\boxed{p_1 + \frac{1}{2}\rho v_1^2 + \rho g h_1 = p_2 + \frac{1}{2}\rho v_2^2 + \rho g h_2 = \text{const}}$$

4.2 为什么泊肃叶流阻 $R \propto \frac{1}{r^4}$ 而不是 $\frac{1}{r^2}$？

电学中导线电阻 $R_e = \rho\frac{L}{\pi r^2} \propto \frac{1}{r^2}$，为什么血管流阻却是 $r$ 的四次方反比？

  • 第一重 $1/r^2$（几何截面积）：管径减半，过流截面积 $A = \pi r^2$ 缩小为 $1/4$；
  • 第二重 $1/r^2$（粘性速度梯度）：由于管壁无滑移边界条件（$v_{\text{壁}}=0$），管径减半时中心层流离静止管壁的距离减半，切应力梯度剧增，使得截面平均流速 $\bar{v} = \frac{\Delta p\, r^2}{8\eta L}$ 也按 $r^2$ 缩小为 $1/4$！
  • 两者相乘，总流量 $Q = A\bar{v} \propto r^2 \cdot r^2 = r^4$，故流阻 $R \propto \frac{1}{r^4}$。

五、 物理公理与底层简单证明（补强短板）

5.1 流体力学—电学类比的“功率共轭”公理

为什么可以把血压 $p$ 类比为电压 $U$、把体积流量 $Q$ 类比为电流 $I$，并直接套用 RLC 电路方程？

  1. 流变量与势变量守恒：电学中电荷 $q = \int I\,dt$ 守恒；流体中不可压缩液体体积 $V = \int Q\,dt$ 守恒（对应 $q \leftrightarrow V,\; I \leftrightarrow Q$）。
  2. 功率与能量严格同构：
    • 瞬时功率：$P_{\text{电}} = U I \quad \leftrightarrow \quad P_{\text{流}} = p Q$；
    • 感性储能（动能）：$E_L = \frac{1}{2}L I^2 \quad \leftrightarrow \quad E_k = \frac{1}{2}m v^2 = \frac{1}{2}(\rho A L)\left(\frac{Q}{A}\right)^2 = \frac{1}{2}\underbrace{\left(\frac{\rho L}{\pi r^2}\right)}_{L_c} Q^2$；
    • 容性储能（弹性势能）：$E_C = \frac{1}{2}\frac{q^2}{C} \quad \leftrightarrow \quad E_p = \frac{1}{2}\frac{V^2}{C_d}$；

一、 平板电容公式与三大工作类型（P70–71, P78–79）

1.1 平板电容器基本方程（PPT P70–71）

忽略边缘效应时，两平行极板构成的电容量为： $$C = \frac{\varepsilon S}{\delta} = \frac{\varepsilon_0 \varepsilon_r S}{\delta}$$ 其中 $\varepsilon_0 = 8.854\times 10^{-12}\;\text{F/m}$ 为真空介电常数，$\varepsilon_r$ 为极板间介质的相对介电常数（空气介质 $\varepsilon_r \approx 1$），$S$ 为极板正对面积，$\delta$ 为极板间距。

1.2 三种电容变化机制与优缺点（PPT P71, P78–79）

  1. 变极距型（$\delta$ 变）：非线性但分辨力极高（可测 $0.01\;\mu\text{m}$ 微位移），在微位移/压力检测中应用最广；
  2. 变面积型（$S$ 变）：如极板相对平动 $\Delta x$（面积 $S = b(a-\Delta x)$），$\Delta C = -\frac{\varepsilon b}{\delta}\Delta x$，天然线性但灵敏度较低，适于较大位移测量；
  3. 变介电常数型（$\varepsilon_r$ 变，P78）：依靠极板间介电层材料（如多孔柔性介电层受压排出空气使等效 $\varepsilon_r$ 增大）或液位高度变化改变电容量。
  • 核心优缺点（P79）：
    • 优点：输入能量极小、分辨力极高；温度稳定性好、能量损耗小；结构简单耐高低温/强辐射/强磁场；动态特性好；可非接触测量且具有平均效应；
    • 缺点：输出阻抗极高（容抗 $1/(\omega C)$ 大）、负载能力差；寄生电容 $C_p$ 影响大；变极距型存在非线性。

二、 单端变极距型：泰勒展开与非线性误差推导（P72–74）

设初始极距为 $\delta_0$，初始电容 $C_0 = \frac{\varepsilon S}{\delta_0}$。当动极板上移 $\Delta\delta$（间距缩小为 $\delta = \delta_0 - \Delta\delta$）时： $$\Delta C = \frac{\varepsilon S}{\delta_0 - \Delta\delta} - \frac{\varepsilon S}{\delta_0} = C_0 \frac{\Delta\delta}{\delta_0 - \Delta\delta} \implies \frac{\Delta C}{C_0} = \frac{\Delta\delta / \delta_0}{1 - \Delta\delta / \delta_0}$$

最小闭环

【最小闭环：单端变极距幂级数展开与非线性误差 $\gamma$ 推导（PPT P73–74）】 在小位移条件 $\frac{\Delta\delta}{\delta_0} \ll 1$ 下，利用无穷几何级数 $\frac{1}{1-u} = 1 + u + u^2 + u^3 + \cdots$ 展开： $$\frac{\Delta C}{C_0} = \frac{\Delta\delta}{\delta_0}\left[1 + \frac{\Delta\delta}{\delta_0} + \left(\frac{\Delta\delta}{\delta_0}\right)^2 + \cdots\right] = \frac{\Delta\delta}{\delta_0} + \left(\frac{\Delta\delta}{\delta_0}\right)^2 + \left(\frac{\Delta\delta}{\delta_0}\right)^3 + \cdots$$

  1. 线性近似与灵敏度：略去二次及以上高次项，得 $\frac{\Delta C}{C_0} \approx \frac{\Delta\delta}{\delta_0}$，故绝对灵敏度为： $$\boxed{K = \frac{\Delta C}{\Delta\delta} = \frac{C_0}{\delta_0} = \frac{\varepsilon S}{\delta_0^2} \propto \frac{1}{\delta_0^2}}$$ 极距 $\delta_0$ 越小，灵敏度按平方反比急剧提高（电容压力传感器常取 $\delta_0 = 0.1\sim 0.2\;\text{mm},\; C_0 = 20\sim 100\;\text{pF}$）。
  2. 相对非线性误差 $\gamma$（PPT P74）：以最主要的二次误差项与一次线性项之比衡量： $$\boxed{\gamma = \frac{(\Delta\delta/\delta_0)^2}{\Delta\delta/\delta_0}\times 100\% = \frac{\Delta\delta}{\delta_0}\times 100\%}$$ 工程权衡：$\delta_0$ 越小灵敏度越高，但同一位移 $\Delta\delta$ 造成的相对非线性误差 $\frac{\Delta\delta}{\delta_0}$ 也越大，故单端型只能工作在极小位移区间。

三、 差动变极距型：偶次项抵消与双倍灵敏度推导（P75–77）

两个定极板夹一个动极板构成差动电容，初始间隙均为 $\delta_0$，初始电容均为 $C_0 = \frac{\varepsilon S}{\delta_0}$。动极板上移 $\Delta\delta$ 后，$\delta_1 = \delta_0 - \Delta\delta$，$\delta_2 = \delta_0 + \Delta\delta$。

最小闭环

【最小闭环：差动变极距偶次非线性抵消证明（PPT P76–77）】

  1. 分别展开上下两电容（记 $u = \frac{\Delta\delta}{\delta_0}$）： $$C_1 = \frac{C_0}{1 - u} = C_0\big(1 + u + u^2 + u^3 + u^4 + \cdots\big)$$ $$C_2 = \frac{C_0}{1 + u} = C_0\big(1 - u + u^2 - u^3 + u^4 - \cdots\big)$$
  2. 作差 $\Delta C = C_1 - C_2$，所有偶次幂项（$u^2, u^4, \dots$）精确相互抵消： $$\frac{\Delta C}{C_0} = \frac{C_1 - C_2}{C_0} = 2\left(\frac{\Delta\delta}{\delta_0}\right) + 2\left(\frac{\Delta\delta}{\delta_0}\right)^3 + 2\left(\frac{\Delta\delta}{\delta_0}\right)^5 + \cdots$$
  3. 性能对比（P77）：
    • 灵敏度翻倍：$K_{\text{差动}} = \dfrac{2 C_0}{\delta_0} = \dfrac{2\varepsilon S}{\delta_0^2}$；
    • 非线性误差降为一阶平方量级（以三次项为主误差）： $$\boxed{\gamma_{\text{差动}} = \frac{2(\Delta\delta/\delta_0)^3}{2(\Delta\delta/\delta_0)}\times 100\% = \left(\frac{\Delta\delta}{\delta_0}\right)^2 \times 100\%}$$ (例如 $\Delta\delta/\delta_0 = 0.1$ 时，单端非线性误差为 $10\%$，差动式骤降至 $1\%$！同时对称结构还能补偿温湿度和寄生电容漂移。)

四、 电容高频等效电路与三类测量电桥（P80–83）

4.1 高频全参数等效电路（PPT P80）

  • 寄生电容 $C_p$ 降低灵敏度定量说明：传感器电容 $C_0$（通常仅几十 $\text{pF}$）与电缆/分布寄生电容 $C_p$（常达上百 $\text{pF}$）并联后，总电容变为 $C_{\text{总}} = C_0 + C_p + \Delta C$，导致实测相对变化率被稀释为 $\frac{\Delta C}{C_0 + C_p} \ll \frac{\Delta C}{C_0}$，灵敏度大幅下降且受电缆晃动干扰。

最小闭环

【最小闭环：纯电容交流电桥全区无近似绝对线性证明（PPT P82–83）】 设差动电容 $C_1 = \frac{\varepsilon_0\varepsilon_r S}{d_0 - x}$、$C_2 = \frac{\varepsilon_0\varepsilon_r S}{d_0 + x}$ 接入图 (b) 纯电容电桥左侧两臂，右侧两臂均为固定电容 $C$，激励电压为 $V_{\text{in}}$：

  1. 容抗分压求节点电压（注意 $Z_C = \frac{1}{j\omega C}$ 与电容成反比！）： $$V_A = \frac{\frac{1}{j\omega C_2}}{\frac{1}{j\omega C_1} + \frac{1}{j\omega C_2}} V_{\text{in}} = \frac{C_1}{C_1 + C_2}V_{\text{in}}, \qquad V_B = \frac{C}{C + C}V_{\text{in}} = \frac{1}{2}V_{\text{in}}$$
  2. 求差分输出 $V_o$ 并代入 $C_1, C_2$ 表达式： $$V_o = V_A - V_B = \left(\frac{C_1}{C_1 + C_2} - \frac{1}{2}\right)V_{\text{in}} = \frac{1}{2}\left(\frac{C_1 - C_2}{C_1 + C_2}\right)V_{\text{in}}$$ $$\frac{C_1 - C_2}{C_1 + C_2} = \frac{\dfrac{1}{d_0 - x} - \dfrac{1}{d_0 + x}}{\dfrac{1}{d_0 - x} + \dfrac{1}{d_0 + x}} = \frac{(d_0 + x) - (d_0 - x)}{(d_0 + x) + (d_0 - x)} = \frac{2x}{2d_0} = \frac{x}{d_0}$$
  3. 严格全区线性输出（不依赖 $x \ll d_0$ 小信号近似！）： $$\boxed{V_o = \frac{V_{\text{in}}}{2 d_0}\,x}$$

六、 物理公理与底层简单证明（补强短板）

6.1 高斯定理（Gauss's Law）4 行导出平板电容公式 $C = \frac{\varepsilon_0\varepsilon_r S}{\delta}$

  1. 高斯定理：穿过任意闭合曲面的电通量等于其包围自由电荷除以介电常数 $\oint_S \vec{E}\cdot d\vec{S} = \frac{Q}{\varepsilon_0\varepsilon_r}$。
  2. 求极板间匀强电场 $E$：对面积为 $S$、带电 $\pm Q$（面密度 $\sigma = Q/S$）的平行极板，取垂直穿过其中一块极板的柱形高斯面，电场仅从极板间一侧穿出： $$E\cdot S = \frac{Q}{\varepsilon_0\varepsilon_r} \implies E = \frac{Q}{\varepsilon_0\varepsilon_r S}$$
  3. 求两极板间电势差 $U$：沿间距 $\delta$ 积分： $$U = \int_0^\delta E\,dx = E\delta = \frac{Q\delta}{\varepsilon_0\varepsilon_r S}$$
  4. 电容定义 $C \equiv Q/U$： $$\boxed{C = \frac{Q}{U} = \frac{\varepsilon_0\varepsilon_r S}{\delta}}$$

6.2 为什么插入电介质（$\varepsilon_r > 1$）能增大电容量？

极板间插入电介质后，极板外电场 $\vec{E}_0$ 会使介质内分子电偶极矩取向排列，在介质上下表面感应出与极板符号相反的束缚极化电荷。这些束缚电荷产生一个反向的退极化电场 $\vec{E}'$，使板间净电场削弱为 $E = E_0 / \varepsilon_r$。在极板电荷 $Q$ 不变时，电势差 $U = E\delta$ 同步减小为原来的 $1/\varepsilon_r$，因此储电能力 $C = Q/U$ 放大为原来的 $\varepsilon_r$ 倍！

1.1 磁路欧姆定律（霍普金森定律）完整推导（PPT P3–4）

自感式传感器由线圈（匝数 $N$）、固定铁芯与可动衔铁组成，通过改变气隙厚度 $\delta$（变气隙型）或导磁截面积 $A$（变面积型）改变自感量 $L$。

最小闭环

【最小闭环：从霍普金森定律导出 $L = \dfrac{\mu_0 A N^2}{2\delta}$（PPT P4）】

  1. 物理公理出发点：由安培环路定理 $\oint \vec{H}\cdot d\vec{l} = N I$ 与 $B = \mu H,\; \Phi = B A$，沿闭合磁路积分得 $N I = \oint \frac{B}{\mu}dl = \Phi\left(\frac{l_{\text{铁}}}{\mu_0\mu_r A_{\text{铁}}} + \frac{2\delta}{\mu_0 A}\right) \equiv \Phi R_m$。
  2. 磁路全磁阻串联模型：磁力线穿过长度为 $l_{\text{铁}}$、相对磁导率为 $\mu_r$ 的铁芯，并往返两次穿过长度为 $\delta$、截面积为 $A$ 的空气隙（真空磁导率 $\mu_0 = 4\pi\times 10^{-7}\;\text{H/m}$），故总磁阻为串联之和： $$R_m = R_{m,\text{铁}} + R_{m,\text{气隙}} = \frac{l_{\text{铁}}}{\mu_0 \mu_r A_{\text{铁}}} + \frac{2\delta}{\mu_0 A}$$
  3. 铁芯磁阻可忽略条件：由于铁磁性材料 $\mu_r \sim 10^3\text{–}10^4 \gg 1$，即使气隙很小，气隙磁阻仍远大于铁芯磁阻，故 $R_m \approx \frac{2\delta}{\mu_0 A}$。
  4. 代入霍普金森定律与自感定义：由磁通势 $N I = \Phi R_m \implies \Phi = \frac{N I}{R_m}$，磁链 $\Psi = N\Phi = \frac{N^2 I}{R_m}$，得自感系数： $$\boxed{L \equiv \frac{\Psi}{I} = \frac{N^2}{R_m} = \frac{\mu_0 A N^2}{2\delta}}$$ (可见 $L$ 与气隙厚度 $\delta$ 成反比，与导磁面积 $A$ 成正比，与匝数平方 $N^2$ 成正比。)

1.2 单端 vs. 差动变气隙自感灵敏度与非线性对比（PPT P5–6）

  • 单端变气隙型：初始气隙 $\delta_0$ 时 $L_0 = \frac{\mu_0 A N^2}{2\delta_0}$。气隙减小 $\Delta\delta$（$\Delta\delta \ll \delta_0$）时做泰勒展开： $$\frac{\Delta L}{L_0} = \frac{\Delta\delta / \delta_0}{1 - \Delta\delta / \delta_0} = \frac{\Delta\delta}{\delta_0} + \left(\frac{\Delta\delta}{\delta_0}\right)^2 + \left(\frac{\Delta\delta}{\delta_0}\right)^3 + \cdots$$
    • 灵敏度 $K = \frac{\Delta L}{\Delta\delta} = \frac{L_0}{\delta_0} = \frac{\mu_0 A N^2}{2\delta_0^2}$；相对非线性误差 $\gamma = \frac{\Delta\delta}{\delta_0}\times 100\%$。
  • 差动变气隙型（P5–6）：两个完全相同的传感线圈共用一个中间衔铁（初始 $d_1 = d_2 = d_0,\; L_1 = L_2 = L_0$）。衔铁向线圈 1 移动 $\Delta d$ 后，$d_1 = d_0 - \Delta d,\; d_2 = d_0 + \Delta d$： $$\frac{\Delta L}{L_0} = \frac{L_1 - L_2}{L_0} = \frac{1}{1 - \Delta d/d_0} - \frac{1}{1 + \Delta d/d_0} = 2\left(\frac{\Delta d}{d_0}\right) + 2\left(\frac{\Delta d}{d_0}\right)^3 + \cdots$$
    • 偶次非线性项全部抵消，灵敏度提高一倍（$2\frac{L_0}{d_0}$），相对非线性误差降至 $\gamma_{\text{差动}} = \left(\frac{\Delta d}{d_0}\right)^2\times 100\%$。

最小闭环

【最小闭环：LVDT 次级开路及带负载 $R_L$ 时的复数输出推导】

  1. 初级回路电流（次级开路时）： $$\dot{I}_1 = \frac{\dot{U}_i}{R_1 + j\omega L_1}$$
  2. 次级反向串联感应电动势（PPT P11–12）：初级交变磁场在两半次级绕组中分别感应电动势 $\dot{E}_1 = -j\omega M_1 \dot{I}_1$ 与 $\dot{E}_2 = -j\omega M_2 \dot{I}_1$。因两绕组反向串联，总开路输出电压相量为： $$\dot{U}_0 = \dot{E}_1 - \dot{E}_2 = -j\omega(M_1 - M_2)\dot{I}_1 = \frac{-j\omega(M_1 - M_2)}{R_1 + j\omega L_1}\dot{U}_i$$
  3. 求输出有效值（取复数模，PPT P12 核心公式！）： $$\boxed{U_0 = \frac{\omega (M_1 - M_2)\,U_i}{\sqrt{R_1^2 + (\omega L_1)^2}}}$$
    • 高频极限：当 $\omega L_1 \gg R_1$ 时，简化为 $U_0 \approx \frac{M_1 - M_2}{L_1}U_i$，灵敏度与电源频率波动无关！
  4. 次级接入负载 $R_L$ 时的修正：设次级两绕组总自感为 $L_2$、总内阻为 $R_2$，则次级回路电流 $\dot{I}_2 = \frac{\dot{E}_1 - \dot{E}_2}{R_2 + j\omega L_2 + R_L}$，且次级电流会在初级产生互感反射电动势，因此实际测量中要求后级输入阻抗 $R_L \gg \sqrt{R_2^2 + (\omega L_2)^2}$ 以逼近空载线性特性。

3.3 输出特性曲线、零点残余电压及其消除（PPT P13–15）

  • 理想输出特性（P13）：铁芯位于中心零位时 $M_1 = M_2 \implies U_0 = 0$；向上/向下偏离对称移动时，$U_0$ 大小对称线性增加，但输出电压相位相差 $180^\circ$（必须通过相敏检波才能区分正负位移方向！）。
  • 零点残余电压（P13–14）：实际衔铁在机械零位时，输出并不为零（残留数 $\text{mV}$ 至数十 $\text{mV}$）。
    • 两大物理成因：
      1. 基波分量：两半次级绕组几何/匝数不完全对称、分布电容不等，导致 $\dot{E}_1$ 与 $\dot{E}_2$ 存在同相基波残差和$90^\circ$ 正交基波残差；
      2. 高次谐波分量：铁芯 $B\text{–}H$ 磁化曲线非线性与磁滞效应，使励磁电流产生奇次谐波（以三次谐波为主），不能在零位完全抵消。
    • 四大消除措施（P14）：
      1. 工艺上保证骨架对称、均匀绕线与铁芯材料一致；
      2. 后端串联相敏检波器（利用正交性抑制 $90^\circ$ 正交基波分量）+ 低通滤波器（滤除高次谐波）；
      3. 并联/串联阻容补偿网络调节相位与幅值平衡；
      4. 适当降低励磁电压避开铁芯磁饱和区。
  • 生物医学应用（P15）：差动变压器导管内血压传感器——导磁金属膜片同时作为感压膜片与差动电感的共用活动衔铁，直接置于导管尖端，避免液体耦合导管传压带来的二阶谐振失真。

四、 物理公理与底层简单证明（补强短板）

4.1 为什么磁压降几乎全落在空气隙上？（安培环路定理直觉）

把磁通 $\Phi$ 类比成电路里的电流 $I$，磁通势 $N I$ 类比成电池电动势 $U$，磁阻 $R_m = \frac{l}{\mu_0\mu_r A}$ 类比成电阻：

  • 铁芯的相对磁导率 $\mu_r \sim 10^3\text{–}10^4$（相当于“超良导体”），而空气隙 $\mu_r = 1$（相当于“高阻负载”）。
  • 串联电路中，总电压几乎全部降落在大电阻上；同理，串联闭合磁路中，哪怕空气隙 $\delta$ 只有毫米级、铁芯长几十厘米，气隙磁阻依然比铁芯磁阻大几个数量级，因此磁通 $\Phi = \frac{NI}{R_m}$ 几乎完全由气隙厚度 $\delta$ 唯一决定。

4.2 互感互易定理 $M_{12} = M_{21}$ 与感抗 $j\omega L$ 的相位来源

  1. 互感互易性：由诺依曼公式 $M_{12} = \frac{\mu_0}{4\pi}\oint_{C_1}\oint_{C_2}\frac{d\vec{l}_1\cdot d\vec{l}_2}{r_{12}}$，积分核对两线圈完全对称，故 $M_{12} \equiv M_{21} = M$。
  2. 为什么电感电压超前电流 $90^\circ$？：由法拉第定律 $u_L(t) = L\frac{di(t)}{dt}$。若正弦电流 $i(t) = I_m\sin(\omega t)$，求导得 $u_L(t) = \omega L I_m\cos(\omega t) = \omega L I_m\sin(\omega t + 90^\circ)$；用相量法表示即 $\dot{U}_L = j\omega L \dot{I}$（乘以虚数单位 $j = e^{j90^\circ}$ 即逆时针旋转 $90^\circ$）。

1.2 三种组态完整推导与对比（PPT P109–113）

最小闭环

【最小闭环：1/4 桥（广义臂比 $n$）、双臂三种接法与全桥严密推导】

  1. 1/4 桥（单臂工作，P109–110）：设初始平衡时臂比 $n = \frac{R_2}{R_1} = \frac{R_4}{R_3}$，仅 $R_1$ 变化 $\Delta R_1$： $$V_o = \left(\frac{n}{1+n} - \frac{n R_1}{R_1 + \Delta R_1 + n R_1}\right)V_i = \frac{n\cdot\frac{\Delta R_1}{R_1}}{(1+n)\left(1 + n + \frac{\Delta R_1}{R_1}\right)}V_i \approx \frac{n}{(1+n)^2}\frac{\Delta R_1}{R_1}V_i$$
    • 当 $n = 1$（等臂电桥 $R_1=R_2=R_3=R_4=R$）时，灵敏度函数 $f(n)=\frac{n}{(1+n)^2}$ 取最大值 $\frac{1}{4}$： $$V_o = \frac{1}{2\left(2 + \frac{\Delta R}{R}\right)}\frac{\Delta R}{R}V_i \approx \frac{1}{4}\frac{\Delta R}{R}V_i$$
    • PPT P110 例题：当 $\frac{\Delta R}{R} = 1\%$ 时，线性近似 $V_o = 2.5\times 10^{-3}V_i$，精确值 $V_o = \frac{0.01}{2\times 2.01}V_i = 2.488\times 10^{-3}V_i$，相对非线性误差约 $0.5\%$。

    • 接法①（差动半桥，相邻两臂反向变化 $R_1 = R+\Delta R,\; R_2 = R-\Delta R$）： $$V_o = \left(\frac{1}{2} - \frac{R - \Delta R}{2R}\right)V_i = \boxed{\frac{1}{2}\frac{\Delta R}{R}V_i}$$ 绝对线性（非线性误差为 $0$），灵敏度 $K_v = V_i / 2$（为 $1/4$ 桥的 $2$ 倍）。
    • 接法②（非差动半桥，相对两臂同向变化 $R_1 = R+\Delta R,\; R_4 = R+\Delta R$）： $$V_o = \left(\frac{R+\Delta R}{2R+\Delta R} - \frac{R}{2R+\Delta R}\right)V_i = \frac{\Delta R}{2R + \Delta R}V_i \approx \frac{1}{2}\frac{\Delta R}{R}V_i$$ 灵敏度虽也提高一倍，但分母仍含 $\Delta R$，存在非线性误差（与 $1/4$ 桥同阶）。
    • (警示：若将两个同向变化的应变片接在同侧相邻两臂，则 $V_o = 0$ 完全抵消无输出！)
  3. 差动全桥（P112）：一对相对桥臂为 $R+\Delta R$，另一对相对桥臂为 $R-\Delta R$： $$V_o = \left(\frac{R+\Delta R}{2R} - \frac{R-\Delta R}{2R}\right)V_i = \boxed{\frac{\Delta R}{R}V_i}$$ 绝对线性，灵敏度 $K_v = V_i$（为 $1/4$ 桥的 $4$ 倍），温度漂移共模抑制最优。

最小闭环

【最小闭环：运放有源线性化电路节点电压法严密推导】 左侧支路为两个固定电阻 $R$ 串联接直流基准 $V_B$，中点接理想运放同相端 $P$；右侧支路为固定电阻 $R$ 接 $V_B$、应变片 $R+\Delta R$ 接运放输出端 $V_{\text{OUT}}$，中点接反相端 $N$。

  1. 虚断求 $V_P$（$I_P = 0$）：$V_P = V_B \frac{R}{R + R} = \frac{V_B}{2}$。
  2. 虚短与 $N$ 点 KCL 方程（$V_N = V_P = \frac{V_B}{2}$，$I_N = 0$）： $$\frac{V_B - V_N}{R} + \frac{V_{\text{OUT}} - V_N}{R + \Delta R} = 0 \implies \frac{V_B}{2R} + \frac{V_{\text{OUT}} - \frac{V_B}{2}}{R + \Delta R} = 0$$
  3. 移项同乘 $(R + \Delta R)$： $$V_{\text{OUT}} - \frac{V_B}{2} = -\frac{V_B}{2R}(R + \Delta R) = -\frac{V_B}{2} - V_B\frac{\Delta R}{2R}$$
  4. 消去常数项 $-\frac{V_B}{2}$： $$\boxed{V_{\text{OUT}} = -\frac{V_B}{2}\frac{\Delta R}{R}}$$ 双重优势：①彻底消除分母中的 $\Delta R$，实现全区绝对线性；②灵敏度比普通 $1/4$ 桥提高 $1$ 倍！

三、 应变片温度误差与五大温度补偿技术（P116–124）

3.1 温度误差（热输出）双物理机制（PPT P116–117）

环境温度变化 $\Delta t$ 引起的虚假电阻相对变化为： $$\boxed{\left(\frac{\Delta R}{R}\right)_t = \left(\frac{\Delta R}{R}\right)_1 + \left(\frac{\Delta R}{R}\right)_2 = \alpha_t\Delta t + K(\beta_e - \beta_g)\Delta t}$$

  1. $\alpha_t\Delta t$：敏感栅材料的电阻温度系数效应；
  2. $K(\beta_e - \beta_g)\Delta t$：被测构件（线膨胀系数 $\beta_e$）与敏感栅（$\beta_g$）热膨胀失配引起的附加应变。

3.2 五大温度补偿方案（PPT P118–124，必考！）

补偿方案 核心原理与数学判据（PPT P118–124） 工程特点与局限
1. 单丝自补偿（P118） 选配合金使 $\alpha_t + K(\beta_e - \beta_g) = 0 \implies \alpha_t = K(\beta_g - \beta_e)$ 结构简单，但只能绑定一种特定 $\beta_e$ 的试件材料
2. 双丝组合自补偿（P119） 串联正温度系数丝（$R_a, \alpha_{tA}>0$）与负温度系数丝（$R_b, \alpha_{tB}<0$），令 $(\Delta R_a)_T = -(\Delta R_b)_T$，即：
$\left(\frac{R_a}{R_{\text{tot}}}\alpha_{tA}+\frac{R_b}{R_{\text{tot}}}\alpha_{tB}\right) - K\left(\frac{R_a}{R_{\text{tot}}}\beta_{gA}+\frac{R_b}{R_{\text{tot}}}\beta_{gB}\right) + K\beta_e = 0$		 并非数学上无关 $\beta_e$，而是通过调节 $R_a/R_b$ 裁剪长度比灵活适配不同材料 $\beta_e$
3. 电路（桥路）补偿法（P120–121） 工作片 $R_1$ 贴受力试件（$\Delta R_1 = \Delta R_\varepsilon + \Delta R_t$）；补偿片 $R_2$ 贴于同材料、同温度、不受力补偿块（$\Delta R_2 = \Delta R_t$），接入相邻两臂：
$V_o \approx \frac{V_i}{4R}[(\Delta R_\varepsilon + \Delta R_t) - \Delta R_t] = \frac{1}{4}K\varepsilon V_i$		 三大条件缺一不可：①同批号同阻值 $R_1, R_2$；②补偿块与试件同材料 $\beta_e$；③同温度环境
4. 热敏电阻分流补偿（P122） 供电端接入 $\text{NTC}$ 热敏电阻 $R_t$ 与分流电阻 $R_5$：温度升高时灵敏度 $K\downarrow$，同时 $R_t\downarrow$ 使电桥实际供电电压 $E'\uparrow$，在 $U_o = \frac{E'}{4}\frac{\Delta R_1}{R_1}$ 中相互抵消 专门补偿灵敏度温漂（前述 1–3 主要补偿零点温漂）
5. 远程三线制接法（P123–124） 将长引线电阻 $r$ 分别串入电源端与电桥两个相邻桥臂中（$R_1+r$ 与 $R_2+r$），引线电阻温漂 $\Delta r$ 在相邻桥臂作差时抵消 解决远程测温/测应变时长导线电阻温漂

四、 交流电桥、调制解调与相敏检波（P125–129）

4.1 交流电桥双重平衡条件与平衡调节（PPT P125–126）

令各臂复阻抗 $Z_i = |Z_i|\angle\varphi_i$，平衡条件 $Z_1 Z_4 = Z_2 Z_3$ 必须同时满足：

  1. 模平衡：$|Z_1|\cdot|Z_4| = |Z_2|\cdot|Z_3|$；
  2. 相位平衡：$\varphi_1 + \varphi_4 = \varphi_2 + \varphi_3$。
  • 平衡调节（P126）：因同时存在实部与虚部两个平衡条件，调节时需用可变电阻 $R_p$ 与可变电容 $C_p$ 协同调节直至输出严格归零。

4.2 调制解调与桥式相敏检波（PPT P127–129）

  • 为什么用交流电桥？（P127）：缓慢生理信号 $x(t)$ 调制在 $5\sim 10\;\text{kHz}$ 高频载波 $V_i(t)$ 上，经交流放大器放大后与放大器自身的低频直流漂移完全频率分离，彻底消除直流温漂。

  • 调幅（DSB-SC）数学本质：设缓慢生理信号引起相对阻抗变化 $x(t) = \frac{\Delta Z}{Z_0} = m\cos(\Omega t)$，高频载波为 $V_i(t) = V_m\sin(\omega_c t)$（$\omega_c \gg \Omega$），则交流半桥输出为抑制载波双边带调幅波： $$V_O(t) = \frac{1}{2}V_m m\cos(\Omega t)\sin(\omega_c t) = \frac{1}{4}V_m m\big[\sin(\omega_c + \Omega)t + \sin(\omega_c - \Omega)t\big]$$ 由于信号在 $\cos(\Omega t)$ 过零变号时发生 $180^\circ$ 相位翻转，普通包络检波器无法区分正负，必须用同步相敏检波！

  • 为什么必须用相敏检波？（P127–129）：当 $x(t)>0$ 时调幅输出 $V_O(t)$ 与载波 $V_i(t)$ 同相；当 $x(t)<0$ 时二者反相（相差 $180^\circ$）。普通二极管包络检波只能读出 $|x(t)|$ 而丢失正负号。

最小闭环

【最小闭环：桥式相敏检波四象限开关导通分析（PPT P129）】 在由 $D_1\sim D_4$ 组成的桥式相敏检波电路中，参考载波幅值必须远大于被测信号（$V_i \gg V_O$），故二极管通断完全由参考电压 $V_i(t)$ 极性控制：

  1. $V_i(t) > 0$ 半周：$D_1, D_4$ 导通、$D_2, D_3$ 截止 $\implies$ 若同相（$V_O > 0$）则输出 $V_A > 0$；若反相（$V_O < 0$）则输出 $V_A < 0$；
  2. $V_i(t) < 0$ 半周：$D_2, D_3$ 导通、$D_1, D_4$ 截止（相当于对 $V_O$ 乘以 $-1$ 翻转）$\implies$ 若 $V_O < 0$（原同相信号的负半周）翻转后仍输出 $V_A > 0$；若 $V_O > 0$（原反相信号的负半周）翻转后仍输出 $V_A < 0$！
  3. 结论：经低通滤波后，同相信号稳定输出正直流电压（$x>0$），反相信号稳定输出负直流电压（$x<0$），完美还原被测量的幅值与正负方向。

五、 物理公理与底层简单证明（补强短板）

5.1 理想运放“虚短”与“虚断”的物理来源

  1. 虚短（$V_+ \approx V_-$）：运算放大器的开环差模增益极大（$A_{OL} \sim 10^5\text{–}10^6$），且输出电压受电源轨限制（例如 $\pm 15\;\text{V}$）。当电路存在负反馈稳定工作时，净输入压差必须满足： $$V_+ - V_- = \frac{V_{\text{out}}}{A_{OL}} \sim \frac{15\;\text{V}}{10^6} = 15\;\mu\text{V} \approx 0 \implies V_+ \approx V_-$$ *(注意：没有负反馈时运放处于饱和比较器状态，不能使用虚短！)*
  2. 虚断（$I_+ \approx I_- \approx 0$）：运放输入级由高输入阻抗的场效应管（FET）或高 $\beta$ 差分对构成（输入电阻 $R_i \sim 10^9\text{–}10^{12}\;\Omega$），流入输入端的偏置电流仅 $\text{pA}\sim\text{nA}$ 级，在 KCL 节点方程中可严格忽略。

5.2 正弦函数正交性公理（相敏检波与交流电桥基石）

为什么同频参考波 $\sin(\omega t)$ 乘以 $90^\circ$ 正交干扰 $\cos(\omega t)$ 后经过低通滤波会严格归零？

  • 利用二倍角恒等式 $\sin(\omega t)\cos(\omega t) = \frac{1}{2}\sin(2\omega t)$。在一个完整周期 $T = \frac{2\pi}{\omega}$ 内积分，正半周与负半周面积严格相等抵消： $$\int_0^T \sin(\omega t)\cos(\omega t)\,dt = \frac{1}{2}\int_0^T \sin(2\omega t)\,dt = \boxed{0}$$
  • 而同相分量 $\sin(\omega t)\cdot\sin(\omega t) = \frac{1 - \cos(2\omega t)}{2}$ 在一个周期内积分平均值为 $\frac{1}{2} \neq 0$。这就是**相敏检波（锁相放大）**能够从强正交干扰中精确提取微弱同相信号的全部数学公理！

六、 真题靶向加厚：有载电桥精确解与大应变/温漂耦合（26-计4）

当真题明确给出**有限负载电阻 $R_L$（或内阻为 $R_A$ 的电流表）以及大应变（如 $\varepsilon = 5\%$）**时，严禁使用 $\Delta R \ll R$ 小信号近似，必须用戴维南等效求精确封闭解：

最小闭环

【最小闭环：1/4 等臂电桥接电流表（$R_A = R$）精确输出电流推导】 设四臂初始均为 $R$，仅工作臂变为 $R + \Delta R$，激励为理想电压源 $V_i$：

  1. 开路戴维南电压： $$V_{th} = V_i\left(\frac{1}{2} - \frac{R}{2R + \Delta R}\right) = \frac{V_i\Delta R}{2(2R + \Delta R)}$$
  2. 戴维南等效内阻： $$R_{th} = \big[R // (R + \Delta R)\big] + (R // R) = \frac{R(R + \Delta R)}{2R + \Delta R} + \frac{R}{2} = \frac{R(4R + 3\Delta R)}{2(2R + \Delta R)}$$
  3. 接电流表（$R_A = R$）输出电流： $$I_o = \frac{V_{th}}{R_{th} + R_A} = \frac{V_i\Delta R}{R(4R+3\Delta R) + 2R(2R+\Delta R)} = \boxed{\frac{V_i\Delta R}{R(8R + 5\Delta R)}}$$
  4. 大应变 + 温漂双因素耦合： 当应变片同时承受机械应变 $\varepsilon$（灵敏度 $k$）与温升 $\Delta T$（温度系数 $\alpha$）时，工作臂总电阻变化量为： $$\boxed{\Delta R_{\text{total}} = \Delta R_\varepsilon + \Delta R_T = R(k\varepsilon + \alpha\Delta T)}$$ 将 $\Delta R_{\text{total}}$ 直接代入上述精确封闭解即可，切勿在最后一步漏掉分母中的 $5\Delta R_{\text{total}}$。
