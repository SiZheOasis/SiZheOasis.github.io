一、 生物传感器概论与换能器映射（P6–11）

1.1 生物传感器的基本组成与核心定位（PPT P6–8, P11）

  • 定义：利用生物活性物质（如酶、抗体、微生物、核酸等）作为分子识别元件（感受器），选择性地识别并测定各种生物化学物质的传感器。
  • 基本链路（直接承接第 13–17 章化学传感器）： $$\text{被测生物化学量} \xrightarrow{\text{分子识别元件（敏感膜）}} \text{生物学反应信息} \xrightarrow{\text{换能器（第 6、7 章）}} \text{电信号} \xrightarrow{\text{放大器}} \text{输出}$$
  • 三大核心性能指标（PPT P9）：选择性（不误判其他干扰物）、灵敏度（检出限低）、稳定性（生物活性保持时间长）。
生物概念穿插

【生物概念穿插：什么是“生物活性物质”和“分子识别”？】

  • 分子识别（Molecular Recognition）：你可以把生物传感器想象成**“锁与钥匙”**。普通化学电极（比如 pH 玻璃电极）只能识别简单的小离子，遇到血液里成千上万种结构相似的有机物（葡萄糖、尿酸、抗坏血酸）就分不清了；而生物大分子具有精确的三维立体结构，只有特定形状和电荷分布的目标分子才能卡进它的结合位点。
  • 常见生物活性材料（PPT P9, P11）：
    • 酶（E, Enzyme）：具有催化功能的特殊蛋白质，能高效、专一地加速某一个化学反应。
    • 抗体（A, Antibody）：免疫系统产生的“Y”形球蛋白，能像磁铁一样死死锁住对应的抗原（Antigen）。
    • 原核生物细胞（PK）与真核生物细胞（EK）：原核生物（如细菌）没有细胞核，结构简单繁殖快；真核生物（如酵母、动植物细胞）有细胞核与线粒体等细胞器（Organelle），代谢网络更复杂。
    • 寡聚核苷酸（Oligonucleotide）：短链的 DNA 或 RNA（通常十几个到几十个碱基），靠碱基互补配对识别基因序列。

1.2 生物学反应信息与换能器映射总表（PPT P9，高频必背！）

生物识别本身不直接产生电压或电流，必须把它转成第 13–17 章学过的物理/化学变化，再交给对应的换能器：

生物学反应信息 对应的换能器选择（第 6、7 章） 典型工作原理
离子变化 离子选择电极（ISE） 生成/消耗特定离子 $\to$ 能斯特膜电位变化
电阻、电导变化 阻抗计、电导仪 反应生成带电离子 $\to$ 溶液电导率 $\sigma$ 改变
电荷密度变化 阻抗计、导纳、场效应晶体管（FET） 表面吸附带电生物分子 $\to$ 调制栅压/界面电容
质子变化（$\text{H}^+$） 场效应晶体管（ISFET / EnFET） 局部 $\text{pH}$ 改变 $\to$ 栅极表面电位变化
气体分压的变化 气敏电极（如 $\text{O}_2, \text{CO}_2, \text{NH}_3$ 电极） 反应消耗 $\text{O}_2$ 或产生 $\text{NH}_3/\text{CO}_2$

1.3 生物传感器的两大分类法（PPT P10）

  1. 按分子识别元件分类：酶传感器、免疫传感器、组织传感器、细胞传感器、核酸（基因）传感器、微生物传感器、分子印迹生物传感器。
  2. 按换能器器件分类：电化学生物传感器、半导体生物传感器、光生物传感器、热生物传感器、声波（压电）生物传感器、电导/阻抗生物传感器、悬臂梁生物传感器。

二、 酶与酶促反应动力学：米氏方程零跳步推导（P12–15）

2.1 酶的催化本质与三大特异性（PPT P13, P15）

  • 活化能与催化机理（PPT P13）：活化能是指一定温度下，$1\;\text{mol}$ 底物分子从初态转变到活化态（过渡态）所需的能量。酶通过与底物结合，降低反应的活化能（促进底物形成过渡态），从而将反应速率提高 $10^6\sim 10^{12}$ 倍，而酶本身在反应前后质量与化学性质不变。
  • 诱导契合假说（Induced Fit，PPT P15）：酶的活性中心并不是一块死板的刚性“铁锁孔”；当底物靠近时，酶分子的空间构象会发生微调，主动包裹并契合底物，同时使底物的化学键处于容易断裂的张力状态。
  • 酶的三大特异性（PPT P13）：
    1. 绝对特异性：只作用于一种特定结构的底物（如脲酶只催化尿素水解）。
    2. 相对特异性：作用于一类具有相同化学键或基团的底物（如酯酶可水解多种酯类）。
    3. 立体异构特异性：只作用于某一种旋光异构体或顺反异构体（如只识别 $\text{D}$-葡萄糖，不识别 $\text{L}$-葡萄糖）。
生物概念穿插

【生物概念穿插：底物、产物与辅助因子（Cofactor）】

  • 底物（Substrate, $S$）：被酶加工的原料分子（也就是传感器要测的待测物，比如血糖仪里的葡萄糖）。
  • 产物（Product, $P$）：底物经过酶催化转化后生成的新分子（比如葡萄糖酸和 $\text{H}_2\text{O}_2$）。
  • 辅助因子（Cofactor）：很多酶单靠蛋白质骨架还不能工作，必须绑定一个“小帮手”（比如金属离子 $\text{Mg}^{2+}$，或有机小分子辅酶如 $\text{FAD}$）才能完成电子转移或催化。

2.2 米氏方程（Michaelis-Menten Equation，PPT P14 核心必考！）

在酶浓度 $[E]_{\text{total}}$ 一定、其他条件不变时，酶促反应初速率 $V$ 与底物浓度 $[S]$ 呈矩形双曲线关系： $$\boxed{V = \frac{V_{\max}[S]}{K_m + [S]}}$$ 其中：

  • $V_{\max} = k_3 [E]_{\text{total}}$：酶被底物完全饱和时的最大反应速率，正比于总酶浓度 $[E]_{\text{total}}$。
  • $K_m = \frac{k_2 + k_3}{k_1}$：米氏常数，物理意义是反应速率达到最大反应速率一半（$V = \frac{1}{2}V_{\max}$）时的底物浓度。$K_m$ 越小，通常说明酶与底物的亲和力越高。
最小闭环

【最小闭环：米氏方程（稳态近似法）零跳步推导】

  1. 反应动力学模型（PPT P14）：酶 $E$ 与底物 $S$ 先可逆结合成酶-底物中间复合物 $ES$，随后 $ES$ 不可逆分解生成产物 $P$ 并释放游离酶 $E$： $$E + S \underset{k_2}{\overset{k_1}{\rightleftharpoons}} ES \xrightarrow{k_3} E + P$$
  2. 写出速率方程与物料守恒： 反应生成产物的速率为： $$V = \frac{d[P]}{dt} = k_3 [ES]$$ 中间复合物 $ES$ 的净生成速率为（生成项减两个消耗项）： $$\frac{d[ES]}{dt} = k_1 [E][S] - k_2 [ES] - k_3 [ES]$$ 设体系总酶浓度为 $[E]_{\text{total}}$，由于酶一部分游离（$[E]$），一部分被底物结合（$[ES]$），故物料守恒为： $$[E]_{\text{total}} = [E] + [ES] \implies [E] = [E]_{\text{total}} - [ES]$$
  3. 稳态近似（Steady-State Approximation）：当底物远过量（$[S] \gg [E]_{\text{total}}$）时，反应迅速进入稳态，中间复合物浓度保持恒定，即 $\frac{d[ES]}{dt} = 0$： $$k_1 ([E]_{\text{total}} - [ES])[S] - (k_2 + k_3)[ES] = 0$$ 展开并移项合并 $[ES]$： $$k_1 [E]_{\text{total}}[S] = \big(k_1[S] + k_2 + k_3\big)[ES]$$ 两边同除以 $k_1$，定义米氏常数 $K_m \equiv \frac{k_2 + k_3}{k_1}$： $$[ES] = \frac{[E]_{\text{total}}[S]}{K_m + [S]}$$
  4. 代入产物速率式：当所有酶都变成 $ES$ 时达到最大速率 $V_{\max} = k_3 [E]_{\text{total}}$，故： $$V = k_3 [ES] = \frac{k_3 [E]_{\text{total}}[S]}{K_m + [S]} = \boxed{\frac{V_{\max}[S]}{K_m + [S]}}$$
  5. 两大极限与传感线性区（考研分析题关键）：
    • 低底物浓度（$[S] \ll K_m$）：$V \approx \frac{V_{\max}}{K_m}[S]$，反应速率与底物浓度呈线性关系（一级反应）——这是生物传感器定量测量的理想线性工作区！
    • 高底物浓度（$[S] \gg K_m$）：$V \approx V_{\max} = k_3 [E]_{\text{total}}$，此时底物已使酶饱和，速率与 $[S]$ 无关（零级反应），传感器出现响应饱和（上平台）。
  • Lineweaver-Burk 双倒数线性化（实验测 $K_m$ 与 $V_{\max}$）：对米氏方程两边取倒数： $$\frac{1}{V} = \frac{K_m}{V_{\max}}\cdot\frac{1}{[S]} + \frac{1}{V_{\max}}$$ 以 $\frac{1}{V}$ 对 $\frac{1}{[S]}$ 作图得一条直线：斜率为 $\frac{K_m}{V_{\max}}$，纵轴截距为 $\frac{1}{V_{\max}}$，横轴截距为 $-\frac{1}{K_m}$。

2.3 影响酶促反应速率的五大因素（PPT P15）

  1. 酶浓度：底物饱和时，$V_{\max}$ 与 $[E]_{\text{total}}$ 呈直线关系。
  2. 温度：具有双重影响——升温一方面加快分子热运动使反应加速，另一方面高温破坏酶蛋白质的空间构象导致热变性失活，故存在一个最适温度（呈钟形曲线）。
  3. $\text{pH}$：通过改变酶活性中心及底物分子的解离（带电）状态影响结合与催化，存在最适 $\text{pH}$。
  4. 抑制剂与激活剂：抑制剂可逆或不可逆地降低酶活性（如重金属离子使酶失活）；激活剂（如 $\text{Mg}^{2+}$）提高酶活性。

三、 酶的固定化技术与微环境调控（P16–19）

游离在水里的酶用一次就流失了，还容易变性。为了做成可重复使用的固体敏感膜，必须进行酶的固定化。

3.1 四大经典酶固定化方法（PPT P16）

方法 物理/化学本质 优点 缺点
1. 吸附法 靠范德华力、静电引力或疏水作用将酶物理吸附在载体表面 条件温和，酶活性保留高，操作简单 结合力弱，酶易受 $\text{pH}$、离子强度变化而脱落
2. 交联法 用双功能试剂（如戊二醛）把酶分子之间或酶与载体交联成网状 结合牢固，不易脱落 化学反应剧烈，易破坏酶活性中心，活力损失大
3. 共价连接法 酶表面非必需基团与载体表面官能团形成稳定的共价键 结合极牢固，耐受性好 修饰位点控制不好会降低酶活性，工艺较复杂
4. 包埋法 将酶包裹在多孔高分子凝胶（如海藻酸钠水凝胶）或半透膜微囊内 酶不直接参与化学成键，保持天然构象 存在扩散传质阻力（底物需钻进凝胶才能遇到酶）

3.2 纳米限域微环境调控（PPT P17–19，戴小川课题组前沿案例）

  • 限域微环境三大优势（PPT P17，Nano Lett. 2019）：
    1. 降低局域介电常数（Mitigate dielectrics）$\to$ 抑制溶液离子屏蔽效应（Suppress screening，对 FET 传感器极其关键）；
    2. 调节孔隙率（Adjust porosity）$\to$ 像筛子一样阻挡大分子杂质非特异性吸附；
    3. 共聚固定（Co-polymerization）$\to$ 显著延长生物受体的使用寿命。
  • 海藻酸钠水凝胶固定化核酸外切酶（Exo III，PPT P19）：虽然因为凝胶传质阻力导致酶催化反应速率略有下降，但酶的抗失活稳定性显著提高。

四、 电流型酶电极：第一代与第二代葡萄糖传感器（P20–24）

4.1 葡萄糖氧化酶（GOD）催化反应与三大检测途径（PPT P20）

在葡萄糖氧化酶（GOD）催化下，葡萄糖被溶解氧氧化为葡萄糖酸（内酯 $\text{C}_6\text{H}_{10}\text{O}_6$ 水解即葡萄糖酸）和过氧化氢： $$\text{C}_6\text{H}_{12}\text{O}_6 + \text{O}_2 \xrightarrow{\text{GOD}} \text{H}_2\text{O}_2 + \text{C}_6\text{H}_{10}\text{O}_6$$ 由此衍生出三种测量途径：

  1. 测生成的葡萄糖酸（引起局部 $\text{pH}$ 下降 $\to$ 电位型/pH电极）；
  2. 测消耗的 $\text{O}_2$（第一代酶电极——氧电极法）；
  3. 测生成的$\text{H}_2\text{O}_2$（第一代酶电极——过氧化氢电极法）。

4.2 第一代电流型酶电极：$\text{O}_2$ 电极 vs. $\text{H}_2\text{O}_2$ 电极（PPT P21–22）

$2\text{H}^+ + \text{O}_2 + 2e^- \to \text{H}_2\text{O}_2$
$2\text{H}^+ + \text{H}_2\text{O}_2 + 2e^- \to 2\text{H}_2\text{O}$		 葡萄糖越多，耗氧越多，阴极还原电流下降；
致命缺点：受样品中溶解氧浓度波动的严重干扰。
过氧化氢电极法（P22） 阳极：$\text{Pt}$
阴极：$\text{AgCl/Ag}$		 $\text{H}_2\text{O}_2$ 在铂阳极被氧化：
$\text{H}_2\text{O}_2 \to \text{O}_2 + 2\text{H}^+ + 2e^-$
(注：PPT P22 简写作 $\text{H}_2\text{O}_2 \to \text{H}_2\text{O}+2e^-+\text{O}_2$)		 葡萄糖越多，$\text{H}_2\text{O}_2$ 越多，阳极氧化电流增大；
缺点：需较高氧化电位（约 $+0.6\;\text{V}$），易将血液中的抗坏血酸、尿酸等干扰物一并氧化，且仍依赖 $\text{O}_2$ 参与第一步反应。

4.3 第二代电流型酶电极：电子媒介体（Mediator，PPT P23–24）

为了彻底摆脱对溶解氧（$\text{O}_2$）的依赖，并降低工作电位、消除干扰，引入人工电子媒介体 $M_{\text{ox}}/M_{\text{red}}$（如二茂铁及其衍生物、苯醌、铁氰化物、细胞色素、辅酶等）来直接搬运电子！

生物概念穿插

【生物概念穿插：GOD-FAD 与电子媒介体的“接力赛”】 葡萄糖氧化酶（GOD）内部深处藏着一个负责接收电子的辅酶叫 FAD（黄素腺嘌呤二核苷酸）。

  • 在第一代电极中，GOD 抢走葡萄糖的电子变成 $\text{GOD–FADH}_2$ 后，必须等路过的 $\text{O}_2$ 把电子接走才能恢复原状。
  • 在第二代电极中，我们派出一群小巧灵活的“电子快递员”——氧化态媒介体 $M_{\text{ox}}$，钻进酶分子内部接走电子变成 $M_{\text{red}}$，再跑到电极表面把电子交给电极。

第二代酶电极三步反应链（PPT P23 必背！）： $$\begin{aligned} \text{步骤 1（酶催化氧化葡萄糖）：}\quad & \text{C}_6\text{H}_{12}\text{O}_6 + \text{GOD–FAD} \longrightarrow \text{C}_6\text{H}_{10}\text{O}_6 + \text{GOD–FADH}_2 \\ \text{步骤 2（酶层中电子交接）：}\quad & \text{GOD–FADH}_2 + 2M_{\text{ox}} \longrightarrow \text{GOD–FAD} + 2M_{\text{red}} + 2\text{H}^+ \\ \text{步骤 3（电极表面再生与测流）：}\quad & 2M_{\text{red}} \longrightarrow 2M_{\text{ox}} + 2e^- \end{aligned}$$

最小闭环

【最小闭环：为什么第二代电极能摆脱溶解氧干扰且抗血液干扰？】

  1. 氧无关性：只要媒介体 $M_{\text{ox}}$ 浓度足够且与 $\text{GOD–FADH}_2$ 的反应速率常数远大于 $\text{O}_2$，电子全部走 $M_{\text{ox}}$ 通道，即使血液缺氧也不会产生误差。
  2. 低工作电位抗干扰：二茂铁衍生物的氧化电位仅约 $+0.1\sim +0.3\;\text{V}$，远低于 $\text{H}_2\text{O}_2$ 所需的 $+0.6\;\text{V}$，因此不会把血液中的维生素 C（抗坏血酸）或尿酸一起氧化产生假电流。

5.2 酶场效应管传感器（EnFET / BioFET，PPT P26–31）

直接结合第 17-1 节的 ISFET！生物反应改变局部 $\text{pH}$ 或表面电荷密度 $\to$ 调制栅极阈值电压 $V_T$ $\to$ 改变漏源电流 $I_D$。

  • 两大优势（PPT P26）：体积微米级、易阵列化（是生物芯片和生物计算机的基础），适合微量样品和活体内测定。
  • 两种结构形式（PPT P27）：
    1. 分离型（Extended-gate）：生物反应系统与 MOSFET 各自为独立组件（中间用导线连接），保护昂贵的晶体管不被生物溶液腐蚀。
    2. 结合型：直接由生物功能材料（如聚合物包埋酶膜，PPT P28）取代 FET 的金属栅极。
  • 典型实例（PPT P30–31）：
    • 乙酰胆碱酯酶 / 青霉素酶 EnFET：青霉素酶催化青霉素水解产生酸（$\text{H}^+$ 增多，$\text{pH}$ 下降）；乙酰胆碱酯酶催化乙酰胆碱水解产生乙酸（$\text{H}^+$ 增多）。
    • 乐高式自由重组（PPT P31）：同一套 ISFET 换能器底座，只要换上不同的酶膜（如①青霉素酶、②脲酶），就能像乐高积木一样组装出测不同底物的传感器！

六、 酶热敏电阻与光纤酶传感器（P32–39）

6.1 酶热敏电阻传感器（PPT P32）

  • 结构：固定化酶柱 + NTC 热敏电阻（回顾 17-2 节：$R_T \approx R_0 e^{B(1/T - 1/T_0)}$）。
  • 原理：酶促反应伴随反应焓变 $\Delta H$（通常为放热反应）。在绝热体系中，反应释放的热量 $Q = -n\Delta H$ 引起体系温度微小变化 $\Delta T = \frac{Q}{C_p} \propto [\text{底物}]$，经高灵敏度热敏电阻转化为电阻/电桥电压变化。

6.2 光纤酶传感器（PPT P33–38）

  • 三大组成（PPT P33）：光纤（高锟 2009 年诺贝尔物理学奖）+ 生物敏感膜（探头） + 光电换能器。

  • 三种探头结构（PPT P33）：(a) 双束光纤（一束送激发光、一束收信号光）；(b) 单束光纤，生物敏感膜在端部；(c) 单束光纤，生物敏感膜与光纤包层为一体（利用消逝波）。

  • 四大核心优势（PPT P34）：①抗干扰能力强（不受电磁场干扰）；②不用参比电极，极易微型化；③可实现远距离遥测；④响应快、灵敏度高。

  • 五大光学传感模式与 PPT 实例（PPT P35–38，常考选择/简答！）：

一、 免疫学反应基础与三明治/竞争法（P40–45）

1.1 免疫传感器的基本概念与分类（PPT P40–41）

  • 定义：利用抗体对相应抗原的特异性识别与结合功能，将抗体（或抗原）固定化膜与信号转换器组合，用来测定抗原（或抗体）浓度的亲和型生物传感器。
  • 性能优劣决定因素：抗体与待测物结合的选择性和亲和力。
  • 两大分类方式（PPT P40）：
    1. 按是否标记：非标记免疫传感器（直接测结合引起的质量/折射率/电荷变化，如 QCM、SPR、FET） vs. 标记免疫传感器（需要酶、荧光或同位素做信号放大）。
    2. 按信号转换过程：直接型 vs. 间接型。
生物概念穿插

【生物概念穿插：抗原、抗体、一抗/二抗与 HRP】

  • 抗原（Antigen, $\text{Ag}$）：能刺激机体产生免疫反应的外来物质（如病毒蛋白、细菌表面分子、肿瘤标志物），也是传感器常要检测的待测目标。
  • 抗体（Antibody, $\text{Ab}$）：机体被抗原刺激后产生的“Y”形免疫球蛋白。Y 形的两条手臂尖端专门抓捕特定抗原，而柄端（Fc 段）结构相对保守。
  • 一抗（Primary Antibody）与二抗（Secondary Antibody，PPT P42）：
    • 一抗是直接固定在传感器表面、用来“抓捕”待测抗原的抗体；
    • 二抗是带有信号标签（如酶、荧光染料）的抗体，用来识别已被一抗抓住的抗原（或者识别一抗本身），负责“报告信号”。
  • 辣根过氧化物酶（HRP，PPT P44）：最常用的酶标记物！它能高效催化 $\text{H}_2\text{O}_2$ 氧化底物产生颜色变化或电流信号，把“抓到一个抗原”放大成几百万个产物分子的信号。
  • 牛血清白蛋白（BSA）封端（Blocking，PPT P56）：固定好抗体后，传感器表面还有裸露的空隙，如果直接加血液样本，杂蛋白会乱粘上去产生假信号。用 BSA（一种惰性小蛋白）把空隙提前填满，就叫封端/封闭。

1.2 两大核心免疫分析模式：三明治法 vs. 竞争法（PPT P42，必考对比！）

对比维度 三明治分析（夹心法，Sandwich） 竞争性分析（Competitive）
结构流程 固定化一抗 $\to$ 结合待测抗原 $\to$ 再结合标记二抗（形成“抗体-抗原-抗体”夹心） 固定化一抗数量有限，待测无标记抗原与外加的标记抗原共同竞争这批一抗位点
信号与浓度关系 待测抗原越多，抓到的标记二抗越多 $\implies$ 信号 $S \propto [\text{Ag}]$（成正比） 待测抗原越多，抢走越多一抗，标记抗原结合越少 $\implies$ 信号 $S \propto \dfrac{1}{[\text{Ag}]}$（成反比）

最小闭环

【最小闭环：质量作用定律解释三明治法与竞争法信号规律】 设抗原-抗体结合平衡常数为 $K_a = \frac{[\text{Ag}\cdot\text{Ab}]}{[\text{Ag}][\text{Ab}]}$：

  1. 三明治法：表面一抗总量 $[\text{Ab}_1]_{\text{tot}}$ 过量且固定。待测抗原 $[\text{Ag}]$ 结合上去的复合物浓度为 $[\text{Ab}_1\cdot\text{Ag}] \propto [\text{Ag}]$；随后加入过量标记二抗 $\text{Ab}_2^*$，每个复合物对应结合一个 $\text{Ab}_2^*$，故测得总标记信号 $S \propto [\text{Ab}_1\cdot\text{Ag}\cdot\text{Ab}_2^*] \propto [\text{Ag}]$。
  2. 竞争法：表面一抗总位点数 $N_0$ 有限且恒定。溶液中同时存在待测抗原 $[\text{Ag}]$ 与固定浓度的标记抗原 $[\text{Ag}^*]$，二者按浓度比例竞争 $N_0$ 个位点，标记抗原占据的比例为 $\theta^* = \frac{[\text{Ag}^*]}{[\text{Ag}^*] + [\text{Ag}] + 1/K_a}$。显然，$[\text{Ag}]$ 越大，分母越大，$\theta^*$ 越小，故信号 $S \propto \theta^*$ 与 $[\text{Ag}]$ 呈反比单调递减！

1.3 五大免疫分析方法（PPT P43–45）

  1. 沉淀法：抗原抗体结合形成肉眼可见的大分子网状沉淀（灵敏度较低）。
  2. 放射免疫测定法（RIA）：用放射性同位素（如 $^{125}\text{I}$）标记，灵敏度极高但有辐射危害。
  3. 免疫荧光测定法（FIA）：用荧光染料标记，通过荧光强度定量。
  4. 酶联免疫测定法（ELISA，PPT P44–45）：将抗原/抗体固定在固相载体上，用 HRP 等酶标记二抗，加入底物后发生显色或电化学反应（兼具特异性与酶催化放大）。
  5. 非标记法：不引入外源标记物，直接利用 SPR、QCM、ISFET 等物理换能器实时监测结合过程。

二、 电化学与半导体型免疫传感器（P46–49）

2.1 电位型免疫传感器（PPT P46）

  • 链路：$\text{抗体固定在载体膜上} \to \text{抗原-抗体特异性结合} \to \text{膜内离子载体性质/表面电荷分布改变} \to \text{电极膜电位变化 } \Delta E \to \text{测得抗原/抗体浓度}$。
  • 两种典型构造（PPT P46 图 6.2.8）：(a) 固定抗体于离子载体膜表面（含内充 $\text{Ag/AgCl}$ 参比与内电解液）；(b) 直接固定抗体于金属电极表面（无内电解液，外配 $\text{Ag/AgCl}$ 参比电极测定膜/金属界面电位差）。

2.2 电流型（酶）免疫传感器（PPT P47–48）

将 ELISA 的酶标记放大与**电流型电极（如氧电极、$\text{H}_2\text{O}_2$ 电极）**结合：

  • 竞争法（P47）：用酶标抗原与待测抗原竞争氧电极上的固定化抗体 $\to$ 酶催化氧化还原反应 $\to$ 产生或消耗电活性物质 $\to$ 电流变化（与待测抗原浓度成反比）。
  • 夹心法（P48）：
    1. 样品中的抗原与电极表面的固定化抗体结合；
    2. 加入过氧化物酶（如 HRP）标记的二抗，形成夹心结构；
    3. 在溶液中加入足量 $\text{H}_2\text{O}_2$，附着在电极上的过氧化物酶催化 $\text{H}_2\text{O}_2$ 还原/氧化，产生与抗原数量成正比的电流信号。

2.3 半导体型免疫传感器（ImmunoFET，PPT P49）

  • 结构：在 ISFET 的栅极绝缘层（或敏感膜）表面直接固定抗体/抗原，取消传统金属栅，由参比电极 + 被测溶液 + 敏感膜构成栅极回路。
  • 原理：免疫复合物（带净电荷）在界面结合 $\to$ 改变固液界面的表面电位与跨膜电场 $\to$ 调制沟道载流子浓度 $\to$ 改变漏源电流 $I_D$（或阈值电压 $V_T$）。
  • 关键物理限制（与 17-1 / 18 节呼应）：溶液中存在大量背景离子会形成双电层屏蔽（德拜长度 $\lambda_D$ 仅约 $0.7\sim 1\;\text{nm}$），抗体分子（约 $10\;\text{nm}$）过大往往会超出 $\lambda_D$ 范围，因此后来发展出纳米限域微环境和小尺寸核酸适配体（见第 21 章）来突破屏蔽限制。

三、 表面等离子体共振（SPR）物理推导与光学免疫传感（P50–54）

3.1 SPR 物理现象（PPT P50）

当偏振电磁波从高折射率棱镜一侧以一定角度 $\theta$ 射向镀有超薄金属膜（如 $\text{Au}$ 膜）的界面时，在全反射条件下，反射光谱在某一特定入射角 $\theta_{sp}$ 处会出现反射光强急剧下降的明显暗带（共振吸收峰）；且金属膜外侧样品的折射率 $n$ 变大时，共振角 $\theta_{sp}$ 会发生偏移。

3.2 波矢匹配条件与公式推导（PPT P51–53，必背核心公式！）

在棱镜/金属膜/样品三层结构中（$x$ 轴平行于金属膜表面）：

  1. 消逝波（Evanescent Wave）在 $x$ 轴方向的波矢分量： $$K_{ev} = \frac{\omega}{c}\sqrt{\varepsilon_0}\sin\theta$$ 其中 $\omega$ 为入射光角频率，$c$ 为真空光速，$\varepsilon_0$ 为棱镜（支持体）的介电常数，$\theta$ 为入射角。
  2. 金属膜表面的表面等离子体波（SPW）在 $x$ 轴方向的波矢分量： $$K_{sp} \approx \frac{\omega}{c}\sqrt{\frac{\varepsilon_1 \varepsilon_2}{\varepsilon_1 + \varepsilon_2}}$$ 其中 $\varepsilon_1$ 为金属膜介电常数，$\varepsilon_2$ 为金属膜表面样品介质的介电常数。
最小闭环

【最小闭环：从 Maxwell 边界条件到 SPR 共振角 $\sin\theta_{sp}$ 推导】

  1. 为何出现表面等离子体波 $K_{sp}$？ 在金属（$\varepsilon_1 < 0$）与电介质样品（$\varepsilon_2 > 0$）的分界面上，TM 偏振（磁场平行于界面）电磁波满足切向电场与磁场连续边界条件，解得色散关系为： $$K_{sp} = \frac{\omega}{c}\sqrt{\frac{\varepsilon_1 \varepsilon_2}{\varepsilon_1 + \varepsilon_2}}$$ 注意当 $|\varepsilon_1| > \varepsilon_2$ 且 $\varepsilon_1 < 0$ 时，$\frac{\varepsilon_1 \varepsilon_2}{\varepsilon_1 + \varepsilon_2} > \varepsilon_2$，故在空气或水中直接用光照射金属表面无法激发（因光的平行波矢 $\frac{\omega}{c}\sqrt{\varepsilon_2}\sin\theta < K_{sp}$）。
  2. 为何需要高折射率棱镜产生消逝波？ 利用高介电常数棱镜（$\varepsilon_0 > \varepsilon_2$）在全反射时产生沿界面传播的消逝波，其平行波矢被放大了 $\sqrt{\varepsilon_0}$ 倍：$K_{ev} = \frac{\omega}{c}\sqrt{\varepsilon_0}\sin\theta$。
  3. 能量与动量匹配（共振条件）：当调节入射角 $\theta$ 使得沿界面方向的动量匹配（$K_{ev} = K_{sp}$）时： $$\frac{\omega}{c}\sqrt{\varepsilon_0}\sin\theta_{sp} = \frac{\omega}{c}\sqrt{\frac{\varepsilon_1\varepsilon_2}{\varepsilon_1+\varepsilon_2}} \implies \boxed{\sin\theta_{sp} = \sqrt{\frac{\varepsilon_1\varepsilon_2}{\varepsilon_0(\varepsilon_1+\varepsilon_2)}} = f(\omega, \varepsilon_0, \varepsilon_1, \varepsilon_2)}$$ 此时入射光能量剧烈耦合进金属表面自由电子的集体振荡（等离子体激元），转化为热能消耗，导致反射光强度急剧下降至最小值！
  4. 从物理量到生物量定量的映射链（PPT P52）： $$\sin\theta_{sp} = f(\omega, \varepsilon_0, \varepsilon_1, \varepsilon_2) \xrightarrow{\omega \to \lambda,\;\varepsilon_2 = n^2} \sin\theta_{sp} = f(\lambda, n) \xrightarrow{n \text{ 正比于表面质量 } m} \sin\theta_{sp} = f(\lambda, m)$$
  1. 为什么样品折射率 $n$ 增大时共振角 $\theta_{sp}$ 总是向右（大角度）移动？（PPT P50 曲线 A $\to$ B 证明）： 将 $\varepsilon_2 = n^2 > 0$（且金属膜满足 $\varepsilon_1 < -\varepsilon_2 < 0$）代入共振条件并对 $\varepsilon_2$ 求导： $$\frac{d(\sin^2\theta_{sp})}{d\varepsilon_2} = \frac{1}{\varepsilon_0}\cdot\frac{\varepsilon_1(\varepsilon_1+\varepsilon_2) - \varepsilon_1\varepsilon_2}{(\varepsilon_1+\varepsilon_2)^2} = \frac{\varepsilon_1^2}{\varepsilon_0(\varepsilon_1+\varepsilon_2)^2} > 0$$ 导数严格大于零！故样品折射率 $n$（或结合生物分子质量 $m$）增大 $\implies \varepsilon_2$ 增大 $\implies \theta_{sp}$ 必然增大（曲线暗带由 A 向右移至 B）。

3.3 SPR 影响因素与免疫传感应用（PPT P53–54）

  • 影响 $\theta_{sp}$ 的四大因素（P53）：①入射光波长 $\lambda$；②金属膜的厚度；③玻璃（棱镜）与金属的介电常数；④界面两侧介质的折射系数（反映介质浓度变化、表面介质均匀度及厚度变化）。
  • SPR 免疫传感器（P54）：将抗体固定在 SPR 金膜表面 $\to$ 通入抗原并发生特异性结合 $\to$ 表面质量与局部折射率 $n$ 增大 $\to$ 共振角偏移 $\Delta\theta_{sp}$ 增大 $\to$ $\Delta\theta_{sp}$ 近似线性正比于所结合抗原的浓度/表面质量（全程无需任何标记，可实时监测结合/解离动力学！）。

一、 微生物传感器概论与两大反应机能（P58–60）

1.1 为什么已经有了酶传感器，还要做微生物传感器？（PPT P58）

  1. 多酶级联反应优势：微生物细胞内部天然自带一整套完整的酶系，对于需要多种酶协同才能完成的复杂反应，微生物传感器可以直接使用，无需分别提纯和固定化好几种酶。
  2. 解决“无法分离的酶”难题：有些酶一旦离开细胞膜环境就会立刻失活，至今无法分离纯化，此时只能直接用含有该酶的完整细菌/真菌组成传感器。
  3. 成本低、寿命长：细胞自带自我修复机制，比昂贵的纯化酶更耐受恶劣环境（如工业废水）。
  • 按信号转换器分类（PPT P58）：电化学微生物传感器、光微生物传感器、燃料电池型微生物传感器、热敏电阻型微生物传感器、压电微生物传感器等。

1.2 微生物传感器的两大反应机能（PPT P59–60，必考分类！）

生物概念穿插

【生物概念穿插：需氧 vs. 厌氧、呼吸机能 vs. 代谢机能】

  • 需氧型微生物（Aerobic）：和人类一样，需要吸收氧气（$\text{O}_2$）来“烧掉”有机物（如葡萄糖、废水中的有机污染物）获取能量，过程叫呼吸作用；有机物越多，它耗氧越快。
  • 厌氧型微生物（Anaerobic）：不需要氧气就能分解有机物，或者在无氧发酵时把有机物拆解成小分子代谢废物（如 $\text{NH}_3$、$\text{CO}_2$、有机酸）。

1. 呼吸机能型（P59） 需氧型微生物 与有机底物作用时，细胞呼吸活性提高，耗氧量增大 用氧电极（Clark 电极）测定呼吸活性变化引起的扩散极限电流下降值 $\to$ 间接测定有机物浓度

二、 电流型微生物传感器与 BOD 检测闭环（P61–62）

2.1 什么是 BOD？（PPT P61）

  • BOD（Biochemical Oxygen Demand，生化需氧量）：指水体中微生物分解有机污染物所消耗的溶解氧的量，是监测水体被有机物污染状况的最常用指标。
  • 传统 $\text{BOD}_5$ 法痛点：传统国标方法需要把水样在 $20^\circ\text{C}$ 避光培养 5 天才能测出耗氧量；而 BOD 微生物传感器只需 15～20 分钟就能给出结果！

2.2 BOD 微生物传感器结构与工作流程（PPT P61–62）

  • 7 层核心结构（PPT P61 结构图）：①电解液、②O 形环、③阴极（$\text{Pt}$）、④聚四氟乙烯膜（透 $\text{O}_2$ 膜，即 Clark 氧电极内膜）、⑤微生物膜（固定有假单胞菌、活性污泥菌、丝孢酵母菌、枯草芽孢杆菌等）、⑥尼龙网（保护支撑）、⑦阳极（$\text{Ag/AgCl}$）。
  • 流路系统（PPT P62）：缓冲液、清洗液、待测样品与标准溶液通过蠕动泵和空气泵（保证恒定溶解氧）进入恒温箱内的微生物传感器，由记录仪记录电流-时间响应曲线。
生物概念穿插

【生物概念穿插：内源呼吸 vs. 外源呼吸（PPT P62 核心考点）】

  • 内源呼吸（Endogenous Respiration）：当传感器放在**纯缓冲液（没有外部有机物食物）**中时，微生物只能靠消耗自己体内储存的营养勉强维持生命，耗氧速率很低且恒定。
  • 外源呼吸（Exogenous Respiration）：一旦通入含有有机物的待测水样，微生物瞬间吃到外界食物，呼吸代谢骤然加快，耗氧量剧增！
最小闭环

【最小闭环：为什么 BOD 越大，传感器输出电流反而“下降”得越多？】

  1. 基线稳态（内源呼吸平衡）：传感器置于充氧缓冲液中，溶解氧向氧电极阴极扩散的通量 $J_{\text{diff}}$ 减去微生物内源呼吸的恒定耗氧速率 $R_{\text{endo}}$，使到达铂阴极的氧通量恒定，输出稳态基线电流 $I_0$（如图 PPT P61 右侧约 $48\;\mu\text{A}$ 平台）： $$I_0 = n F A \big(J_{\text{diff}} - R_{\text{endo}}\big)$$
    • (注：由第 13-2 节 Fick 第一定律，穿过聚四氟乙烯透氧膜到达铂阴极的稳态氧扩散通量 $J_{\text{diff}} = D_{\text{O}_2}\frac{C_{\text{O}_2}^* - 0}{\delta}$，其中溶液溶解氧 $C_{\text{O}_2}^*$ 由空气泵维持恒定，阴极表面氧浓度在极限扩散电位下为 $0$。)
  2. 样品响应（切换至外源呼吸）：通入含浓度为 $C_{\text{BOD}}$ 有机物的水样后，微生物转向外源呼吸，额外增加的耗氧速率在低浓度线性区正比于有机物浓度：$\Delta R_{\text{exo}} = k C_{\text{BOD}}$。此时能穿透微生物膜到达铂阴极的 $\text{O}_2$ 减少，输出电流跌落至新稳态 $I_s$： $$I_s = n F A \big(J_{\text{diff}} - R_{\text{endo}} - \Delta R_{\text{exo}}\big)$$
  3. 电流下降值 $\Delta I$ 定量：两式相减，背景扩散通量与内源呼吸全部抵消！ $$\Delta I \equiv I_0 - I_s = n F A \cdot \Delta R_{\text{exo}} = \boxed{K \cdot C_{\text{BOD}}}$$ 因此电流的下降值 $\Delta I$ 与水样有机物浓度（$\text{BOD}$ 值）呈线性正比关系（PPT P61 图中 $20, 40, 80\;\text{mg/L}$ 样品对应电流下降越来越深；换回缓冲液冲洗后电流在 $20\sim 40\;\text{min}$ 内恢复至基线 $I_0$）。

三、 电位型、光微生物与燃料电池型传感器（P63–65）

3.1 电位型微生物传感器（PPT P63）

  • 基础电极：$\text{pH}$ 玻璃电极、$\text{NH}_3$ 气敏电极、$\text{CO}_2$ 气敏电极等。
  • 定量方程：电极电位与代谢产生的离子/气体活度之间严格符合能斯特方程： $$E = E_0 \pm \frac{RT}{nF}\ln a_{\text{代谢产物}}$$

3.2 光微生物传感器（PPT P64）

  • 生物学基础：某些微生物（如蓝细菌、微藻）具有光合作用能力，在光照下能将待测物转化为电极敏感物质，或者自身裂解水释放 $\text{O}_2$。
  • 结构：将光合微生物固定化，并与氧电极（或光敏器件）结合。若水样中存在抑制光合作用的除草剂或重金属毒物，产氧量会急剧下降，从而反向测出毒性物质浓度。

3.3 燃料电池型微生物传感器（Microbial Fuel Cell, MFC，PPT P65）

  • 定义：有机分子被氧化时释放化学能（故称“燃料”）；在原电池装置中，若由微生物催化该氧化还原反应把化学能直接转变为电能，称为生物燃料电池（Bio-fuel Cell）。
  • 结构特点（PPT P65 示意图）：阳极室（含微生物 + 还原态媒介体 + 燃料有机物）与阴极室（含氧化剂 $\text{O}_2$）之间由**质子交换膜（离子交换膜）**隔开，质子 $\text{H}^+$ 穿膜到达阴极，电子 $e^-$ 通过外电路检流计从阳极流向阴极。

燃料电池型微生物传感器两极反应（PPT P65，注意 PPT 图文字印刷把阴阳极标签写反了，下方已按电化学定义校准并标注！）：

  • 阳极反应（氧化反应，失电子）：微生物氧化有机物（以碳水化合物 $(\text{CH}_2\text{O})_n$ 为例）释放电子与质子： $$(\text{CH}_2\text{O})_n + n\text{H}_2\text{O} \longrightarrow n\text{CO}_2 + 4n e^- + 4n\text{H}^+$$
  • 阴极反应（还原反应，得电子）：氧气在阴极结合电子与穿膜而来的质子生成水： $$\text{O}_2 + 4\text{H}^+ + 4e^- \longrightarrow 2\text{H}_2\text{O}$$ (考试提示：PPT P65 右侧排版把“阳极反应”和“阴极反应”两个紫字标题印反了！记住第 13-2 节第一性原理：阳极永远发生氧化失电子，阴极永远发生还原得电子，故产生 $e^-$ 的有机物氧化一定是阳极反应。)

四、 混合型、生物组织与细胞/细胞器传感器（P66）

在分子识别元件的尺度上，生物传感器经历了“纯酶 $\to$ 微生物 $\to$ 组织切片 $\to$ 活细胞/细胞器”的逐级复杂化拓展（PPT P66）：

类型 敏感元件构成 核心优势与应用特点
1. 酶—微生物混合型传感器 纯化酶 + 微生物混合固定化 弥补单一微生物缺乏某种关键酶、或单一酶缺乏辅助因子的短板，使敏感膜性能更完善。
2. 生物组织传感器 活的动植物细胞切片（如香蕉片、猪肝片、甜菜切片） 组织切片天然富含高浓度特定酶且处于最理想的天然保护环境中，无需提纯酶，寿命长、成本极低。
3. 细胞与细胞器传感器 活细胞或亚细胞结构（如线粒体、叶绿体） 可连续、实时、动态监测活细胞在外界药物或毒素刺激下的真实生理功能变化（而非单一化学反应），用于药物筛选与毒性评估。
生物概念穿插

【生物概念穿插：什么是“细胞器”？】 真核细胞就像一座微缩工厂，里面有不同的功能车间，这些车间就叫细胞器（Organelle）。PPT P9/P66 最常提到的两个细胞器是：

  • 线粒体（Mitochondria）：细胞的“发电站”，负责有氧呼吸消耗 $\text{O}_2$ 并产生能量货币 ATP；
  • 叶绿体（Chloroplast）：植物与藻类的“太阳能板”，负责光合作用吸收 $\text{CO}_2$、释放 $\text{O}_2$。

一、 基因传感器基础与核酸分子杂交（P67–69）

1.1 基因传感器的定义、结构与制备四步（PPT P67）

  • 定义：以 DNA（单链寡核苷酸探针）为敏感元件，通过信号转换器将 DNA 与 DNA、DNA 与 RNA、或 DNA 与其他离子/分子之间作用的生物学信号，转变为可检测的光、电、质量等物理信号的亲和型生物传感器。
  • 基本结构：DNA 探针（分子识别元件） + 信号转换器。
  • 两大关键技术：
    1. 有效地将 DNA 探针固定在固体基质表面的技术；
    2. 在传感器/液相界面对于靶基因的高灵敏检测技术。
  • 制备与检测四步骤：① DNA 探针的固定 $\to$ ② 杂交过程 $\to$ ③ 杂交的指示 $\to$ ④ 信号的检测。
生物概念穿插

【生物概念穿插：ssDNA、dsDNA、碱基互补配对与“杂交”】

  • DNA 的四种碱基（字母表）：DNA 就像一串由 4 个字母写成的密码带——A（腺嘌呤）、T（胸腺嘧啶）、C（胞嘧啶）、G（鸟嘌呤）。
  • 互补配对法则（Watson-Crick 配对，PPT P68）：A 只和 T 配对（靠 2 条氢键），G 只和 C 配对（靠 3 条氢键）。
  • ssDNA vs. dsDNA：单链 DNA（ssDNA）就像半边拉链；当遇到序列完全互补的另一条单链（靶 DNA）时，两条链会像拉链一样严丝合缝地扣在一起形成双螺旋双链 DNA（dsDNA）。这个“单链变双链”的特异性配对过程就叫核酸分子杂交（Hybridization）。
  • 什么是 DNA 探针（Probe）？：我们人工合成一段已知序列的 ssDNA 固定在电极上当“诱饵”，它就是探针；样品里等待被抓捕的未知病毒或基因片段叫靶基因（Target DNA）。

1.2 选择 DNA 探针的三大原则（PPT P67, P69，简答题必背！）

  1. 探针的长度：通常控制在 15～30 个碱基（nt） 左右——太短了特异性不够（随机序列也能撞车），太长了杂交速度慢且容易发生局部错配。
  2. GC 碱基的组成（GC 含量）：因 G≡C 之间有 3 条氢键，而 A=T 之间只有 2 条氢键，故 GC 含量越高，双链结合越牢固、解链温度（$T_m$）越高；一般要求 GC 含量适中（约 $40\% \sim 60\%$）以保证杂交既稳定又有良好的错配分辨力。
  3. 探针分子内不能存在互补区：如果一根单链探针自己的头和尾能互补配对，它就会自己折回来形成“发夹结构（Hairpin）”，把配对位点藏起来，导致无法与外来的靶 DNA 杂交。
最小闭环

【最小闭环：为什么 GC 含量决定杂交温度 $T_m$？】 每对 G≡C 碱基由 3 条氢键维系，而每对 A=T 只有 2 条氢键。对于 $15\sim 30\;\text{nt}$ 的短探针，解链温度（一半双链解开成单链的温度）可用 Wallace 经验公式定量估算： $$T_m\;(^{\circ}\text{C}) \approx 2(N_A + N_T) + 4(N_G + N_C)$$ 因此提高 GC 含量可显著提高 $T_m$（增强杂交热稳定性），但 GC 过高会导致探针内部易自发折叠且非特异性错配不易洗脱，故常取 $40\%\sim 60\%$。

1.3 DNA 探针的四大固定化方法（PPT P69）

  1. 吸附法：利用带负电的 DNA 磷酸骨架与带正电修饰电极之间的静电物理吸附（简单但易脱落）。
  2. 自组装法（SAM）：在探针末端修饰巯基（$-\text{SH}$），利用极强的 $\text{Au–S}$ 键自动整齐地直立组装在金电极表面（见 PPT P73 QCM 图中的 $\text{Au–S}$ 锚定）。
  3. 生物素—亲和素固定法：利用生物素（Biotin）与亲和素/链霉亲和素（Avidin）之间自然界最强的非共价亲和力（$K_d \approx 10^{-15}\;\text{M}$）进行桥接固定。
  4. 共价键结合法：探针修饰氨基（$-\text{NH}_2$）或羧基，与活化后的载体表面形成牢固共价键。

二、 电化学与压电晶体（QCM）DNA 传感器（P70–73）

2.1 电化学 DNA 传感器（PPT P70）

  • 构成：已知序列的 ssDNA 探针 + 电化学电极。
  • 核心痛点与关键技术：DNA 本身在常规电位窗口内几乎不发生氧化还原反应！因此必须引入电化学活性标识物：
    1. 电化学活性的杂交指示剂：小分子嵌入剂（如亚甲蓝、金属配合物），它对 ssDNA 和 dsDNA 的结合能力截然不同；杂交成双链 dsDNA 后大量指示剂嵌入双螺旋沟槽中，产生显著增大的氧化还原电流峰（$e^-$ 转移）。
    2. 寡聚核苷酸上修饰电化学活性官能团：在合成探针时直接给它挂上二茂铁（Fc）等电化学标签。
    3. 标记酶：在靶标或二级报告探针上连接酶（如 HRP、碱性磷酸酶），通过酶促反应产生电活性产物进行电流放大。

2.2 压电晶体（QCM）DNA 传感器（PPT P72–73）

  • 免标记直接检测：无需电化学指示剂或荧光染料！
  • 工作流程（PPT P72–73）：
    1. 压电石英晶体金电极表面活化，通过 $\text{Au–S}$ 自组装固定已知序列的探针 ssDNA（如 PPT P73 示例：5'-GGGAATTCGT-3'）；
    2. 通入待测靶 DNA，若序列互补（如 CCCTTAAGCA），发生杂交形成双链 dsDNA；
    3. 双链结合使石英晶体表面刚性质量增加 $\Delta m > 0$，由 Sauerbrey 方程 $\Delta f = -\frac{2f_0^2}{\sqrt{\rho_q\mu_q}}\frac{\Delta m}{A}$ 直接引起晶振谐振频率下降 $\Delta f < 0$，频率改变量定量反映靶 DNA 浓度。

三、 半导体型适配体传感器（Aptamer-FET，P74–76）

3.1 什么是核酸适配体（Aptamer）？（PPT P74）

  • 定义：一小段经体外筛选（SELEX 技术）得到的单链寡核苷酸序列（或短多肽），能折叠成特定的三维空间口袋，与相应的配体（小分子、神经递质、蛋白质甚至细胞）进行高亲和力和强特异性的结合——俗称**“化学抗体”**。
生物概念穿插

【生物概念穿插：为什么 Aptamer-FET 能打败传统抗体 ImmunoFET？（PPT P75–76 最小闭环）】 回顾第 19 章 2.3 节提到的物理痛点：在生理盐水（PBS 或脑脊液 aCSF）中，高浓度离子会把带电分子包裹起来，德拜屏蔽长度 $\lambda_D$ 只有约 $0.7\sim 1\;\text{nm}$——超过这个距离，FET 沟道就“看不见”电荷变化了！

  • 传统抗体太大（约 $10\;\text{nm}$）：抗原被抓在 $10\;\text{nm}$ 以外，电荷全被盐离子屏蔽了，FET 几乎没信号。
  • 适配体极小且会发生构象折叠（Science 2018，PPT P75–76）：
    1. 适配体本身只有几纳米长，表面带大量负电（磷酸骨架）；
    2. 当靶标小分子（如多巴胺 Dopamine、血清素 Serotonin、葡萄糖 Glucose、S1P，PPT P76）钻进适配体口袋时，适配体自身发生剧烈的三维折叠（构象变化）；
    3. 这种折叠带着自身大量带负电的磷酸骨架在德拜长度 $\lambda_D$ 内靠近或远离 $\text{In}_2\text{O}_3$ 半导体沟道表面，从而产生极强的栅极电场调制，即使面对**不带电的小分子（如葡萄糖）**也能在生理条件下实现超高灵敏度实时检测！

四、 Extra 前沿专题：DNA 芯片光刻制备与纳米孔测序（P77–80）

4.1 DNA 芯片光刻制备（PPT P77–78，张昊《化学与芯片制造》）

把半导体芯片的**光刻技术（Photolithography）**借用到生物芯片上，实现高通量微阵列探针合成：

  • 核心材料：硅基底（Si Substrate）+ $\text{SiO}_2$ 绝缘层 + 光刻胶（Photoresist）+ 掩膜（Mask）+ 光源（$h\nu$）。
  • 正胶 vs. 负胶显影机制（PPT P77 必分清！）：
    • 正性光刻胶（Positive）：被光照曝光的区域变得可溶（soluble），显影时被洗掉，留下未曝光区域。
    • 负性光刻胶（Negative）：被光照曝光的区域发生交联而变得不可溶（insoluble），显影时保留曝光区域，洗掉未曝光区域。
  • 经过曝光（exposure）$\to$ 显影（developing）$\to$ 刻蚀/去胶（strip），即可在晶圆上定义出微米级的生物探针阵列位点。

4.2 纳米孔测序（Nanopore Sequencing，PPT P79–80）

  • 装置结构（PPT P79）：两腔室（Cis 腔与 Trans 腔）充满电解质溶液，中间隔一层带有**纳米级小孔（蛋白孔或固态 $\text{SiN}_x$ 孔）**的薄膜，两侧各插一根 $\text{Ag/AgCl}$ 电极并施加偏压，串联高灵敏度皮安（$\text{pA}$）级电流表。
最小闭环

【最小闭环：纳米孔测序的物理读出机制（阻塞电流 vs. FET 耦合）】

  1. 第一代离子阻塞电流测序（PPT P79）：外加电场驱动带负电的 DNA 单链逐个碱基穿过纳米孔。孔道未堵塞时，电解液离子自由穿孔形成稳定的基线离子电流 $I_0$；当 A、T、C、G 四种大小/形状不同的碱基依次挤过纳米孔时，会不同程度地阻塞孔道截面积，引起特征性的瞬态离子电流下降（$\Delta I$，几十皮安量级）。通过解码台阶状电流脉冲序列即可直接读出 DNA 碱基序列！
  • 定量阻塞估算：将纳米孔近似为长度 $L$、直径 $d$ 的圆柱导体（电解液电阻率 $\rho$），空孔电阻 $R_0 = \frac{4\rho L}{\pi d^2}$。当截面积为 $\Delta A$ 的碱基进入孔道时，有效截面积减小为 $A_{\text{pore}} - \Delta A$，引起相对电流下降： $$\frac{\Delta I}{I_0} \approx -\frac{\Delta A}{A_{\text{pore}}}$$ 不同碱基（A、G 嘌呤较大，C、T 嘧啶较小）对应不同的 $\Delta A$，从而产生可分辨的台阶电流脉冲。
  1. 纳米孔—硅纳米线 FET 协同测序（Harvard 2012, Nature Nanotechnology，PPT P80）：在 $\text{SiN}_x$ 固态纳米孔边缘集成一根 硅纳米线场效应晶体管（SiNW-FET），DNA 穿孔时同时被测跨孔离子电流（$\text{nA}$ 级）和纳米线电导变化（$\text{nS}$ 级），双通道互相印证大幅提升时间分辨率与信噪比。
