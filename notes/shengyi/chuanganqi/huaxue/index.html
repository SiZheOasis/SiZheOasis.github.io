一、 化学传感器概论与系统架构（P1–7）

1.1 核心定义（PPT P2）

化学传感器（Chemical Sensor） 是生物医学测量中最常用、最基本的测量装置之一，指一种对特定化学物质敏感，并能将其浓度、组分或分压等化学量按一定规律转换成可用电信号的测定装置。

1.2 人体感官类比与三大传感器边界（PPT P4–5）

人的鼻子和舌头本身就是精密的化学与生物传感器。通过感官映射可明确三类传感器的技术边界：

人类感官 典型感知对象 对应传感器实例 所属大类 核心识别壁垒
视觉 / 听觉 / 触觉 光、振动、压力、温度 光、振动、压力、温度传感器 物理传感器 物理量直接通过物理效应（光电、压电、热电）换能
嗅觉 / 味觉 气体、气味、离子、无机物 气体、气味、鲜度、离子传感器 化学传感器 依赖敏感膜对特定化学组分的选择性化学识别
病状 / 特异生化感知 代谢物、抗原抗体、核酸 酶、免疫、基因传感器 生物传感器 利用生物活性分子（酶、抗体、DNA）的高特异性识别

1.3 传感器的基本构成三要素（PPT P6–7，核心框图）

所有化学与生物传感器在系统架构上均遵循三级串联链路： $$\text{被测量（浓度/分压）} \longrightarrow \boxed{\text{感受器 (Receptor)}} \xrightarrow{\text{非电量变化}} \boxed{\text{换能器 (Transducer)}} \xrightarrow{\text{电量}} \boxed{\text{输出放大器 (Amplifier)}}$$

  • 感受器（分子识别元件）：决定传感器的选择性（Selectivity）——能否在复杂体液中只抓取目标分子。
  • 换能器：将识别引起的化学势、电荷、光强、质量或热量变化转换为电信号（电位、电流、电导等）。
  • 输出放大器：进行阻抗匹配与信号放大，决定信噪比与分辨率。

二、 电化学原理基础：化学量如何转变为电学参量（P8）

要让“化学物质浓度”变成“电信号”，底层依赖两条物理化学机制：

  1. 氧化还原反应（伴随电子转移或偏移）：反应前后相关元素的**氧化态（化合价）**发生改变。
    • PPT P8 经典实例（氯元素的 6 种化学形态）： $$\text{Cl}^- (-1) \;\Big|\; \text{Cl}_2 (0) \;\Big|\; \text{ClO}^- (+1) \;\Big|\; \text{ClO}_2^- (+3) \;\Big|\; \text{ClO}_3^- (+5) \;\Big|\; \text{ClO}_4^- (+7)$$
  2. 离子的定向迁移（不伴随价态变化）：电解质解离出的阴阳离子在外电场或浓度梯度下定向移动，形成离子电流。
最小闭环

【最小闭环：为什么化学传感器测的是“化学物种”而非“元素”？】

  • 氧化态速算：单质为 $0$，化合物中 $\text{O}$ 通常为 $-2$、$\text{H}$ 为 $+1$，多元离子化合价代数和等于净电荷（如 $\text{ClO}_4^-$：$x + 4\times(-2) = -1 \implies x = +7$）。
  • 物理本质：从 $\text{Cl}^-$ 到 $\text{ClO}_4^-$，氯原子核内质子数均为 $17$（同属氯元素），但因氧的电负性 ($\chi_{\text{O}} = 3.44$) 大于氯 ($\chi_{\text{Cl}} = 3.16$)，共价键电子云向氧偏移，导致氯周围的电子云密度、空间构型（$\text{ClO}_3^-$ 为三角锥形，$\text{ClO}_4^-$ 为正四面体）和氧化还原活性完全不同。传感器识别的是特定价态与构型的“化学物种（Species）”，而非抽象元素。

三、 电导分析法：测量系统与交流电桥（P9）

3.1 宏观控制方程（PPT P9）

电导分析法通过测量电解质溶液的电导 $G$ 来反推离子浓度 $c$。由导体电阻公式 $R = \rho \frac{L}{A}$ 取倒数，结合稀溶液线性规律 $k = Kc$，得： $$G = \frac{1}{R} = \frac{1}{\rho}\frac{A}{L} = k\frac{A}{L} = K\frac{A}{L}c$$

  • $L/A$ 为电导池常数：极板几何尺寸一旦固定，$G$ 与溶液电导率 $k$（及稀溶液下的浓度 $c$）呈严格正比。

3.2 测量电路：交流平衡电桥（PPT P9 右图）

  • 电路拓扑：交流电源 $V_a$ 接在 $A, C$ 两端；右臂为纯电阻 $R_1, R_2$ 分压（中点 $B$）；左上臂为可调电阻 $R_3$ 与可调电容 $C$ 并联，左下臂为待测电导池复阻抗 $Z_x$（中点 $E$）。
最小闭环

【最小闭环：为什么必须用交流电桥，且上臂要并联电容 $C$？】

  1. 必须用交流激励（消除极化）：若用直流电，电极表面会持续发生电解反应并导致离子堆积（电极极化），改变界面局部浓度并产生反向极化电动势，使欧姆电阻测量完全失真；高频交流电使正负半周反应相互抵消，仅测纯离子迁移导电。
  2. 复导纳平衡解耦（消除双电层电容）：电极/溶液界面天然存在双电层寄生电容 $C_x$，故电导池等效为纯溶液电阻 $R_x$ 与 $C_x$ 的并联网络（复导纳 $Y_x = \frac{1}{R_x} + j\omega C_x = G_x + j\omega C_x$）。 调节 $R_3$ 和 $C$ 使电桥平衡（$V_E = V_B$），即满足 $\frac{Y_x}{Y_3} = \frac{R_1}{R_2}$，代入得： $$G_x + j\omega C_x = \frac{R_1}{R_2}\left(\frac{1}{R_3} + j\omega C\right)$$ 实部与虚部分别相等，实现正交独立解耦： $$G_x = \frac{R_1}{R_2}\cdot\frac{1}{R_3}, \qquad C_x = \frac{R_1}{R_2}C$$ 可见待测溶液电导 $G_x$ 仅由电阻 $R_3$ 决定，且完全消除了交流角频率 $\omega$ 的影响。

四、 电导率的微观物理机制与六大影响因素（P10）

PPT P10 明确列出影响溶液电导率 $k$ 的六大因素：离子带电量、离子迁移能力（淌度）、解离能力、活度系数 ($a = \gamma c$)、温度、溶剂。

最小闭环

【最小闭环：从微观漂移电流推出电导率母式，一次看穿六大因素】

  1. 宏观电流密度与微观迁移：设离子 $i$ 的有效导电浓度为 $c_i = \alpha \gamma c$（$\alpha$ 为解离度，$\gamma$ 为活度系数），在电场 $E$ 驱动下达到稳态漂移速度 $v_i = u_i E$（$u_i$ 为淌度）。单位时间内通过单位截面积的总电流密度 $J$ 为各离子电荷通量之和： $$J = \sum_i |z_i| F c_i v_i = \left(\sum_i |z_i| F c_i u_i\right) E$$ 对比微分欧姆定律 $J = kE$，直接得到电导率微观母式： $$k = \sum_i |z_i| F c_i u_i$$
  2. 斯托克斯（Stokes）流体力学定淌度：将水化离子视为半径 $r_i$ 的刚性球，在粘度为 $\eta$ 的溶剂中匀速运动时，电场力等于粘滞阻力： $$|z_i| e E = 6\pi \eta r_i v_i \implies u_i = \frac{v_i}{E} = \frac{|z_i| e}{6\pi \eta r_i}$$
  3. 合体控制方程：代入上式得 $$k = \sum_i \frac{|z_i|^2 F e}{6\pi \eta r_i} (\alpha \gamma c)$$ 该式直接锁死了全部六大因素：带电量 $|z_i|^2$、淌度 $u_i$（受溶剂粘度 $\eta$ 与水化半径 $r_i$ 控制）、解离能力 $\alpha$、活度系数 $\gamma$ 以及温度 $T$（$T\uparrow \implies$ 粘度 $\eta\downarrow$ 且促进解离，故 $k\uparrow$）。
  • 读懂 PPT P10《溶液电导与浓度的关系图》的三个关键现象：
    1. $\text{HCl}$、$\text{KOH}$ 曲线远高于普通盐类：$\text{H}^+$ 和 $\text{OH}^-$ 在水中不靠整个水化球搬运，而是通过水分子氢键网络进行“质子跳跃（Grotthuss 机制）”，等效阻力极小，淌度异常高。
    2. $\text{KCl}$ 高于 $\text{LiCl}$：$\text{Li}^+$ 裸半径虽小，但电荷密度极高，吸引更厚的水化层，导致有效水化半径 $r_{\text{Li}^+} > r_{\text{K}^+}$，淌度反而更小。
    3. 强电解质高浓度区（$C > 4\text{ M}$）电导率反降：浓度过高时，异号离子间的“离子氛”弛豫效应与电泳效应拖拽加剧（德拜-休克尔极限公式 $\lg\gamma_i = -A z_i^2\sqrt{I}$，其中离子强度 $I = \frac{1}{2}\sum c_j z_j^2$；进一步由德拜-休克尔-昂萨格方程 $u_i = u_i^0 - S\sqrt{c}$ 代入 $k \propto c u_i$ 得渐近式 $k \approx \Lambda^0 c - S c^{3/2}$）。随着 $c$ 增大，负修正项 $-Sc^{3/2}$ 迅速压倒线性项并伴随粘度 $\eta$ 剧增，使曲线出现极大值拐点并下降。工程铁律：电导传感器必须工作在低浓度线性上升区；同时在后续第 15 章离子电极测量中，为防止背景离子改变 $I$ 从而调制活度系数 $\gamma_i$，常加入高浓度总离子强度调节缓冲液（TISAB）锁死 $I$ 与 $\gamma_i$。

五、 摩尔电导率推导与科尔劳施独立运动定律（P11–12）

5.1 为什么引入摩尔电导率 $\Lambda$？（几何模型与公式推导）

电导率 $k$ 混杂了“离子数量（浓度 $c$）”与“单个离子的本征导电能力”两个因素。为了剥离数量干扰、单独度量每摩尔电解质的本征导电能力，PPT P11 给出了如下物理构造：

最小闭环

【最小闭环：摩尔电导率 $\Lambda = k V = \frac{1000k}{c}$ 是怎么一步步推出来的？】

  1. 几何定义构造（PPT P11 原文）：把含有 $1\text{ mol}$ 电解质的溶液，全部灌入相距固定为 $L = 1\text{ cm}$ 的两块平行平面电极板之间。此时测得的宏观电导 $G$，就定义为该电解质的摩尔电导率 $\Lambda$。
  2. 面积与体积映射：设这 $1\text{ mol}$ 溶液所占的体积为 $V$（单位：$\text{cm}^3\cdot\text{mol}^{-1}$）。为了在极板间距 $L = 1\text{ cm}$ 的条件下刚好装下体积 $V$，平行极板所需的有效面积 $A$ 必须满足： $$A = \frac{V}{L} = \frac{V}{1\text{ cm}} = V \quad (\text{数值上 } A = V)$$ 将 $L = 1\text{ cm}$ 与 $A = V$ 代入基本电导公式 $G = k \frac{A}{L}$，立刻得到定义式： $$\Lambda \equiv G = k \cdot \frac{V}{1} = k V$$
  3. 单位空间换算（“1000”因子的由来）：实验上浓度 $c$ 的单位是 $\text{mol}\cdot\text{L}^{-1}$，而电导率 $k$ 的几何尺度是 $\text{cm}$（$\text{S}\cdot\text{cm}^{-1}$）。因为 $1\text{ L} = 1000\text{ cm}^3$，所以 $1\text{ cm}^3$ 溶液中含溶质 $\frac{c}{1000}\text{ mol}$；反过来，含有 $1\text{ mol}$ 溶质的溶液体积 $V$ 必然为： $$V = \frac{1000}{c} \quad (\text{cm}^3\cdot\text{mol}^{-1})$$ 代回 $\Lambda = kV$，得到核心控制方程： $$\boxed{\Lambda = k V = k \frac{1000}{c}}$$
  4. 量纲校验：$[\Lambda] = \frac{\text{S}\cdot\text{cm}^{-1} \times \text{cm}^3\cdot\text{L}^{-1}}{\text{mol}\cdot\text{L}^{-1}} = \text{S}\cdot\text{cm}^2\cdot\text{mol}^{-1}$，与 PPT P11 标注完全一致。

5.2 无限稀释摩尔电导率与通用电导方程（PPT P12）

  • 科尔劳施（Kohlrausch）离子独立运动定律： 当浓度 $c \to 0$（无限稀释）时，离子间平均距离趋于无穷大，库仑干扰与离子氛消失（$\gamma \to 1$），阴、阳离子完全独立导电，总无限稀释摩尔电导率等于所有离子贡献的线性叠加： $$\Lambda^0 = \Lambda_+^0 + \Lambda_-^0$$

  • 多组分通用电导方程（PPT P12 核心公式）： 对含多种离子的稀溶液，由 $\Lambda_i = \frac{1000k_i}{c_i}$ 反解单组分贡献 $k_i = \frac{\Lambda_i c_i}{1000}$，叠加得总电导率 $k = \frac{\sum \Lambda_i c_i}{1000}$，代入 $G = k\frac{A}{L}$ 即得： $$\boxed{G = k\frac{A}{L} = \frac{\sum \Lambda_i c_i}{1000}\frac{A}{L}}$$

  • PPT P12 常见离子无限稀释摩尔电导率表（$25^\circ\text{C}$，单位：$\text{S}\cdot\text{cm}^2\cdot\text{mol}^{-1}$）：

    • 必记计算常数：$\Lambda^0(\text{H}^+) = 349.8$，$\Lambda^0(\text{OH}^-) = 197.6$
    • 其他离子：$\text{K}^+$ (73.52) > $\text{NH}_4^+$ (73.4) > $\text{Ag}^+$ (61.92) > $\frac{1}{2}\text{Mg}^{2+}$ (53.06) > $\text{Na}^+$ (50.11)；$\text{I}^-$ (76.8) ≈ $\text{Cl}^-$ (76.34) > $\text{NO}_3^-$ (71.44) > $\text{HCO}_3^-$ (44.5) > $\text{CH}_3\text{COO}^-$ (40.9)。

六、 经典必考例题：纯水电阻率计算与工程局限（P13–15）

【例 6.1】计算纯水的电阻率（$25^\circ\text{C}$，PPT P13–14 原题）

已知 $25^\circ\text{C}$ 下无限稀释摩尔电导率：$\Lambda^0(\text{H}^+) = 349.8\;\text{S}\cdot\text{cm}^2\cdot\text{mol}^{-1}$，$\Lambda^0(\text{OH}^-) = 197.6\;\text{S}\cdot\text{cm}^2\cdot\text{mol}^{-1}$。

标准解题步骤（严格对齐 PPT P14）：

  1. 由水的自偶电离推导离子浓度： 纯水微弱电离 $\text{H}_2\text{O} \rightleftharpoons \text{H}^+ + \text{OH}^-$，由质量作用定律得： $$K = \frac{a(\text{H}^+)\,a(\text{OH}^-)}{a(\text{H}_2\text{O})}$$ 因纯液态水活度 $a(\text{H}_2\text{O})\equiv 1$ 且极稀溶液中 $\gamma\to 1$，在 $25^\circ\text{C}$ 下简写为水的离子积： $$K_w = c(\text{H}^+)\,c(\text{OH}^-) = 1.0\times 10^{-14}$$ 再施加体相电中性约束 $\sum z_j c_j = 0$，即 $(+1)c(\text{H}^+) + (-1)c(\text{OH}^-) = 0 \implies c(\text{H}^+) = c(\text{OH}^-)$，联立解得： $$[c(\text{H}^+)]^2 = 10^{-14} \implies c(\text{H}^+) = c(\text{OH}^-) = 10^{-7}\;\text{mol/L}$$
  2. 代入通用方程求电导率 $k$： $$k = \frac{\sum \Lambda_i c_i}{1000} = \frac{349.8 \times 10^{-7} + 197.6 \times 10^{-7}}{1000} = 5.48 \times 10^{-8}\;\text{S}\cdot\text{cm}^{-1}$$
  3. 取倒数求电阻率 $\rho$： $$\rho = \frac{1}{k} = \frac{1}{5.48 \times 10^{-8}} = 1.83 \times 10^7\;\Omega\cdot\text{cm} = \boxed{18.3\;\text{M}\Omega\cdot\text{cm}}$$

工程映射与方法局限（PPT P15 & 引出后续章节）

  1. 超纯水系统金标准（PPT P15）：实验室 Direct-Q 超纯水机 I 级产水的电阻率指标为 $18.2\;\text{M}\Omega\cdot\text{cm}\;(25^\circ\text{C})$，其物理天花板正是例 6.1 求得的 $18.3\;\text{M}\Omega\cdot\text{cm}$。任何微量杂质离子都会使 $k$ 升高、$\rho$ 跌破该阈值。
  2. 电导分析法的根本短板（引出 13-2 与第 14 章）：由 $k = \frac{\sum \Lambda_i c_i}{1000}$ 可见，电导测量是一个“总和输出”——它只能反映所有离子的总导电贡献，完全缺乏对单一离子的选择性。要实现对特定离子（如 $\text{H}^+$、$\text{Na}^+$、$\text{Ca}^{2+}$）的专一检测，必须转向基于界面氧化还原或选择性离子交换的电极电位与电位分析法。

最小闭环

【最小闭环：吉布斯自由能 $\Delta G$ 与盐桥电中性的底层逻辑】

  1. 为什么 $E_{\text{cell}} > 0$ 才自发？ 恒温恒压可逆条件下，系统吉布斯自由能的降低量等于对外输出的最大非体积功（电功）： $$\Delta G = W_{\text{电, max}} = q E_{\text{cell}} = -n F E_{\text{cell}}$$ 因此 $E_{\text{cell}} > 0 \iff \Delta G < 0$（原电池自发）；而电解池反应 $\Delta G > 0$（$E_{\text{cell}} < 0$），外加电源必须提供至少等于 $|E_{\text{cell}}|$ 的反向电压才能克服化学势垒，这就是理论分解电压的物理来源。
  2. 为什么没有盐桥电流会瞬间归零？ 若无盐桥，阳极不断产生 $\text{Zn}^{2+}$ 带净正电、阴极不断消耗 $\text{Cu}^{2+}$ 留下 $\text{SO}_4^{2-}$ 带净负电，微秒内即在液相拉出反向静电场锁死电子流动。盐桥中的 $\text{Cl}^-$ 迁向阳极池、$\text{K}^+$ 迁向阴极池，维持电中性并闭合内电路。

二、 电极电位与能斯特（Nernst）方程闭环推导（P22–28）

2.1 电极电位的定义与双电层平衡（PPT P22）

  • 定义：金属导体与电解质溶液间的相间电位，即 $\varphi = \varphi_M - \varphi_S$。
  • 物理成因（以 $\text{Zn}|\text{Zn}^{2+}$ 为例）：金属中 $\text{Zn}^{2+}$ 的化学势大于溶液中的 $\text{Zn}^{2+}$，锌倾向于溶解入溶液（$\text{Zn} \to \text{Zn}^{2+} + 2e^-$），把电子留在金属上使金属带负电，与溶液中阳离子形成双电层；金属负电又反过来吸引 $\text{Zn}^{2+}$。3. 达成平衡与纳米级超强电场：当溶解倾向与静电吸引达到动态平衡时，界面两侧形成的稳定电位差即为平衡电极电位 $\varphi$。紧密双电层厚度仅约 $\delta \approx 1\;\text{nm} = 10^{-9}\;\text{m}$，以 $\text{Zn}$ 电极 $\varphi = -0.763\;\text{V}$ 估算，界面局部场强高达 $|\vec{E}| \approx \frac{0.763}{10^{-9}} = 7.63\times 10^8\;\text{V/m}$——正是这近 $10^9\;\text{V/m}$ 的超强局部电场，使溶液中离子浓度的微小对数变化能稳稳调制宏观可测电位。

2.2 能斯特方程与 $25^\circ\text{C}$ 工程化简（PPT P23–24）

  • IUPAC 统一还原写法（PPT P23）：所有半电极反应一律写成还原形式 $\text{Ox} + n e^- \to \text{Red}$（如 $\text{Cu}^{2+} + 2e^- \to \text{Cu}$，电极表达式 CuSO4(x mol/L)|Cu）。
  • 能斯特（Nernst）方程标准式： $$\varphi = \varphi^\ominus_{\text{Ox,Red}} + \frac{RT}{nF} \ln \frac{a_{\text{Ox}}}{a_{\text{Red}}}$$ (注：纯固体、纯液体活度恒为 $1$；气体取分压 $p$。)
  • $25^\circ\text{C}\;(298.15\text{ K})$ 常用对数式（PPT P24 必背）： 利用 $\ln x = 2.303 \lg x$，代入 $R=8.314$、$F=96485$，得 $\frac{2.303RT}{F} \approx 0.059\;\text{V}$： $$\boxed{\varphi = \varphi^\ominus_{\text{Ox,Red}} + \frac{0.059}{n} \lg \frac{a_{\text{Ox}}}{a_{\text{Red}}} = \varphi^\ominus_{\text{Ox,Red}} + \frac{0.059}{n} \lg \frac{\gamma_{\text{Ox}} c_{\text{Ox}}}{\gamma_{\text{Red}} c_{\text{Red}}}}$$ (稀溶液中近似 $\gamma \approx 1$，直接用浓度 $c$ 代入；单价离子 $n=1$ 时浓度每变 10 倍，电位移动 $59\text{ mV}$。)
最小闭环

【最小闭环：从热力学基本方程 $\to$ 化学势对数项 $\to$ Nernst 方程完整推导】 0. 为什么化学势里会有 $RT\ln a_i$？ 由热力学基本方程 $dG = VdP - SdT$，在恒温条件（$dT=0$）下，对 $1\;\text{mol}$ 理想气体（$V_m = \frac{RT}{P}$）有： $$d\mu = dG_m = V_m\,dP = \frac{RT}{P}\,dP$$ 从标准压力 $P^\ominus$ 积分至任意压力 $P$： $$\int_{\mu^\ominus}^{\mu} d\mu = \int_{P^\ominus}^{P} \frac{RT}{P}\,dP \implies \mu = \mu^\ominus + RT\ln\frac{P}{P^\ominus}$$ 对于真实溶液，以有效浓度（活度 $a_i = \gamma_i c_i$）替代相对压力，即得化学势通式： $$\mu_i = \mu_i^\ominus + RT\ln a_i$$

  1. 电化学势导出 Nernst 方程：带电粒子在相内的总能量（电化学势）为 $\bar{\mu}_i = \mu_i^\ominus + RT\ln a_i + z_i F\phi$（标准本征化学势 + 浓度熵效应 + 静电能）。当界面反应 $\text{Ox} + ne^- \rightleftharpoons \text{Red}$ 平衡时，反应物与产物总电化学势相等： $$\bar{\mu}_{\text{Ox}}^S + n\bar{\mu}_e^M = \bar{\mu}_{\text{Red}}^S$$ 将静电项 $nF(\varphi_M - \varphi_S)$ 归拢到左侧，标准化学势差合并定义为 $nF\varphi^\ominus \equiv \mu_{\text{Ox}}^{\ominus,S} + n\mu_e^{\ominus,M} - \mu_{\text{Red}}^{\ominus,S}$，两边同除以 $nF$ 即得： $$\varphi = \varphi_M - \varphi_S = \varphi^\ominus + \frac{RT}{nF}\ln\frac{a_{\text{Ox}}}{a_{\text{Red}}}$$
  2. 为什么阳极实际发生氧化，写能斯特方程却也按还原写？ 电极电位 $\varphi$ 是度量半电池“电子能量高低”的状态量。两边都按还原算出 $\varphi_{\text{右}}$ 和 $\varphi_{\text{左}}$ 后，总电动势公式 $E_{\text{cell}} = \varphi_{\text{右}} - \varphi_{\text{左}}$ 中的负号（$-\varphi_{\text{左}}$）已经在代数上自动把左侧反应反转为氧化反应，无需人工改写方程内部方向。

2.3 相对测量与标准氢电极（SHE / NHE，PPT P25–26）

  • 无法单测：单一界面的绝对电极电位无法直接测量，必须与参比电极组成原电池测电动势 $E_{\text{cell}} = \varphi_{\text{右}} - \varphi_{\text{左}}$。
  • 标准氢电极（NHE）零点基准：半反应 $2\text{H}^+ + 2e^- \rightleftharpoons \text{H}_2(g)$，人为规定在 $c(\text{H}^+)=1\;\text{mol/L}, p(\text{H}_2)=1\;\text{atm}$ 时 $\varphi^\ominus_{\text{H}^+,\text{H}_2} \equiv 0\;\text{V}$。 组池 Pt, H2(1 atm)|H+(1 mol/L)||被测电极，则 $E_{\text{cell}} = \varphi_{\text{被测}} - 0 = \varphi_{\text{被测}}$（若被测电极作阳极、NHE 作阴极，则 $\varphi_{\text{被测}} = -E_{\text{cell}}$）。

2.4 【例 6.2】复杂电池电动势计算（PPT P27–28 原题）

计算电池 $\text{Cu} \mid \text{CuSO}_4(0.02\;\text{mol/L}) \parallel \text{Fe}^{2+}(0.2\;\text{mol/L}), \text{Fe}^{3+}(0.01\;\text{mol/L}), \text{H}^+(0.1\;\text{mol/L}) \mid \text{Pt}$ 在 $25^\circ\text{C}$ 时的电动势。已知 $\varphi^\ominus_{\text{Fe}^{3+},\text{Fe}^{2+}} = 0.700\;\text{V}$，$\varphi^\ominus_{\text{Cu}^{2+},\text{Cu}} = 0.337\;\text{V}$。

标准解题步骤（严格对齐 PPT P28）：

  1. 计算右侧阴极（$\text{Pt}$ 惰性电极上的 $\text{Fe}^{3+}/\text{Fe}^{2+}$，$n=1$）： (注：$\text{H}^+$ 仅用于抑制 $\text{Fe}^{3+}$ 水解，不参与半反应 $\text{Fe}^{3+} + e^- \to \text{Fe}^{2+}$，不代入方程。) $$\varphi_{\text{右}} = \varphi^\ominus_{\text{Fe}^{3+},\text{Fe}^{2+}} + \frac{0.059}{1}\lg\frac{c_{\text{Fe}^{3+}}}{c_{\text{Fe}^{2+}}} = 0.700 + 0.059\lg\frac{0.01}{0.2} = 0.623\;\text{V}$$
  2. 计算左侧阳极（$\text{Cu}^{2+}/\text{Cu}$，$n=2$，纯固体 $\text{Cu}$ 活度为 $1$）： $$\varphi_{\text{左}} = \varphi^\ominus_{\text{Cu}^{2+},\text{Cu}} + \frac{0.059}{2}\lg c_{\text{Cu}^{2+}} = 0.337 + \frac{0.059}{2}\lg 0.02 = 0.287\;\text{V}$$
  3. 计算全电池电动势： $$E_{\text{cell}} = \varphi_{\text{右}} - \varphi_{\text{左}} = 0.623 - 0.287 = \boxed{0.336\;\text{V}}$$

三、 电流、$IR$ 降与电极表面传质机制（P29–30）

  • $IR$ 降与法拉第定量（PPT P29 & P16）：无净电流 ($I=0$) 时电极处于平衡态，服从 Nernst 方程；当有较大电流流过时，溶液内阻 $R$ 产生欧姆压降 $IR$，使原电池输出电动势降低（$E_{\text{输出}} = E_{\text{cell}} - IR$），使电解池所需外加电压增大（$V_{\text{外}} = |E_{\text{cell}}| + IR$）。同时通过电量 $Q = \int I\,dt = nzF$ 对应电极表面反应质量 $\Delta m = \pm\frac{Q}{nF}M$（库仑分析法基础）。
  • 电极表面三种传质方式（PPT P30）：
    1. 扩散（Diffusion）：浓度梯度驱动（伏安/电流传感器定量核心）；
    2. 电迁移（Migration）：电场力驱动带电离子移动；
    3. 对流（Convection）：搅拌或自然流体运动。

四、 斐克（Fick）定律与科特雷尔（Cottrell）方程推导（P31–36）

4.1 Fick 第一定律与第二定律（PPT P31–34）

  • Fick 第一定律（稳态扩散，PPT P31–32）：单位时间内通过面积为 $A$ 的截面的扩散质量速率与浓度梯度及面积成正比： $$\frac{dm}{dt} = -DA\frac{dc}{dx} \quad \text{或通量形式} \quad \frac{dN_{x,t}}{A\cdot dt} = D\frac{\partial c(x,t)}{\partial x}$$
    • $D$ 为扩散系数：单位浓度梯度、单位时间通过单位截面积的物质质量（$\text{cm}^2/\text{s}$）。
    • 负号意义：扩散自发指向浓度降低的方向（$\frac{dc}{dx} < 0$ 时 $\frac{dm}{dt} > 0$）。
  • Fick 第二定律（非稳态扩散，PPT P33–34）：
    • 常系数标准式（$D$ 为常数）：$$\frac{\partial c}{\partial t} = D\frac{\partial^2 c}{\partial x^2}$$
    • 变系数普遍式（$D$ 受浓度影响）：$$\frac{\partial c}{\partial t} = \frac{\partial}{\partial x}\left(D\frac{\partial c}{\partial x}\right)$$
最小闭环

【最小闭环：Fick 第一定律统计起源与 Fick 第二定律严格微元推导】

  1. Fick 第一定律的随机漫步 + 泰勒展开推导： 设一维溶液截面 $A$ 处，$\Delta t$ 时间内粒子以相等概率 $\frac{1}{2}$ 向左或向右跳跃步长 $\Delta x$，则净向右输运质量为： $$\Delta m = \frac{1}{2}A\Delta x\left[c\left(x-\frac{\Delta x}{2},t\right) - c\left(x+\frac{\Delta x}{2},t\right)\right]$$ 在 $x$ 处做一阶泰勒展开 $c\left(x\pm\frac{\Delta x}{2},t\right) \approx c(x,t) \pm \frac{\Delta x}{2}\frac{\partial c}{\partial x}$，代入相减并除以 $\Delta t$： $$\frac{\Delta m}{\Delta t} = -\left[\frac{(\Delta x)^2}{2\Delta t}\right]A\frac{\partial c}{\partial x}$$ 取连续极限 $\Delta x, \Delta t \to 0$，定义扩散系数 $D \equiv \lim\frac{(\Delta x)^2}{2\Delta t}$，即得： $$\frac{\partial m}{\partial t} = -DA\frac{\partial c}{\partial x}$$
  2. Fick 第二定律（PPT P33–34 质量守恒）： 取截面 $A$、厚度 $dx$ 的微元控制体（体积 $A\,dx$），进入 $AB$ 面通量 $J_x = -D\frac{\partial c}{\partial x}$，离开 $EF$ 面通量对整体 $J$ 做一阶泰勒展开： $$J_{x+dx} \approx J_x + \frac{\partial J}{\partial x}dx = -D\frac{\partial c}{\partial x} - \frac{\partial}{\partial x}\left(D\frac{\partial c}{\partial x}\right)dx$$ 微元内物质净积累速率等于流入通量减流出通量： $$\frac{\partial c}{\partial t} = \frac{J_x - J_{x+dx}}{dx} = \frac{\partial}{\partial x}\left(D\frac{\partial c}{\partial x}\right)$$ 当稀溶液中 $D$ 为常数时提出算子外，即退化为常系数形式 $\frac{\partial c}{\partial t} = D\frac{\partial^2 c}{\partial x^2}$。 (物理直觉：某点浓度随时间变化取决于浓度曲线的*二阶导曲率 $\frac{\partial^2 c}{\partial x^2}$；线性分布时曲率为 0，流入=流出，达到稳态。)*

4.2 平面电极的 Cottrell 方程（PPT P35–36，核心必考公式）

设平面电极位于 $x=0$，发生还原反应 $O + ne^- \to R$（PPT P35 模型）：

  • 初始条件 ($t=0,\; x \ge 0$)：$C_O = C^*$（主体浓度），$C_R = 0$
  • 边界条件 ($t>0$)：$x=0$ 处 $C_O = C$（表面浓度），$C_R = C^* - C$；$x \to \infty$ 处 $C_O = C^*$，$C_R = 0$
最小闭环

【最小闭环：拉普拉斯变换 + 伽马函数一步不跳求解 Cottrell 方程】

  1. 定浓度亏损变量：令 $\Delta c(x,t) = c^* - c(x,t)$，满足 $\frac{\partial(\Delta c)}{\partial t} = D\frac{\partial^2(\Delta c)}{\partial x^2}$，初值 $\Delta c(x,0)=0$，边界 $\Delta c(0,t)=c^*-c$（常数），$\Delta c(\infty,t)=0$。
  2. 拉氏变换将 PDE 降维为常系数 ODE：定义 $\overline{\Delta c}(x,s) = \int_0^\infty \Delta c(x,t)e^{-st}dt$。利用微分性质 $\mathcal{L}\{\partial(\Delta c)/\partial t\} = s\overline{\Delta c} - \Delta c(x,0) = s\overline{\Delta c}$，方程变为二阶齐次常微分方程： $$\frac{d^2\overline{\Delta c}}{dx^2} - \frac{s}{D}\overline{\Delta c} = 0$$ 特征方程 $r^2 - \frac{s}{D} = 0 \implies r_{1,2} = \pm\sqrt{\frac{s}{D}}$，通解为 $\overline{\Delta c}(x,s) = A(s)e^{\sqrt{s/D}x} + B(s)e^{-\sqrt{s/D}x}$。
  3. 边界条件定系数：① 当 $x\to\infty$ 时物理要求 $\overline{\Delta c}\to 0$，故发散项系数强制 $A(s)\equiv 0$；② 当 $x=0$ 时 $\overline{\Delta c}(0,s) = \mathcal{L}\{c^*-c\} = \frac{c^*-c}{s}$，得 $B(s) = \frac{c^*-c}{s}$。因此频域精确解为： $$\overline{\Delta c}(x,s) = \frac{c^*-c}{s}e^{-\sqrt{\frac{s}{D}}x}$$
  4. 求表面梯度并严格证明 $\mathcal{L}^{-1}\{\frac{1}{\sqrt{s}}\} = \frac{1}{\sqrt{\pi t}}$：对 $x$ 求导并令 $x=0$，得浓度梯度幅值 $\left.\frac{d\bar{c}}{dx}\right|_{x=0} = \frac{c^*-c}{\sqrt{Ds}}$。正向计算 $\mathcal{L}\{t^{-1/2}\} = \int_0^\infty t^{-1/2}e^{-st}dt$，令 $u = st\;(dt = du/s)$： $$\mathcal{L}\{t^{-1/2}\} = \frac{1}{\sqrt{s}}\int_0^\infty u^{-1/2}e^{-u}du = \frac{1}{\sqrt{s}}\Gamma\left(\frac{1}{2}\right)$$ 再令 $u = y^2\;(du = 2y\,dy)$，得 $\Gamma(\frac{1}{2}) = 2\int_0^\infty e^{-y^2}dy = \int_{-\infty}^\infty e^{-y^2}dy = \sqrt{\pi}$（高斯积分），故 $\mathcal{L}\{\frac{1}{\sqrt{\pi t}}\} = \frac{1}{\sqrt{s}}$。回到时域立得 PPT P36 第一式： $$\left(\frac{\partial c}{\partial x}\right)_{x=0} = \frac{c^* - c}{\sqrt{\pi D t}}$$
  5. 法拉第电流桥接：$dt$ 时间内反应掉 $dN$ 摩尔物质需转移 $n\cdot dN$ 摩尔电子，电荷量 $dQ = nF\,dN$，故瞬时电流 $i = \frac{dQ}{dt} = nF\frac{dN}{dt}$。代入 Fick 第一定律的摩尔通量 $\frac{dN}{dt} = A D \left(\frac{\partial c}{\partial x}\right)_{x=0}$，得平面电极表面扩散电流： $$i = nFAD\frac{c^* - c}{\sqrt{\pi D t}} = nFAD\frac{c^* - c}{\delta}, \qquad \text{其中扩散层厚度 }\delta \equiv \sqrt{\pi D t}$$
  • 极限扩散电流——Cottrell 方程（PPT P36 红字核心）： 施加足够大电压使表面反应物瞬间耗尽（表面浓度 $c \to 0$），扩散电流达到极限值 $i_d$： $$\boxed{i_d = \frac{n F A D_O c^*}{\sqrt{\pi D_O t}} = \frac{n F A D_O^{1/2} c^*}{\sqrt{\pi t}}}$$ 核心结论：在固定采样时间 $t$ 下，极限扩散电流 $i_d$ 与电活性物质主体浓度 $c^*$ 严格成正比，这是伏安与电流型生物传感器的定量基石。

五、 电极的极化与过电位 $\eta$（P37–39）

5.1 极化定义与两大分类（PPT P37–38）

当有较大电流流过原电池或电解池时，电极电位偏离平衡电极电位 ($\varphi_{\text{eq}}$) 的现象称为极化（Polarization）。 电极反应是一条串联步骤链：$\text{溶液本体 } O \xrightarrow{\text{物质传递}} \text{表面层} \xrightarrow{\text{化学反应/水化吸附}} \text{电子传递 } (+ne^-) \xrightarrow{\text{脱附/晶体化}} R$，哪一步最慢就引发哪种极化：

极化类型 动力学瓶颈（慢步骤） 关键影响因素（PPT P38）
浓差极化 **物质传递（扩散）**速度跟不上电极反应消耗，导致表面浓度 $c \neq c^*$ 搅拌、温度、电极面积、电流密度（搅拌可压缩扩散层、消除浓差极化）
电化学极化 电子传递、多步反应活化能差异、水化/吸脱附/晶体化等界面步骤迟缓 电流密度、温度、电极材料（如 $\text{Pt}$ 催化）、产物物态（气体过电位大）

5.2 过电位（超电位）$\eta$ 及其方向律（PPT P39）

  • 定义式：$\boxed{\eta = \varphi - \varphi_{\text{eq}}}$
  • 极化方向铁律（PPT P39 必考）：
    • 阴极超电位使阴极电位向负的方向移动（$\varphi_{\text{阴}} < \varphi_{\text{eq,阴}}$，$\eta_{\text{阴}} < 0$）；
    • 阳极超电位使阳极电位向正的方向移动（$\varphi_{\text{阳}} > \varphi_{\text{eq,阳}}$，$\eta_{\text{阳}} > 0$）。 (直觉：阴极本应得电子消耗，若反应慢则电子在阴极表面堆积，电位更负；阳极失电子后金属溶解慢则正电荷积聚，电位更正。无论哪种极化，都会拉低原电池输出电压、抬高电解池外加电压。)
  • 过电位四大影响因素（PPT P39）：① 电流密度；② 温度；③ 电极材料（如 $\text{Pt}$）；④ 产物的物态（气体 > 金属离子）。

一、 电位分析法的核心定义与四类金属基电极（P40–44）

1.1 电位分析法定义（PPT P40）

电位分析法（Potentiometry）：测定含有被测物的电池电动势（$E_{\text{cell}}$），利用电极电位和溶液中待测离子的活度/浓度关系（能斯特方程），测量待测离子的活度/浓度。

1.2 第一类电极：金属 / 金属离子电极（PPT P41）

  • 构成与反应：纯金属 $M$ 浸入含自身阳离子 $M^{n+}$ 的溶液中；还原半反应 $M^{n+} + n e^- \to M(s)$。
  • 电极表达式：$\text{M}^{n+}(x\;\text{mol/L}) \mid \text{M}$（如 $\text{Cu}^{2+}(x\;\text{mol/L}) \mid \text{Cu}$）。
  • 能斯特控制方程（纯金属固体活度为 $1$，直接对本金属阳离子呈正斜率响应）： $$\varphi_{\text{Cu}^{2+},\text{Cu}} = \varphi^\ominus_{\text{Cu}^{2+},\text{Cu}} + \frac{0.059}{2}\lg c_{\text{Cu}^{2+}}, \qquad \boxed{\varphi_{M^{n+},M} = \varphi^\ominus_{M^{n+},M} + \frac{0.059}{n}\lg c_{M^{n+}}}$$

1.3 第二类电极：金属 / 金属难溶盐电极（PPT P42，以 $\text{Ag/AgCl}$ 为例）

用于测量阴离子（如 $\text{Cl}^-$）或当阴离子浓度固定时用作参比电极。

  • 总电极反应：$\text{AgCl} + e^- \to \text{Ag} + \text{Cl}^-$
  • 电极表达式（必考图式）： $$\boxed{\text{Cl}^-(x\;\text{mol/L}), \text{AgCl} \mid \text{Ag}}$$

  3. $2\text{Ag}^+ + 2e^- \to 2\text{Ag}$（按 $n=2$ 展开第一类银电极方程）： $$\begin{aligned} \varphi_{\text{Ag}_2\text{C}_2\text{O}_4,\text{Ag}} &= \varphi^\ominus_{\text{Ag}^+,\text{Ag}} + \frac{0.059}{2}\lg c_{\text{Ag}^+}^2 \\ &= \varphi^\ominus_{\text{Ag}^+,\text{Ag}} + \frac{0.059}{2}\lg\frac{K_{sp1}}{c_{\text{C}_2\text{O}_4^{2-}}} \\ &= \varphi^\ominus_{\text{Ag}^+,\text{Ag}} + \frac{0.059}{2}\lg\left(\frac{K_{sp1}}{K_{sp2}}c_{\text{Ca}^{2+}}\right) \\ &= \underbrace{\varphi^\ominus_{\text{Ag}^+,\text{Ag}} + \frac{0.059}{2}\lg\frac{K_{sp1}}{K_{sp2}}}_{\text{合并为第三类标准电位 }\varphi^{\ominus\prime}} + \frac{0.059}{2}\lg c_{\text{Ca}^{2+}} \end{aligned}$$ (物理直觉：当待测 $\text{Ca}^{2+}$ 浓度增大 $\implies$ 沉淀消耗 $\text{C}_2\text{O}_4^{2-}$ 使其降低 $\implies$ 迫使 $\text{Ag}_2\text{C}_2\text{O}_4$ 溶解度增大释放更多 $\text{Ag}^+$ $\implies$ 电位正移，对数项前恢复为*正号！)*

1.5 第零类电极：惰性金属电极（PPT P44）

惰性金属（如 $\text{Pt}$、$\text{Au}$）电极本身不发生化学反应，仅作为纯粹的电子导体（提供电子交换场所）测定气体或溶液中氧化还原电对的电位：

  1. 气体电极（标准氢电极）：
    • 电极反应：$2\text{H}^+ + 2e^- \to \text{H}_2(g)$
    • 电极表达式：$\boxed{\text{H}^+(x\;\text{mol/L}) \mid \text{H}_2(y\;\text{Pa}), \text{Pt}}$
    • 能斯特方程：$$\varphi_{\text{H}^+,\text{H}_2} = \varphi^\ominus_{\text{H}^+,\text{H}_2} + \frac{0.059}{2}\lg\frac{c_{\text{H}^+}^2}{p_{\text{H}_2}}$$
  2. 均相氧化还原电对电极：
    • 电极反应：$\text{Fe}^{3+} + e^- \to \text{Fe}^{2+}$
    • 电极表达式：$\boxed{\text{Fe}^{3+}(x\;\text{mol/L}), \text{Fe}^{2+}(y\;\text{mol/L}) \mid \text{Pt}}$
    • 能斯特方程：$$\varphi_{\text{Fe}^{3+},\text{Fe}^{2+}} = \varphi^\ominus_{\text{Fe}^{3+},\text{Fe}^{2+}} + 0.059\lg\frac{c_{\text{Fe}^{3+}}}{c_{\text{Fe}^{2+}}}$$

二、 离子选择性电极（ISE）构造与电位代数解耦（P45–46、P54）

  • 为什么需要 ISE？ 金属基电极依赖氧化还原反应，容易受溶液中其他氧化还原物质干扰，且无法直接检测 $\text{K}^+, \text{Na}^+, \text{F}^-$ 等活泼或非电活性离子。ISE 依靠敏感膜的选择性离子交换/渗透产生电位，不伴随氧化还原反应。
  • ISE 的三层基本构造（PPT P45 图）：
    1. 内参比电极（如 $\text{Ag/AgCl}$ 银丝，内部电位记为 $\varphi_M$）；
    2. 内参比溶液（密封恒定浓度的电解质溶液，电位记为 $\varphi_{\text{内}}$）；
    3. 敏感膜（位于电极底部，选择性让某些特定离子通过/交换，外部待测溶液电位记为 $\varphi_{\text{外}}$）。
最小闭环

【最小闭环：PPT P46 & P54“加减 $\varphi_{\text{内}}$”拆解 ISE 总电位】 根据电极电位的广义定义，整个 ISE 探头相对于外部待测溶液的总相间电位为 $\varphi_{\text{ISE}} = \varphi_M - \varphi_{\text{外}}$。 在中间插入一个恒等零项 $(-\varphi_{\text{内}} + \varphi_{\text{内}})$，即可将宏观总电位拆解为两个物理界面之和： $$\varphi_{\text{ISE}} = \varphi_M - \varphi_{\text{外}} = \underbrace{(\varphi_M - \varphi_{\text{内}})}_{\text{内参比电极的电位}} + \underbrace{(\varphi_{\text{内}} - \varphi_{\text{外}})}_{\text{跨膜电位 }\varphi_{\text{膜}}}$$

  • 第一项 $(\varphi_M - \varphi_{\text{内}})$：因为内参比溶液完全密封、成分恒定（如 $\text{Cl}^-$ 活度锁死），故内参比电极电位是一个严格不变的常数。
  • 第二项 $(\varphi_{\text{内}} - \varphi_{\text{外}})$：即跨膜电位 $\varphi_{\text{膜}}$，是整个电极唯一随外部待测离子活度 $a_1^s$ 变化的项。待第 4 节证明 $\varphi_{\text{膜}} = \text{常数} + \frac{0.059}{n}\lg a_1^s$ 后，代入即得 PPT P54 结论： $$\boxed{\varphi_{\text{ISE}} = \text{常数} + \frac{0.059}{n}\lg a_1^s}$$

三、 三种相界电位的本质对比与盐桥消噪原理（P47–51）

3.1 扩散电位（液接电位，PPT P47–48）

  • 定义（PPT P47）：在液-液接触界面上，由于不同离子通过界面的迁移率（扩散速度）不相等，从高浓度侧（$c_1$）向低浓度侧（$c_2$）扩散时形成电荷的不对称分布；当静电场力与扩散驱动力达到稳态平衡时，界面上产生的电位差称为扩散电位（液接电位）。
  • 计算通式（PPT P48）： $$\varphi_d = \varphi_2 - \varphi_1 = \pm\frac{0.059}{n}\lg\frac{c_2}{c_1} \qquad (\text{正负号由快慢阴阳离子的电性决定})$$

3.2 道南电位（Donnan Potential，PPT P49）

  • 定义（PPT P49）：两溶液间的隔膜是选择性渗透膜（如阳离子交换膜），仅允许特定离子穿过（如阳离子），绝对阻挡反号离子，从而造成选择性的离子扩散和膜两侧电荷分布不均，达到电化学势真平衡时形成的电位差。
  • 计算通式（PPT P49）： $$\varphi_{\text{Donnan}} = \varphi_2 - \varphi_1 = \pm\frac{0.059}{n}\lg\frac{c_2}{c_1} \qquad (\text{正负号由可穿透阴阳离子的电性决定})$$
最小闭环

【最小闭环：3 步从电化学势相等推出道南电位与符号规律】 设可穿透选择性膜的离子电荷数为 $z$（阳离子 $z=+n$，阴离子 $z=-n$），两侧达到热力学真平衡时电化学势相等： $$\bar{\mu}_1 = \bar{\mu}_2 \implies \mu^\ominus + RT\ln a_1 + zF\varphi_1 = \mu^\ominus + RT\ln a_2 + zF\varphi_2$$ 移项归拢电位差与活度比： $$zF(\varphi_2 - \varphi_1) = RT\ln\frac{a_1}{a_2} = -RT\ln\frac{a_2}{a_1}$$ 在 $25^\circ\text{C}$ 下换为常用对数（$\frac{2.303RT}{F} = 0.059\;\text{V}$）并取稀溶液近似 $a\approx c$： $$\varphi_2 - \varphi_1 = -\frac{0.059}{z}\lg\frac{c_2}{c_1}$$ 当可穿透离子为阳离子 ($z=+n$) 时取负号；当为阴离子 ($z=-n$) 时负负得正取正号——这正是 PPT P49 标注“正负号由阴阳离子电性决定”的数学根源。

电位类型 相际转移粒子与反应特征 热力学状态 与离子浓度的关系及工程取舍
1. 电极电位 电子在固-液两相间转移，伴随氧化还原反应 热力学平衡电位 有确定关系（服从 Nernst 方程），可用于离子检测 (√)
2. 道南电位 特定离子在膜两侧转移，不伴随氧化还原反应 热力学平衡电位 有确定关系（服从 Nernst 方程），可用于离子检测 (√，ISE 核心)

3.4 盐桥消除液接电位的原理（PPT P51）

  • 功能：用于电化学池中消除液接电位。
  • 核心配方与机理：盐桥内包含高浓度的 $\text{KCl}$ 或 $\text{KNO}_3$。
    1. 高浓度压制：高浓度盐桥向两侧稀溶液扩散的通量完全主导液接界面，压制了待测液中其他杂乱离子的扩散贡献；
    2. 阴阳离子扩散速度相当（等淌度）：$\text{K}^+$ 与 $\text{Cl}^-$（或 $\text{NO}_3^-$）的迁移率（无限稀释摩尔电导率：$\text{K}^+ = 73.52$，$\text{Cl}^- = 76.34$，$\text{NO}_3^- = 71.44$）几乎完全相等，同步跨界扩散时不产生净电荷不对称堆积，使液接电位趋近于 $0$。

四、 跨膜电位（$\varphi_{\text{膜}}$）的五层拆解与对数消元推导（P52–53）

这是 ISE 与 pH 玻璃电极最核心的理论推导：证明为什么无需知道敏感膜内部的任何微观参数，宏观跨膜电位就能直接线性响应外部待测溶液的离子活度 $\lg a_1^s$。

4.1 跨膜电位的空间阶梯拆解（PPT P52）

设敏感膜左侧为外部待测溶液（下标 $1$，电位 $\varphi_1^s$，活度 $a_1^s$），右侧为内参比溶液（下标 $2$，电位 $\varphi_2^s$，活度 $a_2^s$），膜外侧表层为 $\varphi_1^m (a_1^m)$，膜内侧表层为 $\varphi_2^m (a_2^m)$。 按 PPT P52 顺序逐步插项拆解：

  1. 宏观定义：$$\varphi_{\text{膜}} = \varphi_{\text{内}} - \varphi_{\text{外}} = \varphi_2^s - \varphi_1^s$$
  2. 插入膜两侧表层电位 $\varphi_2^m, \varphi_1^m$： $$\varphi_{\text{膜}} = (\varphi_2^s - \varphi_2^m) + (\varphi_2^m - \varphi_1^m) + (\varphi_1^m - \varphi_1^s)$$
  3. 对齐界面道南电位与膜内扩散电位符号： 定义外侧相界电位 $\varphi_1 \equiv \varphi_1^m - \varphi_1^s$，内侧相界电位 $\varphi_2 \equiv \varphi_2^m - \varphi_2^s$（故 $\varphi_2^s - \varphi_2^m = -\varphi_2$），膜内扩散电位 $\varphi_d \equiv \varphi_2^m - \varphi_1^m$，得： $$\boxed{\varphi_{\text{膜}} = -\varphi_2 + \varphi_d + \varphi_1}$$

4.2 代入能斯特项与对数级联消元（PPT P53 完整推导）

写出三项分量的热力学表达式（PPT P53 上半页）： $$\varphi_1 = k_1 + \frac{0.059}{n}\lg\frac{a_1^s}{a_1^m}, \qquad \varphi_d = \frac{0.059}{n}\lg\frac{a_1^m}{a_2^m}, \qquad \varphi_2 = k_2 + \frac{0.059}{n}\lg\frac{a_2^s}{a_2^m}$$

一步不跳的代数消元（PPT P53 下半页）：

  1. 代入总式 $\varphi_{\text{膜}} = -\varphi_2 + \varphi_d + \varphi_1$： $$\varphi_{\text{膜}} = -k_2 - \frac{0.059}{n}\lg\frac{a_2^s}{a_2^m} + \frac{0.059}{n}\lg\frac{a_1^m}{a_2^m} + \frac{0.059}{n}\lg\frac{a_1^s}{a_1^m} + k_1$$
  2. 翻转负对数项并合并：利用 $-\lg\frac{a_2^s}{a_2^m} = +\lg\frac{a_2^m}{a_2^s}$，将三个对数项做乘积合并： $$\begin{aligned} \varphi_{\text{膜}} &= -k_2 + \frac{0.059}{n}\lg\frac{a_2^m}{a_2^s} + \frac{0.059}{n}\lg\frac{a_1^m}{a_2^m} + \frac{0.059}{n}\lg\frac{a_1^s}{a_1^m} + k_1 \\ &= \frac{0.059}{n}\lg\left(\frac{\cancel{a_2^m}}{a_2^s} \cdot \frac{\cancel{a_1^m}}{\cancel{a_2^m}} \cdot \frac{a_1^s}{\cancel{a_1^m}}\right) + (k_1 - k_2) \\ &= \frac{0.059}{n}\lg\frac{a_1^s}{a_2^s} + (k_1 - k_2) \end{aligned}$$
  3. 施加“膜对称”条件与内参比锁死：
    • 若敏感膜两侧完全对称，则 $\varphi_d = 0$（即 $a_1^m = a_2^m$）且界面常数相等 $k_1 - k_2 = 0$；
    • 又因为内参比溶液密封，内部离子活度 $a_2^s$ 是常数，故 $-\frac{0.059}{n}\lg a_2^s$ 为常数。最终导出跨膜电位核心方程： $$\boxed{\varphi_{\text{膜}} = \frac{0.059}{n}\lg\frac{a_1^s}{a_2^s} = \text{常数} + \frac{0.059}{n}\lg a_1^s}$$
最小闭环

【最小闭环：为什么“膜对称”就一定有 $k_1 = k_2$ 且 $a_1^m = a_2^m$（$\varphi_d = 0$）？】

  1. 为什么 $k_1 = k_2$？ 相界电位的常数项源于标准态化学势差 $k = \frac{\mu^{\ominus,s} - \mu^{\ominus,m}}{nF}$。膜内外两侧接触的均为水溶液（$\mu^{\ominus,s}$ 相同），只要膜左右两个表面的材料结构与化学组成完全对称（$\mu^{\ominus,m}_{\text{左}} = \mu^{\ominus,m}_{\text{右}}$），必有 $k_1 = k_2$。（若膜老化或内外表面不完全一致，残留的 $k_1 - k_2 + \varphi_d \neq 0$ 就是 14-2 节要讲的不对称电位！）
  2. 为什么 $a_1^m = a_2^m$ 且 $\varphi_d = 0$？ 敏感膜内部均匀分布着固定浓度的负电格点（如玻璃膜中的 $\equiv\text{Si}-\text{O}^-$）。根据固体内部的电中性原理，进入膜内的阳离子浓度必须严格等于固定负格点的浓度；只要膜材质均匀对称，两侧表层结合的阳离子活度必然相等（$a_1^m = a_2^m$），膜内无浓度梯度，故 $\varphi_d = \frac{0.059}{n}\lg\frac{a_1^m}{a_2^m} = 0$。
  3. 更妙的数学鲁棒性：观察上面的第 2 步乘积式——哪怕不假设 $\varphi_d = 0$，把 $\varphi_d = \frac{0.059}{n}\lg\frac{a_1^m}{a_2^m}$ 代进去后，对数内部的 $a_1^m$ 和 $a_2^m$ 依然会在分子分母中自动对消！真正决定零点是否漂移的只有对称性差值 $(k_1 - k_2)$。

最小闭环

【最小闭环：甘汞电极系数“2”是如何完美约分的？什么叫“无液接参比”？】

  1. 甘汞电极推导：由 $\text{Hg}_2^{2+} + 2e^- \to 2\text{Hg}$ ($n=2$) 和 $K_{sp} = c_{\text{Hg}_2^{2+}}\cdot c_{\text{Cl}^-}^2$，代入得： $$\varphi = \varphi^\ominus_{\text{Hg}_2^{2+},\text{Hg}} + \frac{0.059}{2}\lg\left(\frac{K_{sp}}{c_{\text{Cl}^-}^2}\right) = \left(\varphi^\ominus_{\text{Hg}_2^{2+},\text{Hg}} + \frac{0.059}{2}\lg K_{sp}\right) - \frac{0.059}{\cancel{2}}\cdot \cancel{2}\lg c_{\text{Cl}^-} = \varphi^\ominus_{\text{Hg}_2\text{Cl}_2,\text{Hg}} - 0.059\lg c_{\text{Cl}^-}$$ 转移电子数 $n=2$ 与氯离子化学计量数 $2$ 恰好约分，最终斜率依然是 $-59\;\text{mV/decade}$！
  2. 为什么 $\text{Ag/AgCl}$ 可以做“无液接参比电极”（PPT P62）？ 普通参比电极需要外玻璃套管和陶瓷砂芯盐桥把内充 $\text{KCl}$ 与待测液隔开（存在液接界面）。如果待测溶液本身含有固定浓度的 $\text{Cl}^-$（例如血液/细胞外液生理盐水环境，且预先被 $\text{AgCl}$ 饱和防止银丝上的 $\text{AgCl}$ 溶解剥落），直接把一根裸露的 $\text{Ag/AgCl}$ 丝插进待测液，其电位就被待测液恒定的 $c_{\text{Cl}^-}$ 锁死，在物理上彻底消灭了“液-液接触界面”与砂芯套管，故液接电位严格为 $0$。

三、 工作电极 / 参比电极 / 对电极：三电极双回路（P64）

在需要通过电流的电化学测量（如第 16 章伏安法）或高精度测控中，为了防止电流流过参比电极引起极化和 $IR$ 降，引入三电极体系（PPT P64）：

  • 三个电极的功能定位：
    1. 指示电极 / 工作电极（WE）：电极电位（或电流）在一定实验条件下能够跟踪被检测物的活度/浓度变化。
    2. 参比电极（RE）：提供恒定标准电位的电极（内部高阻抗断路，绝对不走电流，从而永不极化）。
    3. 辅助电极 / 对电极（CE）：和工作电极形成闭合回路，专门提供电流通过的场所（通常为惰性 $\text{Pt}$ 丝或石墨）。
  • 双回路解耦（PPT P64 必记对应关系）：
    • 工作电极与参比电极（WE – RE）：构成电压回路（高阻测电位，$I \approx 0$）；
    • 工作电极与对电极（WE – CE）：构成电流回路（低阻承载全部电解电流）。

四、 玻璃电极（pH 电极）：构造、硅氧断链与水化层膜电位（P65–69）

4.1 宏观四部分构造（PPT P65）

  1. 高阻玻璃壳体（支撑与绝缘隔离）；
  2. 内参比电极：银-氯化银电极（$\text{Ag/AgCl}$）；
  3. 内参比溶液：$0.1\;\text{mol/L HCl}$（一举两得：既提供固定浓度的 $\text{Cl}^-$ 锁死内参比 $\text{Ag/AgCl}$ 电位，又提供固定浓度的 $\text{H}^+$ 锁死玻璃膜内表面活度 $a_2^s$）；
  4. 敏感膜：底部约 $100\;\mu\text{m}$ ($0.1\;\text{mm}$) 厚的特制玻璃膜。

4.2 特制玻璃膜的硅氧键断裂与“三明治”水化层（PPT P66–67）

  • 为什么普通石英玻璃不导电，而特制玻璃膜对 $\text{H}^+$ 敏感（PPT P66）？ 纯石英玻璃是致密的三维硅氧网络（$\equiv\text{Si}^{\text{IV}}-\text{O}-\text{Si}^{\text{IV}}\equiv$）。熔炼特制玻璃膜时加入碱金属氧化物（如 $\text{Na}_2\text{O}$），使部分的硅氧键断裂，生成带负电的固定硅氧交换质点（$\equiv\text{Si}^{\text{IV}}-\text{O}^-$）和可移动的抗衡离子（$\text{Na}^+$），大幅提升离子透过性与交换性： $$\equiv\text{Si}^{\text{IV}}-\text{O}-\text{Si}^{\text{IV}}\equiv \;+\; \text{Na}_2\text{O} \longrightarrow 2\left(\equiv\text{Si}^{\text{IV}}-\text{O}^- \text{Na}^+\right)$$
  • 浸泡活化后的“三明治”五层空间结构（PPT P67 图）： 玻璃电极使用前必须在水中浸泡活化，膜两侧表面吸水溶胀形成约 $10^{-4}\;\text{mm}$ ($100\;\text{nm}$) 厚的水化凝胶层，发生水相 $\text{H}^+$ 与玻璃相 $\text{Na}^+$ 的离子交换平衡： $$\equiv\text{Si}-\text{O}^-\text{Na}^+_{\text{(膜)}} + \text{H}^+_{\text{(液)}} \rightleftharpoons \equiv\text{Si}-\text{O}^-\text{H}^+_{\text{(膜)}} + \text{Na}^+_{\text{(液)}}$$ 空间结构从外到内依次为（对应 PPT P67 图示标注）： $$\text{外部试液 }\big[a(\text{H}^+)=x\big] \;\Big|\; \text{外水化层 }(10^{-4}\text{ mm}) \;\Big|\; \text{干玻璃层 }(0.1\text{ mm，}\text{Na}^+\text{ 迁移导电}) \;\Big|\; \text{内水化层 }(10^{-4}\text{ mm}) \;\Big|\; \text{内部试液 }\big[a(\text{H}^+)=\text{定值}\big]$$ (注：在水化层内，越靠近溶液侧 $a(\text{H}^+)$ 越高，越靠近干玻璃层 $a(\text{Na}^+)$ 越高；干玻璃层内部 $\text{H}^+$ 无法穿透，靠 $\text{Na}^+$ 在晶格间隙内微距跃迁完成电荷接力传导。)

4.3 玻璃电极膜电位推导与不对称电位（PPT P68–69）

如图 P68 所示，由于左右两侧各有一个水化层，内部扩散电位拆成外水化层扩散电位 $\varphi_{d1}$ 与内水化层扩散电位 $\varphi_{d2}$： $$\varphi_{\text{膜}} = -\varphi_2 + \varphi_{d1} + \varphi_{d2} + \varphi_1 = -k_2 - \frac{0.059}{n}\lg\frac{a_2^s}{a_2^m} + \varphi_{d1} + \varphi_{d2} + \frac{0.059}{n}\lg\frac{a_1^s}{a_1^m} + k_1$$

  • 对称消元（PPT P69）：如果玻璃膜两侧的水化凝胶层完全对称，则： $$\varphi_{d1} + \varphi_{d2} = 0, \qquad a_2^m = a_1^m, \qquad k_1 = k_2$$ 代入 $n=1$ 及 $\text{pH} = -\lg a(\text{H}^+)$，由于内部试液 $a_2^s$ 是定值，方程化简为： $$\boxed{\varphi_{\text{膜}} = \frac{0.059}{1}\lg\frac{a_1^s}{a_2^s} = \text{常数} + 0.059\lg c(\text{H}^+) = \text{常数} - 0.059\,\text{pH}}$$ 结论：在一定温度下，玻璃电极膜电位与溶液 $\text{pH}$ 值呈严格线性关系（每单位 $\text{pH}$ 变化对应 $59\;\text{mV}$）。
  • 不对称电位（Asymmetry Potential，PPT P69）： 实际玻璃膜内外表面的几何曲率、热历史和水化程度不可能绝对对称（即使两侧装完全相同的溶液，$\varphi_{d1}+\varphi_{d2}$ 与 $k_1-k_2$ 也不完全为 $0$），残留的常数偏差称为不对称电位。通过充分浸泡稳定玻璃膜水化凝胶层并在使用前用标准缓冲液校准即可消除。

五、 pH 测量范围误差（碱差/酸差）与离子选择性系数（P70–71）

5.1 测量范围两端的偏差：碱差与酸差（PPT P70 必考简答）

普通玻璃 pH 电极的线性测量范围通常为 $\text{pH } 1 \sim 10$，在两端极端条件下会产生偏差：

  1. 碱差 / 钠差（$\text{pH} > 10$ 或 $\text{Na}^+$ 浓度较高时）：
    • 现象：测得的 $\text{pH}$ 值往往偏低（$\text{pH}_{\text{测}} < \text{pH}_{\text{真}}$）。
    • 原因（PPT P70 原文）：在 $\text{pH} > 10$（$c_{\text{H}^+}$ 极低）且 $\text{Na}^+$ 浓度较高时，水化凝胶层形成的离子交换过程中，钠离子也与氢离子竞争、共同参与离子交换，因此钠离子也对膜电位产生正贡献，使电极反映出来的表观氢离子活度偏高，取负对数后测得的 $\text{pH}$ 偏低。（工程改进：用半径更大的 $\text{Li}_2\text{O}$ 代替 $\text{Na}_2\text{O}$ 制造锂玻璃电极，可将上限扩展至 $\text{pH } 13\sim 14$）。
  2. 酸差（$\text{pH} < 1$ 的强酸溶液）：
    • 现象：测得的 $\text{pH}$ 值产生偏差（往往偏高，$\text{pH}_{\text{测}} > \text{pH}_{\text{真}}$）。
    • 原因：水化凝胶层表面位点已被 $\text{H}^+$ 饱和，且强酸高浓度下水分子活度下降、酸根阴离子渗入水化层破坏道南排斥平衡。

5.2 离子选择性系数与尼科尔斯基-艾森曼方程（PPT P71）

理想情况下 ISE 只对主响应离子 $i$（电荷数 $n_i$）响应；当被测体系中还含有干扰离子 $j$（电荷数 $n_j$）时，干扰离子对电极电位的贡献用扩展的 Nernst 方程（Nicolsky-Eisenman 方程）表示为：

  • 单一干扰离子形式： $$\boxed{\varphi_{\text{膜}} = \text{常数} \pm \frac{2.303RT}{n_i F}\lg\left(a_i + K_{i,j}^{\text{pot}}\,a_j^{\frac{n_i}{n_j}}\right)}$$ (其中阳离子电极取 $+$ 号，阴离子电极取 $-$ 号。)
  • 多干扰离子通用求和形式（PPT P71 底部）： $$\varphi_{\text{膜}} = \text{常数} \pm \frac{2.303RT}{n_i F}\lg\left(a_i + \sum_j K_{i,j}^{\text{pot}}\,a_j^{\frac{n_i}{n_j}}\right)$$
  • $K_{i,j}^{\text{pot}}$ 的物理意义：称为干扰离子 $j$ 对被测离子 $i$ 的选择性系数，度量敏感膜对 $j$ 相对于 $i$ 的响应能力比值。$K_{i,j}^{\text{pot}}$ 越小，说明电极对主离子 $i$ 的选择性越好、抗 $j$ 干扰能力越强。

六、 pH 实用测量定义、单/双点校准与第 6 章全景总结（P72–75）

6.1 pH 测量的实用定义与校准方法（PPT P72，核心计算必考）

由于玻璃电极存在无法预先准确测出的常数项 $k$（包含内/外参比电位、液接电位及随时间缓慢漂移的不对称电位），实际测量采用与标准缓冲溶液比较的方法：

  • 电池组成与极性约定（PPT P72 原文）：
    • 标准液电池：$\boxed{\text{玻璃电极（阳极）} \parallel \text{标准溶液 pH}_s \parallel \text{S.C.E.（阴极）}}$
    • 待测液电池：$\boxed{\text{玻璃电极（阳极）} \parallel \text{待测溶液 pH}_x \parallel \text{S.C.E.（阴极）}}$
最小闭环

【最小闭环：为什么 P69 中 $\varphi_{\text{膜}} = \text{常数} - 0.059\,\text{pH}$ 是负号，而 P72 中 $E = k + \frac{2.303RT}{F}\text{pH}$ 变成了正号？】 关键在于 PPT P72 明确将玻璃电极规定为阳极（左），将饱和甘汞电极（S.C.E.）规定为阴极（右）！ 代入全电池电动势定义 $E = \varphi_{\text{阴}} - \varphi_{\text{阳}}$： $$E = \varphi_{\text{SCE}} - \varphi_{\text{玻璃}} = \varphi_{\text{SCE}} - \left(\varphi_{\text{内参比}} + \text{常数}_{\text{膜}} - \frac{2.303RT}{F}\text{pH}\right) = \underbrace{\left(\varphi_{\text{SCE}} - \varphi_{\text{内参比}} - \text{常数}_{\text{膜}}\right)}_{\text{合并为总截距常数 }k} + \frac{2.303RT}{F}\text{pH}$$ 因为玻璃电极作阳极被减去，负负得正，所以电动势 $E$ 与 $\text{pH}$ 的斜率项变成了正号！

  • 比较法消除未知截距 $k$（PPT P72 推导）：
    1. 测标准缓冲溶液（已知 $\text{pH}_s$）：$$E_s = k_s + \frac{2.303RT}{F}\text{pH}_s$$
    2. 测待测溶液（未知 $\text{pH}_x$）：$$E_x = k_x + \frac{2.303RT}{F}\text{pH}_x$$
    3. 测试条件相同时 $k_s = k_x$，两式相减消去 $k$： $$E_x - E_s = \frac{2.303RT}{F}(\text{pH}_x - \text{pH}_s) \implies \boxed{\text{pH}_x = \text{pH}_s + \frac{F(E_x - E_s)}{2.303RT}}$$
  • 单点校准（定位）vs. 双点校准（斜率校准，PPT P72 底部原话）：
    • 已知温度且电极斜率理想时（单点比较法）：只需 1 种标准缓冲液（$\text{pH}_s$）标定截距 $k$（即定位零点，消除不对称电位）。
    • 若温度未知，或电极老化导致实际斜率偏离理论值 $\frac{2.303RT}{F}$ 时（双点校准）：需用 两个标准 $\text{pH}$ 缓冲溶液（$\text{pH}_{s1}, \text{pH}_{s2}$）校准斜率 $S = \frac{E_{s2} - E_{s1}}{\text{pH}_{s2} - \text{pH}_{s1}}$，再计算 $\text{pH}_x = \text{pH}_{s1} + \frac{E_x - E_{s1}}{S}$。

七、 真题靶向加厚：溶度积 $K_{sp}$ + Nernst + 选择性系数误差边界（26-计8）

此类压轴计算题将“化学沉淀平衡 + 能斯特校准 + 干扰离子误差限”三合一，固定按以下三步拆解：

  1. 标准液单点校准常数 $K$：将已知标准浓度 $[A]_1$ 与测得电动势 $E_1$ 代入 $E = K + S\lg[A]$（注意 $25^\circ\text{C}$ 下 $S = \frac{0.0592}{n}\;\text{V}$），反解仪器常数 $K$。
  2. 由溶度积 $K_{sp}$ 求待测液游离主离子浓度 $[A]_{\text{真}}$：对于难溶盐 $A_p B_q(s) \rightleftharpoons p A + q B$，由 $K_{sp} = [A]^p [B]^q$ 与已知沉淀剂过量离子浓度 $[B]$，算出 $[A]_{\text{真}}$ 并代回校准后的能斯特方程求 $E_2$。
  3. Nikolsky-Eisenman 误差边界反推干扰离子浓度上限： $$[A]_{\text{测}} = [A]_{\text{真}} + K_{A,B}^{\text{pot}}\cdot\big([B]\big)^{n_A/n_B}$$ 由允许相对误差上限 $\delta_{\max}$（如 $5\%$）： $$\boxed{\text{相对误差} = \frac{K_{A,B}^{\text{pot}}\cdot\big([B]\big)^{n_A/n_B}}{[A]_{\text{真}}} \le \delta_{\max}}$$ 解此不等式即可直接求出干扰离子 $[B]$ 的最大允许浓度！

最小闭环

【最小闭环：氟电极的检测下限与酸碱双向干扰（PPT P9 原文填空逻辑）】

  1. 为什么检测下限锁定在 $1\times 10^{-6}\;\text{mol/L}$？ $\text{LaF}_3$ 是难溶盐，浸入水中存在溶解平衡 $\text{LaF}_3(s) \rightleftharpoons \text{La}^{3+} + 3\text{F}^-$（$K_{sp} = [\text{La}^{3+}][\text{F}^-]^3 \approx 2\times 10^{-19}$）。设自身微溶度为 $s$，则 $K_{sp} = s(3s)^3 = 27s^4 \implies s \approx (2\times 10^{-19}/27)^{1/4} \approx 9.3\times 10^{-6}\;\text{mol/L}$，故游离 $\text{F}^-$ 本底在 $10^{-6}\;\text{mol/L}$ 量级，低于此值时信号被晶体自溶噪声淹没。
  2. 为什么 $\text{OH}^-$ 是主要干扰离子，且使检测结果偏高？ $\text{OH}^-$ 半径与 $\text{F}^-$ 极接近，且 $\text{La(OH)}_3$ 比 $\text{LaF}_3$ 更难溶，发生沉淀转化反应： $$\text{LaF}_3 + 3\text{OH}^- \longrightarrow \text{La(OH)}_3\downarrow + 3\text{F}^-$$ 该反应在电极表面释放出额外的游离 $\text{F}^-$，导致测得 $\text{F}^-$ 浓度偏高（PPT P9 第 6 行结论）。
  3. 为什么 $\text{pH}$ 过小时检测结果偏低？ $\text{pH}$ 过低（强酸）时，$\text{H}^+$ 与 $\text{F}^-$ 结合成不电离的弱酸分子 $\text{HF}$（及 $\text{HF}_2^-$），而氟电极只响应游离 $\text{F}^-$，导致测得 $\text{F}^-$ 浓度偏低（PPT P9 第 7 行结论）。
  4. 最佳 $\text{pH}$ 窗口与 TISAB：因此测 $\text{F}^-$ 时需将 $\text{pH}$ 控制在 $5 \sim 6.5$，并加入**总离子强度调节缓冲液（TISAB）**以同时稳住 $\text{pH}$、掩蔽干扰金属离子并固定活度系数 $\gamma$。

4.1 构造与级联化学平衡推导（PPT P15–16，核心必考推导）

气体分子不带电，无法直接产生膜电位。$\text{CO}_2$ 气敏电极（Severinghaus 电极） 采用三级串联结构： $$\text{待测 } \text{CO}_2 \xrightarrow{\text{疏水透气膜}} \text{中介液}(0.01\;\text{mol/L }\text{NaHCO}_3 + 0.01\;\text{mol/L }\text{NaCl}) \xrightarrow{\text{电离产 }\text{H}^+} \text{内层玻璃 }\text{pH 电极}$$

最小闭环

【最小闭环：PPT P16 $\text{CO}_2$ 电极能斯特方程 4 步推导】

  1. 气-液溶解平衡（亨利定律）：$\text{CO}_2 + \text{H}_2\text{O} \rightleftharpoons \text{H}_2\text{CO}_3$，平衡常数 $K_1 = \frac{a(\text{H}_2\text{CO}_3)}{p(\text{CO}_2)}$
  2. 碳酸一级解离平衡：$\text{H}_2\text{CO}_3 \rightleftharpoons \text{HCO}_3^- + \text{H}^+$，平衡常数 $K_2 = \frac{a(\text{HCO}_3^-)\,a(\text{H}^+)}{a(\text{H}_2\text{CO}_3)}$
  3. 消去中间态 $\text{H}_2\text{CO}_3$ 并利用高浓 $\text{NaHCO}_3$ 锁死 $a(\text{HCO}_3^-)$： 中介液中含有高达 $0.01\;\text{mol/L}$ 的 $\text{NaHCO}_3$（完全电离），远大于 $\text{H}_2\text{CO}_3$ 自身解离出的 $\text{HCO}_3^-$，因此 $a(\text{HCO}_3^-)$ 很大且恒定为常数： $$a(\text{H}^+) = \frac{K_1 K_2\, p(\text{CO}_2)}{a(\text{HCO}_3^-)} = \text{常数} \times p(\text{CO}_2)$$
  4. 代入内层玻璃 pH 电极电位公式： $$\boxed{\varphi_{\text{膜}} = \text{常数} + 0.059\lg a(\text{H}^+) = \text{常数} + 0.059\lg p(\text{CO}_2)}$$ (物理直觉：$p(\text{CO}_2)$ 升高 $\implies$ 中介液产酸 $a(\text{H}^+)$ 增大 $\implies$ 玻璃电极电位正移，斜率为 $+59\;\text{mV/dec}$。)

一、 伏安法与经典直流极谱法基础（P21–26）

1.1 定义与电极配置（PPT P21–23）

  • 伏安分析法（Voltammetry）：通过测量电解池的电流–电压（$i–E$）曲线来进行定性与定量分析的方法（1922 年 Heyrovsky 创立极谱法，1959 年获诺贝尔奖）。
  • 极谱法（Polarography）：特指使用**滴汞电极（DME）**作为工作电极的伏安法。
    • 工作电极（滴汞电极）：面积很小、电流密度大，为极化电极（电位随外加电压显著变化，发生浓差极化）。

最小闭环

【最小闭环：为什么极谱法要用“一滴滴落”的汞？】

  1. 汞滴周期性滴落使电极表面不断更新，彻底避免固体电极表面中毒、钝化或产物累积，重现性极高；
  2. 氢在汞上的超电位极大，可在较负电位（还原金属离子）下不析出 $\text{H}_2$ 干扰。

1.2 极谱波中的三个电流（PPT P25）

以典型金属离子在滴汞电极上的还原反应为例（PPT P25 原式）： $$\text{Cd}^{2+} + 2e^- + \text{Hg} \rightleftharpoons \text{Cd(Hg)}$$ 在极谱波中，从零电流到平台区包含三个关键参量： $$\boxed{i_d = i_l - i_r}$$

  • $i_l$（极限电流）：电位足够负时达到的平台总电流；
  • $i_r$（残余电流）：背景电解质与双电层充电电流构成的基线本底；
  • $i_d$（极限扩散电流）：扣除残余电流后，纯粹由待测离子扩散控制的极限电流（$i_d$ 正比于待测物浓度 $c$）。

二、 尤考维奇（Ilkovič）方程推导（P26）

回顾 13-2 节平面电极 Cottrell 方程：$i_d = \frac{nFAD_O c^*}{\sqrt{\pi D_O t}}$（扩散层厚度 $\delta_{\text{平面}} = \sqrt{\pi D t}$）。 在滴汞电极上，汞滴一边生长（面积 $A$ 随时间增大），一边向内扩张的球面使扩散层更薄：

  • 滴汞电极扩散层厚度（PPT P26）：$$\delta_{\text{滴汞}} = \sqrt{\frac{3}{7}\pi D t}$$
  • 瞬时极限扩散电流（Ilkovič 方程）： $$i_d = 708\, n\, D^{1/2}\, m^{2/3}\, t^{1/6}\, c$$
  • 平均极限扩散电流（一个滴汞周期 $0\sim t$ 内积分平均，PPT P26 红字）： $$\boxed{\bar{i}_d = \frac{1}{t}\int_0^t i_d\,dt = 607\, n\, D^{1/2}\, m^{2/3}\, t^{1/6}\, c}$$
最小闭环

【最小闭环：从球体体积积分一步不跳推出 Ilkovič 方程系数 $708$ 与 $607$】

  1. 精确求汞滴表面积 $A(t)$：汞流速度为 $m\;(\text{mg/s})$，经时间 $t$ 滴出的汞质量为 $mt$，体积 $V = \frac{mt}{\rho_{\text{Hg}}} = \frac{4}{3}\pi r^3$（$\rho_{\text{Hg}} = 13.53\;\text{g/cm}^3$），解出半径 $r(t) = \left(\frac{3mt}{4\pi\rho_{\text{Hg}}}\right)^{1/3}$。代入球面积公式 $A(t) = 4\pi r^2$： $$A(t) = 4\pi\left(\frac{3}{4\pi\rho_{\text{Hg}}}\right)^{2/3} m^{2/3} t^{2/3}$$
  2. 代入膨胀球面扩散电流方程：滴汞向外生长压缩了扩散层厚度，精确求解膨胀球坐标扩散方程得 $\delta_{\text{滴汞}} = \sqrt{\frac{3}{7}\pi D t}$。将 $A(t)$ 与 $\delta_{\text{滴汞}}$ 同时代入 $i_d = nFAD\frac{c}{\delta}$： $$i_d(t) = nF \cdot 4\pi\left(\frac{3}{4\pi\rho_{\text{Hg}}}\right)^{2/3} m^{2/3} t^{2/3} \cdot D\frac{c}{\sqrt{\frac{3}{7}\pi D t}} = \underbrace{4\pi\left(\frac{3}{4\pi\rho_{\text{Hg}}}\right)^{2/3}\sqrt{\frac{7}{3\pi}} F \cdot (\text{单位换算})}_{=\,708}\cdot n\,D^{1/2}\,m^{2/3}\,t^{1/6}\,c$$ 可见幂律 $\frac{2}{3} - \frac{1}{2} = \frac{1}{6}$ 完全由球面几何面积与扩散层生长相除自然涌现！
  3. 积分求平均极限扩散电流系数 $607$：在一个滴汞周期 $[0, t]$ 内对 $i_d(\tau)$ 取时间积分平均： $$\bar{i}_d = \frac{1}{t}\int_0^t 708\,n D^{1/2} m^{2/3} c \cdot \tau^{1/6}\,d\tau = 708\,n D^{1/2} m^{2/3} c \cdot \frac{1}{t}\left[\frac{6}{7}\tau^{7/6}\right]_0^t = \left(708\times\frac{6}{7}\right) n D^{1/2} m^{2/3} t^{1/6} c = \mathbf{607}\,n D^{1/2} m^{2/3} t^{1/6} c$$

三、 极谱波方程与半波电位 $\varphi_{1/2}$（P27）

对于快速可逆电极反应 $O + n e^- \rightleftharpoons R$（初始 $C_O = C^*,\; C_R = 0$），在任意电位 $\varphi$ 下，电极表面活度（稀溶液近似浓度）仍满足 Nernst 方程： $$\varphi = \varphi^\circ + \frac{RT}{nF}\ln\frac{[a_O]_s}{[a_R]_s}$$

最小闭环

【最小闭环：从 Ilkovič 比例式 3 步推出极谱波方程与半波电位】

  1. 用电流表达表面浓度：根据 Ilkovič 方程，瞬时阴极电流正比于主相与表面浓度差，极限电流对应 $[c_O]_s \to 0$： $$i_c = k\big([c_O] - [c_O]_s\big) = k'[c_R]_s, \qquad (i_d)_c = k[c_O]$$ （其中 $k \propto D^{1/2}, \; k' \propto D'^{1/2}$，$D, D'$ 分别为 $O, R$ 的扩散系数）。
  2. 反解表面浓度比值：由上两式相减得 $k[c_O]_s = (i_d)_c - i_c \implies [c_O]_s = \frac{(i_d)_c - i_c}{k}$，且 $[c_R]_s = \frac{i_c}{k'}$。代入 Nernst 方程： $$\varphi = \varphi^\circ + \frac{RT}{nF}\ln\left(\frac{k'}{k}\cdot\frac{(i_d)_c - i_c}{i_c}\right) = \varphi^\circ + \frac{RT}{nF}\ln\left(\frac{D'}{D}\right)^{1/2} + \frac{RT}{nF}\ln\frac{(i_d)_c - i_c}{i_c}$$
  3. 定义半波电位 $\varphi_{1/2}$：令 $i_c = \frac{(i_d)_c}{2}$，对数第二项 $\ln(1) = 0$，此时对应的电位即为半波电位： $$\boxed{\varphi_{1/2} = \varphi^\circ + \frac{RT}{nF}\ln\left(\frac{D'}{D}\right)^{1/2}}$$ 故极谱波方程简写为：$\varphi = \varphi_{1/2} + \frac{RT}{nF}\ln\frac{(i_d)_c - i_c}{i_c}$。 核心性质：$\varphi_{1/2}$ 与待测物浓度 $c$ 无关，只取决于电对本性 $\varphi^\circ$ 和扩散系数比，因此是极谱定性分析的指纹依据（如图 P27 中 $\text{Pb}^{2+}$ 与 $\text{Cd}^{2+}$ 各自在特征 $\varphi_{1/2}$ 处出波）。

四、 单扫描极谱法与 Randles-Sevcik 方程（P28–29）

  • 单扫描极谱法（示波极谱法）：在一滴汞生长后期，快速施加一次线性扫描电压，用示波器记录电流响应。由于扫速极快，表面反应物瞬间耗尽后来不及补充，电流达到峰值后迅速衰减，形成峰形曲线而非 S 形平台。

【最小闭环：为什么 Clark 氧电极测出的极限电流 $i_d$ 与氧分压 $p_{\text{O}_2}$ 严格成正比？】

  1. 外部样本中的溶解氧分压 $p_{\text{O}_2}$ 由亨利定律决定膜外表面氧浓度 $c_{\text{O}_2}^* = S \cdot p_{\text{O}_2}$。

  • 几何特征：电极尺寸微米级（半径 $r \sim \mu\text{m}$）。

最小闭环

【最小闭环：球坐标扩散方程 4 步推出超微电极稳态电流 $i = 4\pi nFDc_0 r$】

  1. 球对称 Fick 第二定律：对半径为 $r_0$ 的微球电极，球坐标下的径向扩散方程为： $$\frac{\partial c}{\partial t} = D\frac{1}{r^2}\frac{\partial}{\partial r}\left(r^2\frac{\partial c}{\partial r}\right)$$
  2. 稳态解（$t$ 足够大时 $\frac{\partial c}{\partial t} = 0$）：方程退化为常微分方程： $$\frac{d}{dr}\left(r^2\frac{dc}{dr}\right) = 0 \implies r^2\frac{dc}{dr} = C_1 \implies c(r) = -\frac{C_1}{r} + C_2$$
  3. 代入边界条件：无穷远 $r\to\infty$ 处 $c = c_0 \implies C_2 = c_0$；电极表面 $r=r_0$ 处极限耗尽 $c(r_0) = 0 \implies C_1 = c_0 r_0$。故稳态浓度分布为： $$c(r) = c_0\left(1 - \frac{r_0}{r}\right)$$
  4. 计算表面梯度与总电流：对 $r$ 求导得表面浓度梯度 $\left.\frac{dc}{dr}\right|_{r=r_0} = \frac{c_0 r_0}{r_0^2} = \frac{c_0}{r_0}$。乘以球表面积 $A = 4\pi r_0^2$、扩散系数 $D$ 与 $nF$，即得与时间无关的稳态极限电流（记半径为 $r$）： $$i = nF(4\pi r^2)D\frac{c_0}{r} = \boxed{4\pi nFDc_0 r}$$ (而完整含时解正是 PPT P36 给出的 $i = 4\pi nFDc_0\left(r + \frac{r^2}{\sqrt{\pi D_O t}}\right)$：当 $\sqrt{\pi D_O t} \gg r$ 时平面瞬态项消失，只剩径向汇聚稳态项！)

一、 半导体物理最小前置底座（P39–43）

在化学传感器中，电化学换能器占约 $90\%$，而另外 $10\%$（尤其是微型化、集成化芯片和生物传感器）由半导体器件、光、压电、热敏等其他换能器承担（PPT P39）。

    • n 型掺杂：在四价硅中掺入五价元素（如磷 $\text{P}$），多出自由电子，以电子为多数载流子；
    • p 型掺杂：在四价硅中掺入三价元素（如硼 $\text{B}$），缺少电子形成空穴，以空穴为多数载流子。
  • p–n 结与场效应晶体管（FET，PPT P41–43）：
    • FET 优势：灵敏度高、响应迅速、输出阻抗低（对比玻璃电极的 $10^9\;\Omega$ 高内阻，实现了原位阻抗变换），且利用微纳加工工艺易于微型化和集成化（PPT P43）。

二、 离子敏感场效应管（ISFET）结构与工作原理（P44–49）

2.1 从 MOSFET 到 ISFET 的结构替换（PPT P44–45）

  • 传统 MOSFET：源极（S）、漏极（D）、金属栅极（G）、绝缘层与衬底（如 p-Si）。
  • ISFET（Ion Sensitive Field Effect Transistor）：去掉传统 FET 的金属栅极，在绝缘层上直接沉积一层离子选择性敏感膜，并将待测溶液与参比电极置于敏感膜上方构成液相栅极回路（PPT P44–45）。

2.2 工作原理与有效栅压方程（PPT P46–47）

  1. 敏感膜与被测溶液界面建立道南/能斯特膜电位 $\varphi_i$，该电位串联叠加在栅极回路中，改变实际施加在绝缘膜与半导体表面的有效栅源电压 $V'_{GS}$（PPT P47）： $$\boxed{V'_{GS} = V_{GS} - \varphi_i - \varphi_{\text{ref}}}$$ (其中 $V_{GS}$ 为外加偏压，$\varphi_{\text{ref}}$ 为参比电极恒定电位。)
  2. 生物传感器拓展核心（PPT P47 下）：只要设法利用生化反应过程产生的物质（如 $\text{H}^+$、电荷变化）去改变膜电位 $\varphi_i$，就能调制沟道导电性并输出漏源电流 $I_D$ 的变化——这就是第 18–21 章 BioFET（酶FET / 免疫FET / 适配体FET） 的通用原理。
  3. 微型 $\text{K}^+$ ISFET 实例（PPT P48–49）：在 ISFET 栅区表面涂覆含缬氨霉素的敏感膜，直接将高阻敏感膜耦合到栅极，大幅减小输出阻抗，可用于细胞膜内外 $\text{K}^+$ 活度测量。

三、 ISFET 固态 pH 传感器数学闭环推导（P50–52）

以 p-沟道 ISFET 固态 $\text{pH}$ 传感器为例（PPT P50 图 4-12）：

  1. 氢离子敏感膜建立能斯特响应（PPT P50）： $$E = E^0 + 2.303\frac{RT}{nF}\ln a_{\text{H}^+} \quad (\text{改写为 }\text{pH}\text{ 形式：}\Delta E = K \cdot \text{pH},\; K = \frac{2.303RT}{F})$$
  2. 阈值电压 $V_T$ 随 $\text{pH}$ 线性平移（PPT P51）： 源极接地，阈值电压指漏源之间刚好导通时的栅源电压： $$|V_{GS}| = |E + E_{\text{ref}}|, \qquad |V_T| = |E + E_{\text{ref}}| - |\Delta E| = |E + E_{\text{ref}}| - |K\cdot\text{pH}|$$
  3. 线性区漏源电流 $I_{GS}$ 方程（PPT P52）： 实际应用时应避开饱和区（工作在线性区），当外加偏压 $V_{GS}$ 恒定时，化简后的漏源电流为： $$\boxed{I_{GS} = \frac{-\mu C W}{2L}\big(|K\cdot\text{pH}| - 0.5|V_{GS}|\big)\cdot |V_{GS}|}$$ (其中 $\mu$ 为沟道载流子迁移率，$C$ 为单位面积栅绝缘层电容，$W/L$ 为沟道宽长比。)

【最小闭环：从 MOSFET 线性区电流方程推导 PPT P52 的 ISFET 线性响应】

  1. MOSFET 线性区（非饱和区）标准电流公式：当 $|V_{DS}| < |V'_{GS} - V_T|$ 时，沟道漏源电流为： $$I_{DS} = \frac{\mu C W}{L}\left[(V'_{GS} - V_T)V_{DS} - \frac{1}{2}V_{DS}^2\right]$$

【最小闭环：Beer-Lambert 定律积分推导与双波长指夹血氧仪如何消去手指厚度 $l$？】

  1. Beer 定律微分推导：光强为 $I$ 的单色光穿过厚度 $dl$、浓度 $c$ 的吸光介质，被吸收的光强增量正比于 $I$、$c$ 与 $dl$： $$\frac{dI}{I} = -\kappa c\,dl$$ 从 $0\to l$（光强 $I_0 \to I$）积分得 $\ln\frac{I_0}{I} = \kappa c l$，换为常用对数定义吸光度 $A$： $$A \equiv \lg\frac{I_0}{I} = \frac{\kappa}{2.303} l c = \varepsilon l c$$
  2. 双波长消去未知光程 $l$：在手指动脉搏动脉动分量上，吸光物质为 $\text{HbO}_2$（浓度 $c_1$）和 $\text{Hb}$（浓度 $c_2$），分别在 $\lambda_1=660\;\text{nm}$ 和 $\lambda_2=940\;\text{nm}$ 测吸光度增量： $$\Delta A_{\lambda_1} = (\varepsilon_{1,\lambda_1} c_1 + \varepsilon_{2,\lambda_1} c_2)l, \qquad \Delta A_{\lambda_2} = (\varepsilon_{1,\lambda_2} c_1 + \varepsilon_{2,\lambda_2} c_2)l$$ 两式作比 $R = \frac{\Delta A_{\lambda_1}}{\Delta A_{\lambda_2}}$，未知的手指动脉光程 $l$ 在分子分母中完全消去！再上下同除以 $(c_1 + c_2)$，即可直接解出仅与比值 $R$ 有关的血氧饱和度 $\text{SaO}_2 = \frac{c_1}{c_1 + c_2}$。
  3. 化学发光与电化学发光（ECL，PPT P56–58）：
  • 电化学发光定义（PPT P56）：某些化学物质经过电极反应完成高能电子转移，生成不稳定激发态粒子，回到基态时以光辐射形式释放能量。
  • 鲁米诺（Luminol）试剂：鲁米诺 + 过氧化氢（$\text{H}_2\text{O}_2$）在碱性/铁催化下发蓝光，对血迹检出限低至 $1\;\text{ppm}$（PPT P57）。
  • 电化学发光甲醛传感器（PPT P58 四步反应链）： $$\begin{aligned} \text{Ni(II)} &\longrightarrow \text{Ni(III)} + e^- \\ \text{Ni(III)} + \text{HCHO} + 2\text{OH}^- &\longrightarrow \text{Ni(II)} + \text{CH}_2(\text{O})\text{O}^- + \text{H}_2\text{O} \\ \text{L}^{\cdot -} + \text{Ni(II)} &\longrightarrow \text{Ni} + \text{AP}^{2-*} \end{aligned}$$ 激发态 $\text{AP}^{2-*} \longrightarrow \text{AP}^{2-} + h\nu\;(425\;\text{nm})$，检测 $425\;\text{nm}$ 发光强度即可定量甲醛。

二、 压电石英晶体换能器与 Sauerbrey 方程（P59–64）

2.1 石英晶体的晶轴与压电效应（PPT P59–60）

    • 光轴（Z 轴）：对称轴，沿 Z 轴无双折射且无压电效应；

    • 逆压电效应：施加交变激励电压产生机械谐振（振荡器由石英晶体 + 反馈振荡电路组成）。

2.2 Sauerbrey 方程（PPT P61 & P63，核心计算必考公式！）

当石英晶体表面均匀沉积一层极薄的刚性物质（质量增加 $\Delta m$）时，谐振频率变化量 $\Delta f\;(\text{Hz})$ 与 $\Delta m$ 成严格正比（负号表示质量增加、频率下降）： $$\boxed{\Delta f = \frac{-2 f_0^2}{\sqrt{\rho_q \mu_q}}\cdot\frac{\Delta m}{A} = -C_f \frac{f_0^2}{A}\Delta m}$$

  • $f_0$：吸附物质前的石英晶体谐振基频（$\text{MHz}$）；
  • $A$：晶体表面电极有效面积；
  • $\rho_q = 2.648\;\text{g/cm}^3$（石英密度），$\mu_q = 2.947\times 10^{11}\;\text{g}\cdot\text{cm}^{-1}\cdot\text{s}^{-2}$（AT 切割晶体剪切模量）；
  • 代入常数合并得质量灵敏度常数 $C_f = 2.26\times 10^{-6}\;\text{cm}^2\cdot\text{s/g}$（注意 PPT P61 写作 $\Delta f = -2.26\times 10^{-6} f_0^2 \frac{\Delta m}{A}$，其中 $f_0$ 单位为 $\text{MHz}$），检测限可达 $10^{-12}\;\text{g}$（皮克级），故称石英晶体微天平（QCM / QCW）。
最小闭环

【最小闭环：Sauerbrey 方程 3 行驻波微分推导】 厚度为 $d_q$ 的石英晶片在基频谐振时满足半波长驻波条件：$d_q = \frac{\lambda}{2} = \frac{v_q}{2 f_0}$（其中石英剪切横波声速 $v_q = \sqrt{\mu_q / \rho_q}$）。 当表面均匀沉积极薄刚性质量 $\Delta m$ 时，等效于晶片厚度增加了 $\Delta d_q = \frac{\Delta m}{\rho_q A}$。由 $f_0 d_q = \frac{v_q}{2} = \text{常数}$ 取一阶相对微分： $$\frac{\Delta f}{f_0} = -\frac{\Delta d_q}{d_q} = -\frac{\Delta m / (\rho_q A)}{v_q / (2f_0)} \implies \Delta f = -\frac{2 f_0^2}{\rho_q v_q}\frac{\Delta m}{A} = \boxed{-\frac{2 f_0^2}{\sqrt{\rho_q \mu_q}}\frac{\Delta m}{A}}$$

  • PPT P62–63 应用实例：
    • 表面沉积氨基硅烷 $\to$ 微量 $\text{CO}_2$ 传感器；
    • 吸附三甲胺（TMA）$\to$ 鱼肉鲜度传感器（弱相互作用可重复使用）；PPT P63 给出实例：$f_0 = 8\;\text{MHz}$、直径 $5\;\text{mm}$ 晶振，$\Delta f = -1\;\text{Hz}$ 对应表面吸附质量密度 $\Delta m / A = 8.62\;\text{ng/cm}^2$（(注：该方程将在第 19 章压电免疫传感器中直接用于计算结合的抗体分子数！)）。

三、 热敏电阻换能器（P65–66）

  • 材料与分类（PPT P65）：由钴、锰、镍等金属氧化物高温烧结而成，分为正温度系数（PTC）、临界温度系数（CTR）、**负温度系数（NTC）**三类。
